# 更好的网络搜索 · 使用引导

> 这个插件**不注册也能用**，而且只有一件事是必须的：把宿主内置的『网络搜索』停掉。
> 想让它更快更稳，再往下看三步拿一把免费密钥，全过程大概 3 分钟，不需要信用卡。

## 一、装好后第一件事：关掉宿主内置的『网络搜索』

到宿主的**「插件中心」**里把 `web_search`（显示名『网络搜索』）**停用**，本插件就接管对话里的联网搜索。

- 这一步要你自己点：本插件不替你按宿主的开关。以前它是代你去按宿主的本地管理接口，而宿主正在重载插件列表时那一按常常 8 秒以上才回话，回话之前分不清是"没生效"还是"没答上"，结果把已经做成的事报成错误。停用一次就长期有效，也更稳。
- 在插件中心停用会顺手把「开机自启」也写成关，重启后它不会自己爬起来。
- 面板**首屏**就是这件事的检查页：它读宿主的实际状态，显示"在跑 / 已停"。还在跑时每次打开面板都会回到这一页；点「我关好了，查一下」确认已停用之后就不再弹。状态读不到时不算"没关"，也不会拿这个骚扰你。
- 为什么值得关：两个搜索插件同时挂着时，这一轮对话用哪一个由模型自己挑，你填的密钥、选的链路可能整轮都没轮到。

## 二、想让它更快更稳：三步接入（注册 → 粘贴 → 完成）

### 第 1 步：注册并拿到密钥

打开这个网址（国内可以直连打开，实测几百毫秒就能开，不用挂代理）：

https://dashboard.exa.ai/api-keys

- 登录方式选**邮箱登录**（按钮上写的是 Continue with Email）。QQ 邮箱、163 邮箱都能收验证信；半天没收到先去垃圾邮件里翻一下。
- 邮箱用 **QQ 邮箱 / 163 邮箱都可以**。等了一会儿没收到信，先去**垃圾邮件**里翻一下。
- 登录后点 **Create API Key**，生成一串密钥，**整段复制**下来。页面上写的 "API Key" 就是这里说的"密钥"。

注册完邮箱，Exa 会连着问你三个问题。照下面选就能进控制台，**选错了也不影响密钥、不影响额度**：

| 它问的问题 | 怎么选 |
| --- | --- |
| What are you coding with? | 随便选一个 |
| What integration should the prompt generate? | 选 **mcp** |
| What are you building? | 选 **Web search tool** |

这三题只决定它给你看哪一种接入引导；本插件调的是同一个端点，跟额度、速度都无关。

### 第 2 步：把密钥粘进面板的输入框

在插件面板的引导里，点进输入框，直接 `Ctrl+V` 整段粘贴，前后不要留空格。

- 保存以后，面板上**只显示后四位**（形如 `exa****9b2c`），不会再显示完整内容。
- 明文不会留在面板里，也不会写进日志；插件请求 Exa 时把密钥放在请求头里，不放进网址。

### 第 3 步：点「保存并使用」

插件会立刻用它搜一次来验货：

- **成功**：这把钥匙立刻让 Exa 升到搜索链路首位（只要 `anysearch_api_key` 还空着），以后每轮先走它；用的也是你自己账号的额度，不再和所有匿名用户挤同一个公共池。速度不会有明显变化，省的是"公共池被人问爆"的那种失败。
- **没验通过**：面板会直接告诉你原因，这把被标成「没验通过」，搜索自动去撞下一把钥匙；整池都不行才改用别的免费来源（免 Key 的 anysearch、必应），不会因此就搜不到东西。

之后随时能在面板「进阶」页的「Exa 密钥」卡里：查看每把密钥的掩码与状态、重测、移除单把、加一把；那三步教程收在这张卡的「怎么拿到一把 Exa 密钥」折叠块里，池子里已经有钥匙时它会自动收起。

### 一把的额度不够用？再加几把

一个 Exa 账号每月 $10（约 1400 次搜索）。不够就**换一个邮箱**再注册一个账号，拿到第二把密钥，在面板「进阶」页的「Exa 密钥」卡里点**加一把**贴进去。

- 密钥是**一个环**：一次搜索只用一把，从"上一把成功的那把"开始；这把报错就顺延下一把，走到列表末尾再绕回开头。你完全感觉不到中间失败过。
- 没有倒计时、没有"歇到几点"：一把坏钥匙要等其它每把都轮过一遍才会再被试一次，**这个循环本身就是重试节奏**。账号多几个，转一圈的时间自然就更长。
- **重启软件或插件都不会把循环打回原点**：转到哪一把了就按那把的指纹记下来，重启后从同一把继续，不会又从头去撞已经用完的那几把。
- 整池都失败时：默认**直接改用其它搜索来源**（免 Key 的 anysearch、必应等），照样能搜到东西。想要"再用一次公共匿名档试一下"，把「密钥管理」里那个开关打开就行——默认是关的，因为钥匙全见底时公共匿名档通常也不通，不如把时间省给下一个来源。
- 如果 Exa 整个连不上（超时、网络不通，跟你的钥匙没关系）：插件不会拿后面几把钥匙去撞同一条死网络，而是让 Exa 歇一会儿、这一次直接用别的来源。所以偶尔看到"这次是必应答的"，不代表密钥坏了。
- 面板不显示"还剩多少刀"——Exa 只提供已花费金额、不提供余额，而且那个接口要按团队找客服开通。所以状态一律来自密钥实际的回答：能用 / 额度用完 / 没验通过 / 还没测。

### 顺手也有：anysearch 的密钥（同样可选，只有一把）

面板「进阶」页的「AnySearch 密钥」卡里：粘贴 → 点「保存并使用」，插件会**立刻用它真搜一次**验货；旁边还有「测这把」和「移除」。怎么拿这把密钥写在同一张卡的「怎么拿到一把 AnySearch 密钥」折叠块里，已经有密钥时它会自动收起。

- 注册入口：https://www.anysearch.com/about （国内可直连），注册或登录后在控制台里生成密钥，整段复制。
- 留空照样能搜：anysearch 的匿名档本来就是默认的各路第一。
- 填了买到的是**更高的限额**，另外它还决定 exa 要不要升到链路首位——**填了这把，exa 就不再自动打头**。
- 429 只会告诉你"这次被限流"，不会把密钥标成没验通过；网络不通同理，状态一律不动。
- 和 Exa 那边一样，面板、日志、状态上报最多只显示 `any****尾4位`。

## 三、只想省事：什么都不用配

**照样能用。** 把上面第一节那一步做完就能直接开始搜，一个密钥都不用填：插件走公共的免费搜索来源，顺序是 **anysearch 首选 → Exa 次选 → 必应再次 → 百度兜底**。老版本装过来的机器，配置文件里可能还留着当年那份 exa 打头的顺序，插件认得它并且会忽略，不用你手动改。

差别只有这些：

- 更慢一点；
- 限额更低；
- 偶尔抽风（某些来源近期对陌生访问管得比较严）。

额度账（注册之后）：

- 注册送 **$20**，之后**每月刷新 $10**；
- 搜索一次大约 **$0.007**，所以 **每月约 1400 次、平均每天 47 次**；
- **不需要绑信用卡，用完不会自动扣钱**：超出后 Exa 返回 402，插件会自动切到别的搜索来源，你只会觉得慢一点。

## 四、常见问题

### 1. 搜不到结果怎么办？

按这个顺序看，不用改任何配置文件：

1. 先看「最近一次搜索」这张卡（它在「状态」页；「刷新面板」按钮在「诊断」页，重开一次面板也会刷新）：它写明刚才是哪一路答的、几条、多久、依次试过哪几路，失败时还会带上当时回给对话的那句话。这张卡是空的（"还没有搜索记录"）说明那次请求根本没走到插件，问题在宿主侧。
2. 再看面板顶部：插件是不是已经启动了。启动中时按钮点不动，等它跑完再刷新一次。
3. 点「开始自检」（在「诊断」页，它会真的挨个去搜——每个来源一次，开了"直连/代理双测"就是两次，会占额度），跑完给一句中文结论。
4. 看「现在会用到哪些搜索来源」：列表为空说明暂时没找到可用的来源，等插件启动完成后刷新。
5. 密钥状态显示「没验通过」：重新复制一次密钥再点「保存并使用」（常见原因是粘贴时带了空格、或者复制到了别人的密钥）。显示「额度用完」不是坏了，是这个账号的 $10 用完了：点「再加一把」补一个账号，或者点「重测全部」立刻再验一次；什么都不做也行，转一圈会轮到它。
6. 某一次特别慢：不用管，前面的来源不行时插件会自动换下一个来源重试。

### 2. 国内要不要开代理？

**不用为了这个插件特意开代理。** 默认打头的 anysearch、次选的 Exa、以及必应，国内直连都能到（实测 0.2–0.5 秒握手完成）。

- 面板「现在会用到哪些搜索来源」里显示"代理方式：auto"时，它会跟随你的系统/环境代理，不用手填。
- **duckduckgo 只有在检测到你在用代理时才会被启用**：国内直连它基本搜不到东西，所以没代理时你不会在列表里看到它，这是正常的。
- 如果你用 TUN 模式、拿到的是 `198.18.x.x` 这类虚拟地址：面板里的「代理虚拟地址放行」保持开着就能抓到网页正文，不需要你去懂网段配置。

### 3. 额度用完会扣钱吗？

**不会。** 注册不要信用卡、也不绑卡，所以不存在自动扣费。用完之后 Exa 返回 402，这把钥匙会被标成「额度用完」，本次搜索自动换下一把；整池都用完了才改用别的免费来源（免 Key 的 anysearch、必应），你只会觉得慢一点。

想让面板显示当前额度还剩多少，请到 Exa 自己的控制台看：https://dashboard.exa.ai

### 4. 要是想把内置搜索开回来呢？

到宿主「插件中心」把『网络搜索』重新启用就行，本插件不会拦它、也不会去改它的状态。记一件事：宿主的搜索网关留着 5 分钟的失败冷却，刚开回来的头几分钟相关路径可能还是空的，那不是没生效。

### 5. 注册账号老给我发广告邮件怎么办？

Exa 和 AnySearch 都是邮箱注册，验证邮件之后可能还会推产品动态。收到营销邮件时点信底的 **unsubscribe（退订）** 就好：只是不再收广告，注册好的账号和已经生成的密钥照常能用，额度、限速都不受影响。本插件不碰你的邮箱，也不替你退订。
