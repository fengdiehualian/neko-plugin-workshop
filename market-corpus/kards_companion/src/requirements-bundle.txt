#   * Record the exact wheel filenames and hashes in the bundle manifest; the
#     worker self-check must prove imports originate inside vendor/python.
#   * Keep the two JSON contracts separate:
#       worker-runtime.json  -> kards-worker-runtime/1 (worker self-check)
#       bundle-manifest.json -> neko-kards-bundle-manifest/1 (distribution tool)
#     The worker must never generate or overwrite bundle-manifest.json.
#   * Run the publication gate in THIRD_PARTY_NOTICES.md before publishing.
