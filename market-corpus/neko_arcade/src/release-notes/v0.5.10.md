# 🎮 猫娘小游戏 v0.5.10

> 这一版把**发布包从 252 MB 瘦到 1.7 MB** —— 装得快、更新也快，
> 而玩法、画面、存档**一模一样**。

## 📦 包体：252 MB → 1.7 MB

| | 以前 | 现在 |
|---|---|---|
| 发布包 | 252 MB | **1.7 MB** |
| 塔罗牌面（131 张） | 251 MB 打进包里 | **不进包**，首次运行自动下载 |
| 界面素材（头像/背景/立绘/徽章） | 2.0 MB 原图 | 288 KB（WebP，仍在包里） |
| 人生重开剧情数据 | 2.25 MB 明文 | 132 KB（压缩，内容不变） |

## ✨ 现在是怎么工作的

- **首次运行**：后台自动把塔罗牌面下载到本地（131 张 / 23.8 MB），
  每张都校验 sha256；**断网/失败会自动换源重试**（Gitee 主源 → GitHub 兜底），
  下载好的文件会跳过，重启不会重下。
- **还没下完就抽牌**：先出一张占位图 + 一句猫娘台词，补好之后自动出真图（不会卡住不回应）。
- **之后完全走本地缓存**，不再联网。
- **界面素材留在包里** → 帮助图的背景/立绘/徽章、头像**离线也能出图**。
- 想关掉自动下载/预热：主配置 `asset_auto_download` / `asset_prefetch` 设为 `false`；
  也可用 `asset_base_url` / `asset_mirrors` 换成你自己的素材源。

## 🎮 玩法没变

十一款小游戏、帮助图、棋类对弈、修仙 61 条指令、喵图相册……全部照旧。
你的存档与设置（`config.json`）不受影响，升级后出厂内容（帮助/关键词/情感模板）会自动刷新。

## 📥 安装

1. 把下面的 `neko_arcade.neko-plugin` 导入 N.E.K.O（1.7 MB，秒装）
2. 插件管理 → 启用「猫娘小游戏」
3. 直接聊天开玩喵（塔罗第一次抽牌时会自动把牌面下到本地）

## ⚠️ 已知

- 第一次抽塔罗牌可能要等一两秒（正在下载那张牌面）；之后都是本地读取。
- 离线安装时塔罗牌面出不来，会用占位图代替 —— 联网后自动恢复。
- 旧宿主（未合并原生图片通道的版本）会自动回退 markdown 图片语法，属预期行为。
