# 🎮 猫娘小游戏 (neko_arcade)

> 让猫娘陪你玩各种小游戏——下棋、钓鱼、海龟汤、修仙、塔罗牌……一个插件，无限可能。

N.E.K.O 插件 · 插件化小游戏聚合器 · 支持聊天/语音自然语言直接开玩

## 🌟 这是什么

一个**装着十一款小游戏的街机厅**，而猫娘就是陪你玩的那位。

你不用记指令、不用点菜单——在聊天里（或语音里）说一句游戏名，她就懂了，
然后**一路陪着你玩**：下棋时认真跟你对局、**落子就发一张棋盘图**；钓鱼时帮你数鱼获；
解海龟汤时当裁判；抽塔罗时给你解牌；修仙时给你护法。赢了夸你，输了安慰你，
还会**记住你上一次的冒险**，下次接着聊。

她不是念台词的工具人：**台词、心情、闲聊与局中主动搭话都由插件的统一陪伴层负责**——
读的是你在宿主里设定的**猫娘人设**（换角色即时生效），说话口吻、自称、在意什么都跟着角色走；
你下完一手迟迟不动，她会自己找个话头催你。

每个游戏都有：**中文配置面板**（想改数值直接点）· **帮助图**（不会玩就问她）·
**独立存档**（你的进度只属于你）· **专属指令**（十一个游戏不会互相串台）。

## ✨ 功能特性

- 🧩 **插件化游戏架构**：`games/` 目录放一个小游戏包即完成接入，零改动主插件
- 🔍 **自动发现**：启动自动扫描注册所有游戏，单个加载失败不影响其他游戏
- 💬 **自然语言开玩**：聊天/语音里对猫娘说游戏名或指令自动路由（LLM 工具）
- ♟️ **棋类对弈**：一个入口六种棋（五子棋 / 黑白棋 / 中国象棋 / 四子棋 / 围棋 /
  国际象棋），三档难度、可悔棋认输，**落子即出棋盘图**，边下边聊
- 🫧 **统一陪伴层**：台词三级降级（缓存 → LLM → 游戏模板）、心情由事件驱动、
  局中静默主动搭话；游戏只报"发生了什么"，怎么说全归插件
- 🧠 **LLM 网关**：游戏要"生成内容"（出题 / 剧情 / 文案）时只声明场景，
  缓存、配额、失败兜底与用量统计由网关统一负责，不再各写一套
- 🔄 **人格热更新**：猫娘人设从宿主配置读取（带文件签名 + TTL 缓存），
  宿主换角色后台词立刻跟着换，不会还挂着上一位的口吻
- 📦 **出厂内容随升级刷新**：`help / keywords / emotion` 升级即更新，
  你的 `config.json` 个人设置永不被覆盖
- 📖 **统一帮助系统**：帮助图按**功能分组**，「修仙帮助 战斗」直接看那一块，
  「我的纳戒」直接出那张背包格图；配色排版与面板同一套官方视觉
- 🖼️ **渲染桥接**：帮助图 / 棋盘图 / 面板图 / 结果卡全部由插件渲染（游戏只给数据），
  换主题、改版式对所有游戏一次生效
- 📸 **喵图相册**：猫娘随手晒照片（想发就发，频率她自己拿捏，不会刷屏），
  也能把你自己上传的图收进图鉴
- 🖥️ **玻璃拟态面板**：游戏卡片 + 开始/停止 + 配置抽屉 + 指令台，3s 自动刷新
- 🎯 **统一接口**：`GameAdapter` 基类——指令处理 / 玩家存档 / 状态上报 / 聊天推送
- 💾 **完整存档**：每玩家数据按游戏隔离存于 store，跨重启保留

## 🎮 怎么玩

聊天里直接对猫娘说游戏名即可开始：

- 「**下棋**」→ 她会列出六种棋，你挑一个（比如「**五子棋**」）
- 「**钓鱼**」→ 抛竿钓鱼
- 「**修仙**」→ 开始修仙之旅
- 「**塔罗牌**」→ 猫娘给你占卜
- 「**猫猫进化**」→ 领养小猫开始进化

**棋类怎么落子**（不同棋报法不同，棋盘图上都写了）：

| 棋种 | 怎么报 |
|---|---|
| 五子棋 | 坐标，如 `H8` |
| 黑白棋 | 坐标，如 `d3` |
| 中国象棋 | 起点终点，如 `b3 b7` |
| 国际象棋 | 起点终点，如 `e2 e4` |
| 围棋 | 坐标如 `d4`；不想下说「**过**」 |
| 四子棋 | 报一列，如 `d`（或写 4） |

对局中随时可以「**棋盘**」（重发棋盘图）、「**悔棋**」（双方各回一手）、
「**认输**」、「**换棋种**」；下腻了说「再来一局」也行。

不会玩？三种问法都行：

| 你想知道 | 就这样说 |
|---|---|
| 这个游戏有什么玩法 | 「**帮助**」（发一张功能目录图） |
| 某一类怎么玩 | 「**修仙帮助 战斗**」「**钓鱼帮助 鱼市**」 |
| 某一条指令怎么用 | 直接说指令名，比如「**我的纳戒**」 |

> 每个游戏的指令都是**专属命名**（猫猫状态 / 修仙状态 / 鱼店 / 海龟汤状态…），
> 不会跨游戏串台；具体指令以游戏帮助图为准。完整玩法见
> 📖 [使用指南](docs/ui/guide.md)。

## 📥 安装

1. 将 `neko_arcade` 发布包文件导入 `N.E.K.O` 就可以啦喵
2. 启动 N.E.K.O → 插件管理 → 启用「猫娘小游戏」
3. 直接聊天开始游戏吧喵

> 版本历史见 [docs/CHANGELOG.md](docs/CHANGELOG.md)。

> **📦 包体只有约 1.7 MB**：代码 + 界面素材 + 配置。
> 塔罗牌面（131 张 / 23.8 MB）**不进包** —— 首次运行自动从素材源下载到本地缓存并校验
> sha256（主源 Gitee，GitHub 兜底），之后完全离线；界面素材（头像/背景/立绘/徽章）
> 随包发布，所以没网也能正常出帮助图。

## ⚙️ 配置

每个游戏自带中文配置面板：字段、类型、说明都由游戏声明，面板自动渲染。玩家存档自动存于插件 store。

喵图相册的图库放在 `games/neko_photo/data/<分类>/`（**不进 git**，打包默认空图库）；
上传的图只在你本地，不会被提交或打进发布包。
