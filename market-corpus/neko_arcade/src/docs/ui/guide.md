# 🐱 猫娘小游戏 · 使用指南

> 喵呜～欢迎来到猫娘小游戏！这里是教你怎么和我一起玩的小手册，请放心食用～ 💕

## ✨ 怎么开始玩

超简单的！只要在聊天里对我喊一声游戏名就可以啦：

- **「下棋」** → 我陪你下一盘！五子棋 / 黑白棋 / 象棋 / 四子棋 / 围棋 / 国际象棋都行 ♟️
- **「钓鱼」** → 我们一起去河边钓鱼喵！🎣
- **「修仙」** → 开启修仙之旅，突破境界飞升！🧘
- **「塔罗牌」** → 让我给你算一卦，看看今天的运势！🔮
- **「猫猫进化」** → 领养一只小猫，陪我一起长大！🐱

> 也可以打开面板，点一下游戏卡片上的 **▶ 开始**，然后在指挥台输入指令哦～

## ♟️ 陪我下棋

说「**下棋**」我会列出六种棋，你挑一个就能开局（也可以直接说棋种名）。
落子怎么报、棋盘怎么看，我都写在棋盘图上了喵：

| 棋种 | 怎么报 |
|------|--------|
| 五子棋 | 坐标，比如 `H8` |
| 黑白棋 | 坐标，比如 `d3` |
| 中国象棋 | 起点终点，比如 `b3 b7` |
| 国际象棋 | 起点终点，比如 `e2 e4` |
| 围棋 | 坐标比如 `d4`；这一手不想下就说「**过**」 |
| 四子棋 | 报一列，比如 `d`（写数字 4 也行） |

每落一手我都会**发一张新的棋盘图**给你看。想重看就说「**棋盘**」，
手滑了说「**悔棋**」（我们各回一手）、不想下了说「**认输**」，
换一盘就说「**换棋种**」或者「**再来一局**」～

> 难度可以在面板里调（随手 / 正常 / 认真），嫌我太厉害就调低一点喵～

## 💬 游戏里怎么说话

| 你想做什么 | 对我这样说 |
|-----------|-----------|
| 开始玩一个游戏 | 说游戏名，比如「下棋」「钓鱼」「修仙」 |
| 看这个游戏有什么玩法 | 说「**帮助**」喵（会给你一张功能目录图） |
| 只看某一类怎么玩 | 说「**修仙帮助 战斗**」这样——游戏名 + 帮助 + 玩法名 |
| 看某一条指令怎么用 | 直接说指令名，比如「**我的纳戒**」（会给你那张背包图） |
| 查看自己的状态 | 说「**猫猫状态**」「**修仙状态**」这类指令 |
| 不玩了 | 说「不玩了」或者点面板的「⏹ 停止」 |

> 💡 每个游戏的指令都是**专属命名**（猫猫状态 / 修仙状态 / 鱼店…），
> 不会串来串去喵～具体指令以游戏帮助图为准！

## 🎁 猫娘会做什么

- 你玩游戏，我会在旁边**陪你加油打气**，赢了夸你、输了安慰你～
- 钓到稀有鱼、抽到好牌的时候，我会给你**发图片卡片**记录高光时刻！
- 我会**记住你玩过什么**，下次见面还记得上次的冒险喵～
- 我还会**随手晒照片**给你看（想发就发，但不会刷屏喵）；
  你也可以**上传自己的图**到「喵图相册」，我会挑出来发给你～
  上传的图只存在你本地，不会跟着插件包跑喵。

## ❓ 常见问题

| 问题 | 解决 |
|------|------|
| 喊游戏名没有反应 | 检查插件有没有启用喵；面板上能看到游戏卡片就 OK |
| 帮助图没有弹出来 | 重启一下插件再试试喵～（图是插件现场渲染的，稍等一下下） |
| 说「发图」没有图 | 相册里还没有图也可以的喵——我会先发自己哒；上传几张就更热闹啦 |
| 我晒图太频繁了 | 跟我说一声就好喵～插件也会自动拦下过密的发图 |
| 语音没有声音 | 语音是宿主在播的，去宿主的语音设置看看有没有打开喵 |
