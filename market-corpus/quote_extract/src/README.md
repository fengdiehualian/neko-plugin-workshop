# 照片语录 (quote_extract)

一个 **N.E.K.O.** 插件：随机抽一张**照片语录**发送到聊天。普通款为主，**隐藏款小概率掉落**（盲盒机制）。

- 图库内置并自动同步：往图库目录增删图片即可，无需任何配置
- 图库地址与只读凭据已内置锁定，对使用者不可见、不可修改
- AI 也可以在对话中主动发图（`send_meme` 工具）

## 使用

- 入口 **抽语录**：随机发一张照片语录；隐藏款平均每 20 抽出 1 次（可在配置调掉率）
- 入口 **刷新图库** / **图库统计**
- LLM 工具 `send_meme`：让猫娘自己决定什么时候发照片语录

## 更新图库

往 WebDAV 图库目录里上传/删除图片即可（支持 png / jpg / jpeg / gif / webp / bmp）：

- 普通款：`/memes/`
- 隐藏款：`/memes_hidden/`

图库列表默认每 10 分钟自动刷新，也可以手动触发「刷新图库」。

## 隐私说明

本插件不读取宿主的会话总线；图库凭据为只读密钥（仅可列目录与下载），抽图记录只保存在内存中。
