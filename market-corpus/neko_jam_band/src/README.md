# neko_jam_band — 猫娘伴奏团

你唱歌，猫娘用乐器伴奏。

```
麦克风 16kHz → YIN 音高检测 → 稳定音判定 → 音级直方图
     → Krumhansl 调性估计（24 大小调）
     → I-V-vi-IV / i-VI-III-VII 和弦进程（每小节一换）
     → 合成器（泛音叠加 + ADSR）→ 音箱
```

## 设计原则

- **拍点驱动，不逐音跟随**：猫娘按 BPM（默认 92）稳定弹和弦，你的歌声用于校准调性——故意不跟你的节奏，不然伴奏会乱
- **自动听调**：开唱后哼两句，8 秒窗口的音级直方图和 Krumhansl-Kessler 权重做相关性匹配，锁定 24 调之一；也可手动定调
- **长音和声**：唱稳一个音超过 0.8 秒，猫娘在上方叠一个和弦三音（可在面板关闭）
- **零采样文件**：四种乐器全部用泛音叠加 + ADSR 合成（钢琴/电钢琴/八音盒/尤克里里各有谐波结构与衰减曲线）

## 乐器

| 名 | 音色 |
|----|------|
| `piano` | 经典钢琴（快 attack，2.2 次幂衰减） |
| `epiano` | 电钢（软起音，长延音） |
| `music_box` | 八音盒（高频泛音，铃铛感） |
| `ukulele` | 尤克里里（拨弦瞬态） |

## 伴奏型

- `arpeggio`（默认）：每拍琶音 + 小节头低音
- `chord_pad`：每小节一次长和弦铺底
- `offbeat`：反拍短和弦（轻快）

## LLM 入口

| 入口 | 触发语 |
|------|--------|
| `jam_start` | "给我伴奏" / "弹起来" |
| `jam_stop` | "停" / "别弹了" |
| `set_instrument` | "换钢琴/八音盒/尤克里里" |
| `set_key` | "C 调" / "自动听调" |
| `set_pattern` | "换琶音/反拍" |
| `jam_status` | "现在什么调" |
| `recent_notes` | 回顾主人唱的音 |

## 依赖

- 运行：`sounddevice`（PortAudio 绑定；延迟导入，缺库不影响插件加载与测试）
- 测试/乐理：仅 `numpy`

## 已知边界（v0.1）

- 单声道人声基频（70-1000Hz），不支持多人和声检测
- 调性估计需要约 8 秒连续歌唱才能稳定；置信度 < 50% 时面板会提示继续哼
- 变调歌曲（中途转调）依赖音级直方图慢速漂移，可能滞后 2-4 小节
