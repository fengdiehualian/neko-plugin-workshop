# 应用启动器 (App Launcher)

管理软件快捷方式和可执行文件路径，让猫娘可以帮主人打开指定软件，支持开机自启功能。

## 功能特性

- **应用注册**：可直接把文件路径发给猫娘完成设置，名称可商量或由猫娘取名
- **精准启动**：按精准名称或别名启动已注册应用
- **应用列表**：查询可启动应用列表及状态
- **语音删除**：按名称删除已设置应用
- **实时同步**：操作后前端界面实时同步更新
- **开机自启**：支持设置应用开机自动启动

## 猫娘专属工具（@llm_tool）

| 工具名 | 功能 |
|--------|------|
| `app_launcher_list_apps` | 动态感知已注册应用及状态 |
| `app_launcher_launch_app` | 精准名称/别名启动，歧义给候选 |
| `app_launcher_register_app` | 文件路径直接注册，名称可协商或自动取名 |
| `app_launcher_remove_app` | 按名称删除 |

## 安装方式

通过 N.E.K.O 插件商城安装，或手动将本插件放入 `plugin/plugins/` 目录。

## 使用方法

### 方法一：通过猫娘对话

直接告诉猫娘你想打开什么软件，例如：
- "帮我打开 Chrome"
- "注册一下 D:\Games\my_game.exe"
- "删除已注册的 VS Code"

### 方法二：通过 Web UI

访问插件管理面板，可图形化管理已注册应用。

### 方法三：开机自启设置

在 Web UI 中为应用开启自启功能，N.E.K.O 启动时自动运行。
