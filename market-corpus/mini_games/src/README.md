# 猫娘小游戏屋 (mini_games)

让猫娘在聊天里陪你玩的**迷你小游戏合集**——抽卡 Gacha、今日运势、摇骰子。适合打发时间、欧气比拼、和猫娘一起玩。

> 设计目标：做成猫娘/ACG 语境下的「爆款」小游戏插件，主打抽卡，辅以运势与骰子。

## 玩法一览

| 入口 | 说明 |
| --- | --- |
| `gacha_pull` | 抽卡·单抽：抽一次卡，返回稀有度与猫娘道具 |
| `gacha_ten` | 抽卡·十连：十连抽，保底至少 R，更易出货 |
| `gacha_status` | 抽卡·图鉴：查看累计抽数、保底进度、收集统计 |
| `gacha_reset` | 抽卡·重置：清空当前玩家的抽卡进度与图鉴 |
| `fortune` | 今日运势：大吉/中吉/小吉/平/凶 + 幸运数字/幸运色/宜做之事（每天同一人结果稳定） |
| `dice` | 摇骰子：可指定颗数与面数，返回每颗结果与合计 |

## 抽卡机制

- 稀有度：`N / R / SR / SSR / UR`（概率默认 60% / 28% / 9% / 2.5% / 0.5%）。
- **保底**：连续 `pity_ssr`（默认 50）抽未出 SSR 及以上时，下一抽必出 SSR/UR；出货后保底计数归零。
- **十连保底**：十连的第 10 抽若前面都没出 R 及以上，强制保底 R。
- **图鉴**：按 `session_id` 隔离不同玩家的收集进度，可随时查看 TOP 收集。

## 示例对话

- 「来一发！」→ 猫娘调用 `gacha_pull`，喊出抽到的道具。
- 「十连！」→ 猫娘调用 `gacha_ten`，播报最好的一张。
- 「今天运势怎么样」→ 猫娘调用 `fortune`，播报今日吉凶。
- 「丢个骰子」→ 猫娘调用 `dice`，给出点数。

## 配置

复制 `config.example.toml` 为 `config.toml` 可调整：`pity_ssr`、`ten_pull_floor`、`dice_sides`、`dice_count`、`rarity_weights`。
