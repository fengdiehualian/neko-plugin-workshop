# Development-Aide 使用说明

## 功能定位
这个插件不是单纯的陪伴插件，而是面向开发协作的辅助型插件：

- 可以导入一个 Skill 技能目录
- 可以读取指定项目目录中的源码、配置和说明文件
- 只读模式下不会修改文件
- 让猫娘或开发助手基于这些内容给出代码建议、错误指正、结构建议和追踪分析

## 主要能力
- Skill 导入：通过 `scan_skill_dirs` 扫描候选，再用 `import_skill` 导入并持久化
- 只读扫描：通过 `list_project_files` 查看项目文件列表
- 文件读取：通过 `read_project_file` 读取源码与配置内容
- 结构分析：`project_summary` / `code_review` / `error_fix` / `multi_file_summary` / `quick_audit`
- 配置管理：在设置面板中配置工作区路径、Skill 路径和单文件读取上限

## 快速上手

### 1. 配置工作区
在设置面板把「项目工作区路径」填成**项目根目录的绝对路径**（例如 `D:\projects\demo`），点「保存设置」。
面板会用状态标签告诉你目录是否真的存在——如果显示"工作区目录不存在"，读取一定会失败，请先修正。

### 2. 读取文件
`read_project_file` 支持三种写法，随便哪一种都能用：

| 写法 | 例子 | 说明 |
|------|------|------|
| 工作区相对路径 | `src/main.py` | 最准确，推荐 |
| 工作区内的绝对路径 | `D:\projects\demo\src\main.py` | 自动转成相对路径 |
| 只给文件名 | `main.py` | 在工作区内自动查找；同名多个时会列出候选让你选 |

工作区**之外**的文件会被拒绝，错误信息里会带上当前工作区路径，方便你改配置。
面板里也有「读取文件（自检）」区块，可以直接验证读取是否正常。

### 3. 导入 Skill
1. 面板点「扫描技能目录」：自动扫描 `~/.trae/skills`、`~/.trae-cn/skills` 等常见位置，以及当前工作区
2. 在「扫描到的技能目录」下拉里选一个
3. 点「导入所选技能」

也可以直接把技能目录的绝对路径粘进输入框后导入，或对猫娘说「把 `D:\...\skills\xxx` 导入」。
技能目录需要包含 `SKILL.md`（或 `skill.toml`）作为标记。

### 4. 分析结果里的"覆盖度"
所有分析类入口都会在结果里说明**实际读取了多少文件、多少字符、是否有内容被截断**——
如果只覆盖了部分文件，结果里会标出 `partial: true`，不会把"没读到"说成"没问题"。

## 适用场景
- 用户在编写插件或项目代码时，需要 AI 站在代码现状上给出意见
- 需要对接已安装的外部 skill 提供开发方法论
- 需要在不修改文件的前提下分析代码结构、定位问题和推荐修正方案

## 关键原则
- 仅读，不写
- 不修改工作区原始文件
- 以代码内容为依据，给出结构化建议
- 帮助用户完成开发、纠错、优化与重构
