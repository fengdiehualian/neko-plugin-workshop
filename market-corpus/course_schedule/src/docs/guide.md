# 课程表插件使用指南

通用课程表工具，支持 **手动录入**、**课表文件上传** 和 **一键从教务系统导入** 三种方式。

---

## 🚀 方法一：一键从教务系统导入（推荐）

最快的初始化方式。打开插件面板 → 找到「🚀 一键从教务系统导入」卡片 → 按下面填写。

### 表单每一项怎么填？（含来源说明）

| 字段 | 怎么填 | 去哪里找 |
|---|---|---|
| **教务适配器** | 下拉选择，如「喜鹊儿」 | 由插件自动检测可用适配器。如果显示"未检测到可用的教务适配器"，说明插件没完整加载，点右上角「重载」按钮。 |
| **教务系统地址** | 填你的学校教务系统完整 URL | 浏览器打开学校教务系统登录页，地址栏里的那个 URL。<br>例：`https://jwxt.your-school.edu.cn` 或 `https://jwgl.your-school.edu.cn/jwglxt/`<br>⚠️ 不要只填域名，要包含路径（有的学校是 `/jwglxt/`，有的是 `/jxgl/`） |
| **或 学校代码** | 填学校代码（如果你知道） | 教育部发布的院校代码，如 `12623`。<br>如果适配器内置了这所学校的预设配置，填代码就不用填"教务系统地址"。<br>👉 **不确定就留空，改填上面的"教务系统地址"** |
| **学号 / 工号** | 你在教务系统里的登录账号 | 就是你选课、查成绩用的那个学号。 |
| **密码** | 教务系统密码 | 就是你登录教务系统的密码。<br>🔒 **仅本次请求使用，不会被保存**（浏览器开发者工具能看到明文，请在私人设备上使用） |
| **学期关键字（可选）** | 如 `2025秋` / `2025-2026-1` | 如果留空，插件会自动拉取最新学期。<br>想指定某学期才需要填，填教务系统里学期名称包含的任意关键字即可。 |
| **导入到学期（可选）** | 下拉选择 | 如果你已经在插件里创建了学期，选一个导入进去（会自动匹配/新建课程）。<br>留空 = 插件自动创建或匹配最合理的学期。 |

### 常见教务系统 URL 示例

| 学校类型 | URL 格式 |
|---|---|
| 大多数高校 | `https://jwxt.xxx.edu.cn` 或 `https://jwgl.xxx.edu.cn/jwglxt/` |
| 部分独立学院 | `https://jw.xxx.edu.cn/jxgl/` |
| 中学 / 中职 | `https://erp.xxx.edu.cn/jwglxt/` |

> 💡 **小技巧**：在教务系统登录页 **按 F12 → Network → 刷新页面**，找到 URL 里带 `jwglxt` 或 `jxgl` 的地址，那就是根地址。

### 导入后发生了什么？

1. 插件用你的账号密码登录教务系统
2. 解析课表 HTML → 提取每门课的课程名 / 教师 / 地点 / 周次 / 节次
3. 在数据库里创建或更新课程 + 课时
4. Toast 提示：`✅ 导入成功 | 3 门课新建 | 12 课时`

### 导入失败怎么办？

| 症状 | 可能原因 | 解决 |
|---|---|---|
| `登录失败` | 密码错 / 教务系统升级了接口 | 重新确认密码；换浏览器登录试试是否正常 |
| `找不到学期` | 学期关键字不对，或 URL 路径不对 | 去掉关键字留空；确认 URL 里是否包含正确路径（`/jwglxt/`） |
| 导入后课程全空 | 教务系统用了验证码 | 目前适配器不支持有验证码的系统 |
| URL 拼出来 404 | 没填路径 | 补全到含 `/jwglxt/` 的完整地址 |

## ✍️ 方法二：手动添加课程

适合教务系统用不了、或只想加几门课的场景。

### 第一步：创建学期

在面板「学期管理」卡片里填写：
- **学期名**：如 `2025 秋季`
- **开始日期**：第一周周一的日期
- **结束日期**：最后一周周日的日期

→ 点「添加学期」，系统自动算好第几周。

### 第二步：添加课程

在面板「添加课程」卡片里填写：
- **课程名**：如 `高等数学`
- **教师**：如 `王老师`
- **上课地点**：如 `3-201`
- **时间安排**：周几 + 第几节，支持多段

### 周次进阶（可选）

如果你的课是单周上 / 双周上 / 特定几周上：
- 在"周次"里填 `1,3,5,7,9,11,13,15,17`（单周）
- 或 `2,4,6,8,10,12,14,16,18`（双周）
- 不填 = 每周都上

## 📄 方法三：上传课表文件

支持 `.xlsx` / `.xls` / `.csv` / `.json` / `.ics`。教务系统导出的 `.xls` 即使是 **HTML 伪 xls** 或带**合并单元格**（双节课跨行、表头跨列），也能正确展开解析。

1. 面板「上传课表文件」卡片 → 选择文件 → 自动识别并导入
2. 导入结果提示：识别 N 门课 / 新增 N 门 / N 节
3. **重复导入安全**：同名课程自动复用（补全教师/地点）、相同课时自动去重，不会产生重复数据

> 💡 想先确认识别结果？用「高级工具 → 预览/诊断」查看解析出的课程与课时。

## ⏱ 上课时间自定义

面板「作息时间（上课时间设置）」卡片（需先创建学期）：

- 每节课可自定义 **起止时间**（`HH:MM` 格式）与 **时段**（上午/下午/晚上）
- 支持 **添加一节** / **删除** / **恢复默认**（默认 11 节作息）
- 点「保存作息时间」后，周课表角标时间、「下节课」提醒、今日课表立即按新时间生效

## 🔧 核心功能一览

### 查询类

| 功能 | 说明 | 入口 |
|---|---|---|
| 今日课表 | 今天有什么课 | 面板「今日课表」卡片 |
| 明日课表 | 明天有什么课 | 面板「今日课表」右侧按钮 |
| 本周课表 | 整周一览 | 面板「本周课表」7 列展示 |
| 下一节课 | 最近还没上的那节 | 面板顶部「距下次考试」旁 |
| 周数信息 | 当前第几周 / 学期剩余天数 | 面板「倒计时」卡片 |

### 作业管理

面板「作业管理」卡片：添加作业、设置截止日期、标记完成。

### 考试管理

面板「考试管理」卡片：添加考试、设置考试时间、地点。到期前会在面板顶部提示。

### 调课与例外

如果某天某节课有变动（调课 / 取消 / 加课）：
- 「取消一节课」：选原课程 + 日期 + 节次
- 「新增一节临时课」：填课名 + 日期 + 节次 + 地点

## ⚙️ 配置文件

插件根目录下的 `plugin.toml` → `[course]` 段：

```toml
[course]
timezone = "Asia/Shanghai"         # 时区，默认上海
remind_enabled = false              # 上课提醒（默认关，设 true 开启）
remind_lead_minutes = 10            # 提前多少分钟提醒
remind_check_interval_seconds = 60  # 每多少秒检查一次
```

⚠️ 修改后需要点插件面板右上角的「重载」按钮才能生效。
