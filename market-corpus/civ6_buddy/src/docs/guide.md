# 文明6陪玩（civ6_buddy）使用说明

让 YUI 陪你打《文明6》：看懂你的局面、给分主题建议，还能**自动托管每回合的重复运营**——你专心打仗和做决策。

## 它能做什么

**看懂局面**（解析你的 `.Civ6Save` 存档 + FireTuner 官方数据）：
- 回合数、游戏速度、地图大小与类型
- 你的文明与领袖（含特性一句话）、全部敌对文明与领袖、城邦列表、已装 MOD
- 各文明外交关系、文化产出/旅游业绩、经济面板（金币/人口/单位构成）、城市人口与产出

**给建议**：开局 / 科技 / 建城 / 战争 / 胜利路线 / 外交——按当前局面给出规则化建议（可追溯，不是空话）。

## 怎么用

对桌面 YUI 说，例如：
- 「看一下我文明6的存档，现在什么局面？」
- 「我这局用什么路线好？」
- 「我现在的对手都有谁？关系怎么样？」

YUI 会自动调用插件工具：列出存档 → 解析最新存档 → 汇报局面 → 给建议。

## 运营托管（核心能力：官方数据写链路）

分工规则：**运营归 YUI，打仗归你**。托管时 YUI 每回合自动处理：

- **推进回合**：点「下一回合」前先处理完所有挡路的事——弹窗、待选科技/市政、待任命总督、单位待指挥、政策空槽、万神殿待选等
- **自动选科技与市政**：按当前局面（人口/金币/地形/军力）从政策库里选最优解（不是机械乱点）
- **自动填政策槽 / 选万神殿 / 任命总督 / 单位自动升级**（只强化不引战）
- **侦察兵自动探路**（远离首都、避开水域/山脉/己方单位），战斗单位不主动开战
- **自动关卡死弹窗**（自然奇观发现、尤里卡提示等），不再卡回合；有自愈兜底
- **外交自动化**：自动向离首都最近的城邦派使节

**怎么开始与交还**：
1. 「**开始托管文明6**」→ 进入托管（记录当前回合）
2. 「**继续**」→ 执行本回合运营（官方 API 设置生产/科研、跳单位、关弹窗、结束回合）
3. 「**我来打**」/「停止托管」→ 立即交还控制权；检测到战争横幅也会自动交还

**能力边界（如实说明）**：
- 操作全部走**官方通道**（FireTuner 官方 API 为主，屏幕点击兜底），**不改你的存档**、不做任何内存 hack
- 每一步操作后真实截图/官方读回验证；识别不了就停下如实汇报，**绝不瞎点、不挂机、不编状态**
- 单位移动与战斗归你；侦察兵只做安全探路，不引战
- 托管期间 steam_manager 让位锁生效，避免两个自动化抢键鼠
- 首次使用会自动装 Steam SDK（appid 597260，最小必要）并启用 Tuner；可随时关掉

**按钮坐标校准**：默认按钮坐标按 1920×1080 窗口实测；分辨率不同时在运行配置 `[civ6_buddy.ops_buttons]` 中校准（见 config.example.toml 注释）。

## 存档目录

默认读取：

```
C:\Users\<用户名>\Documents\My Games\Sid Meier's Civilization VI\Saves
```

可在插件运行配置 `config\plugin.toml` 的 `[civ6_buddy]` 节中改 `saves_dir` 覆盖。

## 运行依赖

- 本机安装 Node.js（>=16）：存档解析器内嵌于插件包，通过 `node` 执行
- 游戏本体《Sid Meier's Civilization VI》（本地路径检测不依赖游戏运行中）

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 「尚无任何存档」 | 游戏还没自动存档：开局后等 AutoSave 生成再问 |
| 「本机没有 node」 | 安装 Node.js（https://nodejs.org）后重启插件 |
| 「解析失败」 | 存档损坏或版本不兼容：换个存档试 |
| 托管时频繁停下汇报 | 画面/按钮识别不到（分辨率或 MOD 变了）：先按「校准」指引调整，或先交还手动 |
