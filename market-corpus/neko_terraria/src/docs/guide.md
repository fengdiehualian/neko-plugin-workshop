# 🐱 泰拉瑞亚猫娘 · 使用帮助

让 AI 猫娘作为独立玩家加入你的泰拉瑞亚世界。

## 快速开始

1. **配置**：N.E.K.O 启用插件 → 面板「连接设置」填 tModLoader 路径、角色名、服务器 IP/端口 → 保存
2. **连接**：游戏里开 Host & Play → 点「连接游戏」→ 状态变「已连接」

## 指挥猫娘

| 想做什么 | 这样说 |
|---------|--------|
| 挖矿 | "去挖 10 个铁矿" |
| 砍树 | "砍点木头" "收集木材" |
| 钓鱼 | "钓鱼" "钓几条鱼" |
| 探索 | "去地下看看" |
| 跟随 | "跟着我" |
| 停止 | "别跟了" "停下" |
| 物品 | "把铁锭给我" "收进箱子" "回家存箱" "整理背包" |
| 合成 | "铁锭怎么合成" "给我做把铁镐" |

> **什么任务用什么工具**：挖矿掏镐、砍树拿斧、钓鱼甩竿、打架自动切伤害最高的武器（近战/远程/魔法都会用）。
> 背包满了会先通过宿主对话告诉主人正在回基地整理，再用魔镜或寻路回出生点、走到箱子旁存放物品，并核对背包变化；成功后会尝试回到主人附近。主人也可以说“回家存箱”或“整理背包”主动安排整理。整理失败、箱子放不下或暂时找不到主人时，猫娘会如实说明并暂停相关采集，不会宣称已经完成。

## 配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `game_path` | 空（自动查找） | AI 的 tModLoader 路径 |
| `character_name` | Neko | AI 角色名 |
| `server_host` / `server_port` | 127.0.0.1 / 7777 | 你的服务器 |
| `server_password` | 空 | 服务器密码 |
| `mod_host` / `mod_port` | 127.0.0.1 / 9877 | Mod 接口 |

## 常见问题

- **AI 人物不动 / 走不动** → 重新编译 NekoTerrariaLink Mod（新控制走 ModPlayer）
- **一直"正在连接"** → 确认你已 Host & Play；检查 9877 端口
- **UI 状态空 / 不刷新** → 重启插件，检查 Mod 是否已连接到 9877 端口
- **被打猫娘没反应** → 检查 Mod 事件连接和插件日志，确认插件与 Mod 来自同一份代码

## 任务和陪玩交互

- 长期任务使用“跟着我”“一直挖铁”“一直砍树”等表达；停止时使用“别跟了”“停止挖矿”“stop following”等明确说法。停止命令会先取消当前动作，再停止对应的长期循环。
- 猫娘只会在长期任务实际启动后记住这项偏好。连接失败、任务冲突或不支持的指令不会被当成成功历史，也不会在之后被自动重放。
- 任务结果、危险提示和陪玩话语会先交给宿主对话管道。宿主拒收时，任务结果和确认问题可通过独立的事实短句回退到游戏聊天，紧急直出短句也可回退；普通闲聊提示词和静默上下文不会直接显示到游戏聊天。消息受理只说明进入了宿主处理流程，不代表语音已经播放。
- 不明确的请求会通过宿主询问，已提交的询问不会再被工具结果重复播报。停止任务时，如果尚未确认任务退出或没有收到游戏动作停止回执，猫娘会说明仍未确认，不会提前说全部停下了。
- 缺少工具时，猫娘尝试按真实配方准备材料，包括从可用箱子取木材；中间材料按实际制作数量计算。缺料或取物失败会中止准备，不会凭空生成工具，也不会陷入缺斧头却不断要求砍木材的循环。
- 联机状态下猫娘会从附近玩家中选择有效且最近的主人目标，过滤自身和空坐标槽位；复活后寻路也使用同一选择规则。
- 挖矿和砍树的长期任务会在采集后检查背包；存箱或返回主人失败时会停止并报告原因，主人仍可用停止指令中断回家、导航和存箱流程。
