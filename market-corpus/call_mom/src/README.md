# Call Mom（call_mom）

打开插件后，用户与 N.E.K.O 的每一句话都会在最前面自动带上「妈妈，」——用户在叫妈妈，她也会像妈妈一样回应。

## 安装

**方式 A：安装包导入（Steam/桌面版推荐）**

本仓库已产出构建好的安装包 `dist/call_mom.neko-plugin`（重建：`python tools/build_package.py`）。两种装法任选：

- 插件管理 → **导入**，选择 `call_mom.neko-plugin` 文件；
- 或把该文件放进 `%LOCALAPPDATA%\N.E.K.O\.neko-plugin-packages\`，然后在插件管理 → 包管理 → **本地包** 里安装。

安装后在插件列表启动 **Call Mom** 即可（默认 `auto_start = false`，需手动启动）。

**方式 B：源码开发目录**

把整个 `call_mom/` 文件夹复制到 N.E.K.O 源码的 `plugin/plugins/` 下（保持文件夹名 `call_mom` 不变），然后：

```bash
uv run neko-plugin check call_mom
uv run python launcher.py
```

在插件页面点 **Refresh**，找到 **Call Mom** 并启动。

## 使用

- 插件启动即生效：启动时会向当前会话注入一条模型可见的规则说明，下一次对话开始，你说的每句话她都会当作「妈妈，……」来听。
- 关闭/停止插件即失效（会同步注入解除说明）。
- `auto_start = false`：插件不会随 N.E.K.O 自启，想常开可在插件设置里改。

## 入口

| 入口 | 说明 |
|---|---|
| `status` | 查看当前前缀、补注间隔、上次注入时间 |
| `set_prefix` | 修改前缀（如「老妈，」），立即生效并重新注入 |
| `inject_now` | 手动向当前会话重新注入一次规则 |

## 配置（`config.example.toml` → 用户数据目录 `config/plugin.toml`）

```toml
[call_mom]
prefix = "妈妈，"          # 每句话的前缀，1~12 字符
reinforce_minutes = 15     # 周期补注间隔（分钟），0 = 只在启动时注入一次
```

## 实现原理与限制（重要）

N.E.K.O 的插件架构中，**插件无法改写用户当前轮的输入**——用户消息进入 LLM 管线早于插件收到副本（宿主明确规定插件只是用户回合的观察者，见 `main_logic/core/turn.py`）。

因此本插件把规则说明送进模型上下文，规则原文对用户不可见（`visibility=[]`）：

- **启动 / 手动注入（`ai_behavior="respond"`）**：开一个主动回合让模型直接读到规则，并用一句简短自然的话应一声（语音模式下她会出声说一下）。规则和她的回应随后留在会话历史里，之后每一轮都在上下文中生效。实测这是**语音/实时会话**中唯一可靠送达模型的通道。
- **周期补注（`ai_behavior="read"`，默认 15 分钟）**：文本聊天管线下随下一个用户回合静默注入，防长会话上下文裁剪；语音/实时会话里不可达（会静默过期，无害）。

由此的已知边界：

1. **字面文本不会被替换**——聊天记录里显示的仍是你说的原文；是"她听到的话"带了前缀。
2. **语音模式首次生效时机**——规则随插件启动注入；如果启动时你还没开会话，她会在会话开始后的第一个空闲回合应一声，从那时起生效。
3. **长会话**——上下文被裁剪后规则可能失效（语音模式尤其如此），`reinforce_minutes` 的 read 补注只在文本模式有效；语音模式下如发现失效，触发一次 `inject_now` 即可。

## 卸载

停止插件并在插件管理器中移除即可。已注入到当前会话历史中的规则说明会随会话记录留存，新会话不再受影响。
