# NEKO 直播助手 v0.3.0

本版本将中文显示名改为「NEKO 直播助手」，并修正 manifest 默认值与代码默认值不一致的问题。

## 变更

- 中文界面（`zh-CN` / `zh-TW`）的插件名、面板标题和面向用户的文案统一为「NEKO 直播助手」；英文及 `ja` / `ko` / `es` / `pt` / `ru` 界面仍显示「NEKO Live」。命名约定见 [development.md「命名与范围」](../development.md#命名与范围)。
- 面板标题改为 i18n 引用，随宿主语言切换。
- `plugin.toml` 默认值与 `LiveConfig` 对齐：`activity_level` 由 `active` 改为 `standard`，`queue_limit` 由 `3` 改为 `5`，`stream_theme` 清空误留的示例主题。
- 新增 manifest 与 `LiveConfig` 默认值一致性回归测试。
- 修复从宿主软链接路径运行时，旧标识扫描测试误扫自身的问题。

## 升级与边界

- 插件 id `neko_live`、entry、包名、数据目录和 `previous_ids` 不变，无需迁移。
- 内部 prompt 标记（如 `[NEKO Live ...]`）保持原文，不改变 prompt 契约。
- 在面板保存过设置的用户继续使用已保存的值；从未保存过设置的用户会使用新默认值，即活跃度变为「标准」、队列上限变为 5、直播主题为空。需要原有行为时可在面板中重新设置。
- 不新增依赖或后台轮询。

## 验证

- 本地全量 Python 回归：2294 passed、1 skipped；跳过项为 Windows 上的 POSIX 权限检查。
- 插件 CLI check 无错误；面板类型/编译/交互及兼容面板一致性检查通过。
- 发布流程另行执行发行包构建、元数据与 payload hash 校验，并由 GitHub Actions 生成 Market evidence。

以上离线验证不包含真实平台连接、实际模型回答及 Electron 音频播放验收。
