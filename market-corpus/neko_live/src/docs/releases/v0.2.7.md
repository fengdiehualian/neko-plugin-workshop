# NEKO Live v0.2.7

本版本集中修复直播连接、账号退出、观众记忆、档案管理与平台监听的异常边界，并补齐面板和发行资产检查。

## 修复

- 断开、退出账号或修改房间后，旧连接请求不再重新启动监听或覆盖新的连接状态；Bilibili 连接要求有效登录验证。
- Twitch 迟到的凭据刷新不能恢复已退出的账号；订阅撤销或连接终止后正确停止监听并更新状态。
- 关闭个性化观众记忆后停止收集与提交；投递回执不再写成猫的回答；批次按角色、平台和直播会话隔离，并限制积压和请求数量。
- 插件停止时取消并等待所属任务，逐模块隔离清理超时，允许重试未完成的清理；修复抖音启动取消及重连时的旧连接清理。
- 自定义档案目录回退使用独立数据文件与持久化归属标记，避免重启读取旧库或多个目录互相覆盖。
- 观众档案搜索、删除、重置与清空接通 Hosted UI 授权；搜索不会循环请求，删除或重置后刷新当前搜索结果。
- 礼物连击使用最终累计数量、价值和感谢档位。
- 主动话题统一执行单观众防刷屏门槛，保留话题证据并适配宿主 1000 token 预算；成功为空的趋势结果正常缓存。
- 兼容面板从模块源码生成，补齐配置同步字段，新增生成一致性、类型和交互检查；继续隐藏旧的空白“打开界面”入口。
- 恢复固定版本的 Windows amd64 抖音桥接程序，并检查发行包内的程序、SHA256、版本与 MIT 许可文件。

## 升级说明

个性化记忆开启时会保存筛选后的观众话语并提交宿主长期记忆。关闭停止新增；本地档案删除、重置或清空不会删除宿主已经接受的记忆。八种语言的面板说明已同步。

自定义路径的新回退库按来源隔离。已有明确归属标记的旧回退库会在下次写入时迁入独立文件，并保留原文件；没有归属标记的历史回退文件保留供人工恢复，不自动混入其他目录的数据。

抖音桥接程序增加约 42.5 MB 原始体积、约 13 MB 压缩体积；该内置程序适用于 Windows amd64。缺失、校验失败或其他平台无法启动时会显示不可用状态。

## 验证

- Python 全量回归：2024 passed、1 skipped；跳过项为 Windows 上的 POSIX 权限检查。
- 与发布 CI 相同的 Ruff 0.12.4 检查。
- 六份 UI 源码类型与转译检查，宿主 UI-kit 下搜索/重置/删除、新 action 转发的离线交互验证。
- 八种语言 key/占位符一致性，以及发行包内容、元数据和 payload hash 检查。

以上验证不包含真实平台 OAuth、长时直播、实际模型生成及 Electron 音频播放验收。
