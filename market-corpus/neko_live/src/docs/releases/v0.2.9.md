# NEKO Live v0.2.9

本版本集中修复多观众连续互动中的欢迎、头像、作者归属和历史证据问题，并修复队列清理、开关即时生效及观众记忆提交的异常边界。

## 修复

- 同时开启进场锐评和欢迎时，已经锐评过的观众回退到欢迎；在同一观众锁内决定分流，避免老观众被去重吞掉。
- 普通接话中明确询问自己头像时，可以携带当前观众头像，图片传输与锐评路由分离。未附图、默认头像、分析关闭或图片超限时明确限制视觉依据，禁止借用历史图片。
- 头像请求识别排除引述、转述及明确拒绝；拒绝锐评头像时走普通回复。
- 当前弹幕正文内联公开昵称和稳定的观众标识，推荐称呼与作者身份分离；提示词截断保留完整作者标签，标识不用于语音称呼。
- 询问首次来访或认识时间时，没有明确记录就承认未知，不把过去模型猜测当作事实。
- 压缩已知重复规则和作者引用，修复中文长昵称、表情与罕见字在首次锐评中挤满提示词预算的问题；保持宿主 1000 token 上限，未知必要规则继续完整保留。
- 清空队列及恢复运行会取消插件尚未投出的弹幕、进场、关注、点赞和支持事件任务；取消未完成前保留队列占用，迟到任务在输出前再次校验。
- 关闭关注或点赞欢迎后，身份查询、档案查询等异步步骤中的旧事件在输出前重新检查开关。
- 本地档案和观众记忆只学习真实观众话语，排除进场、关注、点赞及系统礼物描述，保留 SC 正文和已验证 Twitch Cheer 文本；批量欢迎保留原弹幕。
- 宿主记忆接口返回 HTTP 成功但未确认保存时保留待提交批次，后续使用相同幂等键重试，避免把未保存误记为成功。
- 面板的头像分析开关可独立于首次锐评开关设置，兼容面板同步更新。

## 升级与边界

- 无需修改既有配置，也不新增依赖或后台轮询。
- 当前头像传输使用现有平台能力；未新增 Douyin 或 Twitch 头像抓取。
- 观众标识用于区分作者，不承诺匿名性；提示词约束不能保证模型永远不认错。
- 插件不能撤回已交给宿主的输出或音频；清空队列只影响插件尚未投出的任务。
- 历史档案和宿主已经接受的旧记忆不会自动清理。
- 本次未新增历史首次来访查询；本地首次观察时间不等于首次认识时间。

- 回归覆盖新老观众分流、A/B 头像交替、同名与改名观众、引述和拒绝、长昵称预算、异步清队列与开关、真实话语筛选及记忆确认失败后的重试。

以上离线验证不包含真实平台连接、实际模型回答、宿主历史压缩效果及 Electron 音频播放验收。
