## 1.3.0

**新增国内卫星百科（灰机wiki）检索**

### 新增

- **卫星百科检索**（`sat_wiki_search`）：检索卫星百科（sat.huijiwiki.com / 灰机wiki）
  的中文航天条目，覆盖火箭、卫星、航天器、发射场、航天机构与任务等，
  返回标题、摘要（去掉高亮标签）、规范链接与命中总数。
- **卫星百科查询工具**（`lookup_satellite_wiki`）：猫娘回答「风云四号是什么卫星」
  「文昌发射场」这类问题时，可主动调用该国内中文航天百科。
- **接入综合查询**：`lookup_space_info` 现在会在百度百科之后、网页兜底之前
  先查卫星百科，让「XX 是什么」类问题的中文资料覆盖面更广。

### 改进

- 新增可配置项 `huijiwiki_base_url`（默认 `https://sat.huijiwiki.com/`），
  可替换为任意同类 MediaWiki 站点。
- **风控识别**：卫星百科（灰机wiki）启用了 Cloudflare 托管挑战，被拦截时接口
  返回的是 **HTTP 403 + HTML 挑战页**（响应头带 `cf-mitigated: challenge`），
  而不是 JSON。插件会先按响应头/正文特征判定风控，再区分「接口报错」，
  如实返回「站点风控拦截了本次请求」并建议改用 `baike_search`——
  既不会把风控页当成「未收录」，也不会用旧缓存或猜测内容顶替。

### 数据来源

Launch Library 2、NASA NTRS、百度百科、卫星百科（灰机wiki）、Bing
（均为国内可直连）。

## 1.2.0

**新增多来源检索与防幻觉引导**

### 新增

- **中文百科检索**（`baike_search`）：查询百度百科条目摘要，适合检索中文航天资料，
  例如「长征五号」「东方红一号」「天宫空间站」。
- **网页兜底检索**（`web_fallback_search`）：本地数据库和百科都没有收录时，
  用网页搜索获取相关资料链接与摘要，便于进一步查阅原文。
- **综合查询工具**（`lookup_space_info`）：猫娘回答「XX 是什么」这类问题时，
  会自动依次检索航天数据库、中文百科与网页，任一来源命中即返回。

### 改进

- **自动降级**：Launch Library 2 返回额度限制（429）或未收录时，
  不再直接报错，而是自动改用百度百科与网页检索。
- **无结果时给出明确指引**：三个来源都没有查到时会返回
  「本地数据库没有收录，请直接告诉用户没有查到，不要凭猜测描述
  型号、尺寸、推力、服役时间等信息」，避免在缺少资料时编造内容。
- **网页结果相关性过滤**：剔除同名的无关条目。例如检索生僻型号时，
  搜索引擎可能返回同名服装品牌、游戏卡牌等内容，这类结果会被丢弃。

### 数据来源

Launch Library 2、NASA NTRS、百度百科、Bing（均为国内可直连）。

## 1.1.0

**新增航天器检索与 NASA 技术文献检索**

### 新增

- **航天器与机构检索**（`search_space_objects`）：在 Launch Library 2 中检索
  航天器、火箭型号、空间站、航天机构与宇航员，返回名称、类型、所属机构、
  系列、首飞时间、成立年份等结构化信息。
- **NASA 技术文献检索**（`search_nasa_documents`）：检索 NASA 技术报告库（NTRS）
  的技术报告与会议论文，返回标题、摘要、作者、所属研究中心与全文链接。
- **两个对话工具**：`search_space_knowledge`（回答「猎鹰九号是什么火箭」
  「国际空间站的资料」）与 `search_nasa_literature`（回答技术原理与研究资料）。

### 数据来源

Launch Library 2、NASA NTRS。

## 1.0.0

**首个版本：查询下一次太空发射**

### 功能

- **下一次太空发射**（`next_launch`）：返回下一次发射的任务名、火箭、发射服务商、
  本地时间、倒计时、发射场与任务简介。
- **即将进行的发射列表**（`upcoming_launches`）：返回未来 1–20 次发射，
  可按发射服务商、火箭型号或发射场筛选。
- **发射数据概览**（`launch_stats`）：返回即将进行的发射总数与当前接口配置。
- **两个对话工具**：`get_next_space_launch` 与 `list_upcoming_space_launches`，
  猫娘可在对话中直接回答「下一次火箭发射是什么时候」。

### 说明

- 内置响应缓存与倒计时换算，适配 Launch Library 2 的免费额度限制。
- 过滤已结束的任务，避免把刚发射完、状态尚未刷新的记录当成「下一次发射」。

### 数据来源

Launch Library 2。
