# B站全能助手（bili_viewer）

让 YUI 浏览、感知并管理哔哩哔哩的 N.E.K.O 插件：搜索视频/直播/用户，查看视频详情、弹幕、CC 字幕、AI 概要、评论，直播间信息与实时弹幕，UP主信息与投稿列表，感知用户当前正在看/用的内容（前台窗口通用感知），并支持管理自己的稿件、在直播时回复弹幕。

## 功能

| 工具 | 说明 |
|---|---|
| `bili_search` | 搜索视频 / 直播 / 用户，返回候选列表 |
| `bili_video_info` | 视频详情：标题、UP主、时长、分区、播放/弹幕/点赞/投币/收藏、分P、字幕、标签 |
| `bili_video_danmaku` | 视频弹幕文本（带时间点），了解观众反应 |
| `bili_video_subtitle` | 视频 CC 字幕逐句文本，快速通读内容 |
| `bili_video_ai_summary` | B站官方 AI 视频概要（部分视频提供） |
| `bili_video_comments` | 视频评论（热门/最新、分页） |
| `bili_live_info` | 直播间信息：标题、主播、状态、在线人数、分区、简介 |
| `bili_live_danmaku` | 直播间实时弹幕（匿名连接弹幕服务器采集数秒） |
| `bili_user_info` | UP主信息：粉丝、关注、视频数、等级、签名 |
| `bili_user_videos` | UP主的投稿视频列表 |
| `bili_now_watching` | 感知用户当前正在看/用的内容：识别前台窗口的应用/站点/页面主题；B站视频/直播页自动匹配详情 |
| `bili_my_info` | 账号信息：昵称、uid、等级、硬币、大会员（默认走独立小号，可传 account=main） |
| `bili_my_videos` | 自己账号的稿件列表（状态/播放/时长；默认走独立小号） |
| `bili_edit_video` | 修改自己稿件的标题/简介/标签（需登录态，写操作，默认走独立小号；v0.7.6 起该接口带 wbi 签名，避免 -352 风控拒绝） |
| `bili_live_send_danmaku` | 向直播间发送弹幕（直播时回复观众，需登录态，写操作；默认走独立小号） |
| `bili_reply_comment` | 给视频/直播间写评论（v0.7.0；默认走独立小号） |
| `bili_yui_dynamic` | 用独立小号发 B站文字动态（v0.7.0；每日限 6 条） |
| `bili_yui_upload` | 用独立小号投稿视频（v0.7.0；文件放插件目录 yui_uploads/，每日限 2 条） |
| `bili_yui_status` | 查询独立小号绑定状态与今日自主额度（v0.7.0） |
| `bili_accounts` | 查询大小号视图：昵称/uid/绑定时间/默认角色（v0.7.10，YUI 分清大小号） |
| `bili_set_roles` | 修改大小号归属：交换角色 / 按 uid 指定角色（v0.7.10，后期说明修改） |

## 使用示例（对 YUI 说）

- "搜一下B站：原神 4.0 剧情" → `bili_search(keyword="原神 4.0 剧情")`
- "看看 BV1xx411c7mD 这个视频" → `bili_video_info(bvid="BV1xx411c7mD")`
- "这个视频弹幕在刷什么" → `bili_video_danmaku(bvid="...")`
- "帮我总结一下这个视频" → `bili_video_ai_summary(bvid="...")`（无 AI 概要时可用字幕或简介）
- "看看评论怎么说" → `bili_video_comments(bvid="...", mode="hot")`
- "xxx 的直播间开着吗，多少人在线" → `bili_live_info(room="12345")`
- "直播间现在弹幕在说什么" → `bili_live_danmaku(room="12345", duration=8)`
- "查一下这个UP主" → `bili_user_info(mid=12345)` / `bili_user_videos(mid=12345)`
- "我现在在看什么 / 我切视频了 / 跟着我看" → `bili_now_watching()`
- "看看我的账号/我的稿件" → `bili_my_info()` / `bili_my_videos()`
- "把我的视频 BV1xx... 标题改成 XXX" → `bili_edit_video(bvid="...", title="XXX")`
- "帮我在直播间回复弹幕：谢谢大家的关注" → `bili_live_send_danmaku(room="12345", text="谢谢大家的关注")`
- "给这个视频写条评论" → `bili_reply_comment(target="BV1xx...", text="...")`
- "发条动态" / "投稿这个视频" → `bili_yui_dynamic(text="...")` / `bili_yui_upload(file="xxx.mp4", title="...")`

## YUI 独立小号（v0.7.3：后台静默运营 + 复查加固）

v0.7.3 复查加固：动态发布接口补 wbi 签名（缺失会被 B站 -403/-352 拒绝，动态发不出去的问题已修复）；小号 Cookie 文件走 mtime 缓存（后台轮询不再反复读盘）；投稿 multipart 文件名清洗（防边界破坏）；Chrome 启动失败会自动尝试 Edge；面板/绑定状态不再重复探测调试端口。

v0.7.1 起 YUI 独立小号**完全后台化**：所有自主行动与内容同步一律**静默注入**（`read` 行为），
不弹气泡、不主动开口、不打断玩家界面；行动成功不播报，仅权限/风控类无法自行解决的问题
才在下次自然对话中简短求助。可接入一个**独立 B站账号**（与你主账号完全隔离），实现：

- **同步行动**：你打开某直播间/视频时，YUI 在后台跟随到同一直播间/视频（你询问时能自然接上，不会主动播报"系统又同步"）；
- **自行行动**：你不在 B站时，YUI 自主挑选热门内容，理解内容后在后台自行决定是否发弹幕、写评论、发动态、投稿视频。

### 配置（小号凭证）

方式 A（推荐，v0.7.10 双账号绑定）：打开接入面板（bili_bind_web），用浏览器先后登录两个 B站账号——**第一个登录的账号自动成为大号（main），第二个登录的账号自动成为小号（yui，默认操作账号）**，绑定持久化到插件目录 main_cookie.txt / yui_cookie.txt，无需手动复制 Cookie。大小号归属后期可随时说明修改（bili_set_roles 交换角色）。

方式 B（手动）：小号 Cookie 保存到插件目录 `yui_cookie.txt`（需含 `SESSDATA`；写操作还需 `bili_jct`）。插件目录即 `C:\Users\jh\AppData\Local\N.E.K.O\.neko-plugin-installations\plugins\bili_viewer\`。

方式 C：设置环境变量 `BILI_YUI_COOKIE`（优先级高于文件）。

未配置小号时：写操作自动回退主账号（不影响原功能）；配置后：弹幕/评论/动态/投稿/改稿件/查看自己的稿件与账号信息默认全部走小号——未说明用哪个账号时一律默认小号（v0.7.9 统一规则），显式传 `account=main` 才用大号。

YUI 分清大小号：调用 bili_accounts 可查询大号/小号的昵称、uid、绑定时间与默认角色；bili_set_roles 可交换大小号归属（仅文件层绑定的账号可互换，环境变量优先时请手动调整）。

### 自主运营规则（防封号硬限制）

- 唤醒冷却：同一目标自主行动后 900 秒内不重复唤醒；
- 弹幕：同一目标 60 秒内限 1 条；评论：同一视频/直播间 120 秒内限 1 条；
- 动态：每日上限 6 条；投稿：每日上限 2 条（仅接受插件目录 `yui_uploads/` 内的文件）；
- 投稿分片间限速（0.15s/片），不占满玩家带宽；
- 热门拉取 60s 缓存（无跟随目标时后台不重复打 B站热门接口）；
- 风控错误（-352/-401/-412/-101）自动退避，不做重试轰炸；
- 可通过环境变量 `YUI_AUTONOMY=0` 关闭自主运营（仅保留跟随同步，且同步时也不主动行动）。

### 纪律（v0.6.40+ 延续 + v0.7.1 后台化）

- YUI 绝不主动询问"要不要发弹幕"；弹幕仅在用户明确要求或自主运营任务中发送；
- 发送/行动成功后只静默完成，不播报"我发了/搞定了"；不刷屏、不复制已有内容、不攻击；
- 后台任务不打断玩家：自主唤醒与内容同步均为 `read` 静默注入，YUI 在下次自然对话中消费执行。


## 感知当前观看（bili_now_watching + 实时同步）

- **实时同步（默认开启）**：插件后台每 2.5 秒感知一次观看内容，检测到变化（切视频/切网页/切应用）后，把"用户当前正在看/用 X"推送注入 YUI 上下文——**v0.7.1 起一律后台静默注入（read）：不触发 YUI 主动开口、不弹气泡、不打断玩家**；YUI 在下次自然对话中消费（你问"我现在在看什么"时能直接接上）。内容稳定 2 次才推、同一内容只推一次、两次推送间隔 ≥15 秒（防刷屏）。
- **多窗口感知**：枚举所有可见窗口，排除 N.E.K.O 聊天客户端自身与开发终端（Terminal/PowerShell/cmd），按"B站视频/直播 > 已知站点 > 网页 > 应用"选最可能在看的内容。切回 N.E.K.O 打字时，YUI 依然知道你后台开着哪个 B站视频。
- 推送文本标注"实时感知"，YUI 将其作为线索而非事实。
- 前台为 B站视频页时 `bili_now_watching` 自动搜索匹配并返回视频详情；直播页返回直播主题
- 可关闭实时同步：环境变量 `BILLI_SYNC_DISABLE=1` 后重启客户端
- 仅读取窗口标题与进程名（本地操作，无网络传输、不读取页面内容）
- 平台：Windows；其他平台自动停用同步

## 配置（可选）——接入你的 B站账号

插件提供三种方式接入账号，让被 B站对游客风控/拦截的接口（直播弹幕 -352 等）正常使用：

### 方式一：浏览器扩展（B站接入桥，最省心，推荐）

自 v0.6.8 起插件支持浏览器扩展直连；**v0.7.4 起按浏览器拆分为三个独立扩展包**
（扩展显示名与推送来源相互独立，可多浏览器共存互不干扰，插件日志可区分来源）：

| 扩展目录 | 适用浏览器 | 扩展显示名 |
|---|---|---|
| `browser_extension/bili-bridge-chrome` | Google Chrome | B站接入桥 (Chrome) |
| `browser_extension/bili-bridge-edge` | Microsoft Edge | B站接入桥 (Edge) |
| `browser_extension/bili-bridge-360` | 360 安全/极速浏览器 | B站接入桥 (360) |

装一次扩展，登录态自动实时同步，**彻底告别"浏览器被占用/残留进程/调试端口"等一切接入问题**：

1. 打开对应浏览器的扩展管理页（Chrome/360 为 `chrome://extensions`，Edge 为 `edge://extensions`），开启右上角"开发者模式"；
2. 点"加载已解压的扩展程序"，选择对应扩展目录：
   Chrome 选 `bili-bridge-chrome`、Edge 选 `bili-bridge-edge`、360 选 `bili-bridge-360`
   （从 GitHub Releases 下载源码 zip 解压即可找到；插件启动也会自动把三包投放到桌面
   `桌面\B站接入桥扩展`，并生成单个三扩展压缩包 `桌面\B站接入桥扩展_v版本.zip`
   内含三扩展独立文件夹+名字与三份安装脚本，双击对应浏览器的安装脚本即可自动复制+打开扩展页）；
3. 扩展图标出现即生效：它会读取 bilibili.com 的登录态并**只推送到本机 127.0.0.1 的插件面板服务**，
   登录/退出 B站时自动同步（Cookie 变化即推送 + 每分钟兜底一次）；
4. 对 YUI 说"**打开接入面板**"可随时查看扩展在线状态与绑定状态。

- 扩展仅本机通信（host_permissions 只含 `127.0.0.1:8765` 与 bilibili.com 域），Cookie 不上传任何外部网络；
- 插件优先使用扩展通道；未装扩展时自动回退到下面的 CDP 自动接入。

### 方式二：CDP 自动接入（无需手动复制、无需关闭浏览器）

新版 Chrome/Edge 已启用 App-Bound Encryption（Cookie 为 v20 加密），离线文件读不出登录态；
插件自 v0.6.0 起全面采用 **CDP 运行时接入**——通过 DevTools 协议让浏览器进程自己解密并返回 Cookie，
**绝不关闭、重启你的浏览器**，并持续监控浏览器接入状态：

1. 先在浏览器里登录一次 bilibili.com（扫码或账号密码均可）；
2. 对 YUI 说"**允许你读取浏览器 Cookie 绑定 B站账号**"——YUI 会调用 `bili_bind_account(allow=true)` 记录授权（只确认一次，永久生效）；
3. 插件启动后自动静默连接正在运行的浏览器并绑定（无需重复指令）；之后持续监控：
   浏览器接入状态（已接入/未开启接入端口/未运行）会实时更新，YUI 随时可用 `bili_bind_status` 查看；
4. 若浏览器以普通模式运行（未开启接入端口），插件会**直接尝试以调试模式启动**（不关闭你的浏览器）；
   若默认配置的浏览器正被占用、无法再开调试实例，**无需退出浏览器**——优先使用"B站接入桥"扩展通道
   （扩展随浏览器自动同步登录态），或对 YUI 说"**打开接入面板**"查看扩展通道状态、一键接入。

- 读取为本地操作：CDP 仅绑定 127.0.0.1 本机端口，Cookie 不上传、不写日志、不发给 AI；
- 若检测到浏览器未登录或登录态已过期，插件会提示你先登录 bilibili.com，登录好后再绑一次即可；
- 调试模式下的浏览器与普通浏览器完全一样（标签/书签/登录态都在），只是额外开放一个仅本机可访问的调试端口；
  日常使用照旧，插件会持续监控你的接入状态。

### 方式三：手动配置（备选）

在客户端插件管理页的 bili_viewer 配置界面填写 `bili_cookie`；
或编辑 `C:\Users\jh\AppData\Local\N.E.K.O\.neko-package-profiles\bili_viewer\default.toml`，
在文件末尾追加：

```toml
[settings]
bili_cookie = "完整Cookie字符串"
```

获取方法：浏览器登录 bilibili.com → F12 → Application（应用）→ Cookies → `https://www.bilibili.com` → 任选一条 Cookie 右键复制。
要求：读接口需含 `SESSDATA`；写接口（发弹幕/改稿件）还需 `bili_jct`。手动配置优先级高于自动读取。
插件绝不把 Cookie 写入日志或对外发送。

## 安全说明

- 读操作只访问公开内容；写操作（改稿件、发弹幕）仅限当前账号自己的内容，需登录态与用户明确确认
- 感知功能仅读取前台窗口标题与进程名（本地、无网络传输）
- 直播弹幕采集为匿名游客方式，不做刷屏/干扰；发送弹幕限长 30 字
- 网络受限或触发风控时返回明确提示，不重试轰炸
- 纯标准库实现（urllib + socket + ssl + zlib + gzip + ctypes），无第三方依赖

## 内容"看"的边界

YUI 无法解码视频画面，但可通过 **字幕 + 弹幕 + AI 概要 + 简介/评论** 充分理解视频内容与观众反应；直播通过 **直播间信息 + 实时弹幕** 掌握现场动态，并可用发送弹幕与观众互动。
