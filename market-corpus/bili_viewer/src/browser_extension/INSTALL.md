# B站接入桥（bili-bridge）扩展安装说明

让 N.E.K.O 的 bili_viewer 插件直接通过浏览器扩展拿到你的 B站登录态，
**装一次永久生效**：登录/退出 B站自动同步，不再需要关闭浏览器、不受残留进程影响。

本目录内置**三个浏览器专用扩展包**（相互独立，可多浏览器共存互不干扰）：

| 目录 | 浏览器 | 扩展显示名 | 安装脚本 |
|---|---|---|---|
| `bili-bridge-chrome` | Google Chrome | B站接入桥 (Chrome) | `一键安装B站接入桥(Chrome).bat` |
| `bili-bridge-edge` | Microsoft Edge | B站接入桥 (Edge) | `一键安装B站接入桥(Edge).bat` |
| `bili-bridge-360` | 360 安全/极速浏览器 | B站接入桥 (360) | `一键安装B站接入桥(360).bat` |

按你实际使用的浏览器选对应的包，**不要混装**：比如 Edge 只装 Edge 版，
三个版本同时装也能共存（推送 source 相互独立，插件侧可区分来源）。

## 安装（约 30 秒）

### 方式 A：一键脚本（推荐）

1. 按浏览器双击对应脚本（Chrome/Edge/360 各有一个）
2. 脚本会自动把扩展复制到 `文档\bili-bridge-扩展名` 并打开对应浏览器的扩展管理页：
   - Chrome → `chrome://extensions`
   - Edge → `edge://extensions`
   - 360 安全/极速浏览器 → `chrome://extensions`
3. 打开页面右上角「开发者模式」→ 点「加载已解压的扩展程序」→ 选择复制好的那个目录

### 方式 B：手动

1. 打开对应浏览器的扩展管理页，开启右上角「开发者模式」
2. 点「加载已解压的扩展程序」，选择本目录下对应扩展文件夹
   （Chrome 选 `bili-bridge-chrome`、Edge 选 `bili-bridge-edge`、360 选 `bili-bridge-360`）

## 验证

- 工具栏出现「🅱️ B站接入桥」图标（灰色则点一下允许）
- 对 YUI 说"**打开接入面板**"，面板显示「扩展在线」即成功
- 点击扩展图标可查看最近推送时间

## 安全说明

- 扩展仅把 B站登录态推送到**本机 127.0.0.1:8765**（bili_viewer 面板服务）
- 权限只含 bilibili.com 与 127.0.0.1，Cookie 不经过任何外部网络、不上传、不写日志

## 更新扩展

插件升级后重新双击对应浏览器的安装脚本即可覆盖更新（扩展随浏览器自动生效）。
