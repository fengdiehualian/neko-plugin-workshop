# 和猫娘一起坐火箭（KSP）

让猫娘读懂你在《坎巴拉太空计划 Kerbal Space Program》里的飞行。

**这个插件是只读的** —— 它只读数据、只给建议，不会操作你的飞船。
操纵杆始终在你手里。

---

## 它能做什么

装好之后，你可以直接对着猫娘说话：

| 你说 | 她会做什么 |
| --- | --- |
| 「我现在飞到哪了」 | 读出飞船名称、飞行阶段、海拔、速度、姿态、质量 |
| 「我入轨了吗」 | 读轨道根数，明确告诉你近点够不够高、算不算稳定轨道 |
| 「油还够吗」 | 列出燃料、氧化剂、电、单组元等资源的余量与百分比 |
| 「我锁定的是什么」 | 读出目标名称、距离、相对速度（对接时最有用） |
| 「有哪些星球」 | 列出星系里所有天体及半径、重力、大气高度 |
| 「我有哪些飞船」 | 列出存档里所有飞船的状态和位置 |
| 「船上有谁」 | 读出乘员名单、职业和等级 |

她还会**给出判断**，而不只是念数字。比如你说「我入轨了吗」，
她会告诉你：

> 绕 Kerbin 的轨道：远点 152.34 km，近点 78.50 km，离心率 0.0531，
> 倾角 28.61°，周期 40分。近点高过大气层顶，是稳定轨道。

而不是干巴巴丢一堆字段给你。

## 安装

需要**两部分**配合：

### 1. 游戏模组

从 [N.E.K.O-KSP-bridge Releases](https://github.com/LShangPiao/N.E.K.O-KSP-bridge/releases)
下载 `NekoKspBridge.dll`，放进

```
<你的 KSP 安装目录>/GameData/N.E.K.O-KSP-bridge/
```

然后重启游戏。

### 2. 本插件

在 N.E.K.O 插件中心导入安装。

### 验证装好了

浏览器打开 <http://127.0.0.1:21579/ping>，
看到 `{"ok":true,...}` 就说明模组在正常工作。

## 配置

在 N.E.K.O 的插件设置里可以改：

- **bridge_url** —— 模组监听的地址，默认 `http://127.0.0.1:21579`
- **timeout_seconds** —— 请求超时，默认 6 秒（正常是毫秒级，短一点更快报错）
- **auto_brief_enabled** —— 自动播报，默认开
- **auto_brief_interval_seconds** —— 自动播报间隔，默认 15 秒（范围 5-300）

> 改端口要改**两处**：模组侧的 `neko-ksp-bridge.ini` 和这里的 `bridge_url`。

如果你的机器较慢、或者常在大存档里玩，可以把超时调大一些 ——
KSP 在加载存档、切场景、开高倍加速时会卡顿，读数据会慢一拍。

### 自动播报：为什么它不用你开口

以前是问答式：你问一句，猫娘才去调一次工具读遥测，中间那段时间她其实
**不知道**你在飞什么。现在换成自动播报 —— 只要游戏在跑，插件就在后台按
间隔读一次 `/state`，把最新的飞船状况写进她的上下文里。

具体做法是 `push_message(ai_behavior="read")`：消息会进模型的上下文，但
**不会打断对话、不会突然插话**；等你下次开口时，她已经知道你在哪个天体、
多高、多快、还有多少燃料，可以直接接话，而不是先调一遍工具。

几个细节：

- **同键合并**（`coalesce_key`）：队列里同一时刻只保留最新一条，所以调小
  间隔不会把上下文越堆越长，只会更勤快地刷新。
- **没飞船就不说话**：停机坪、编辑器、主菜单里读不到飞船，这条播报直接
  不发，不浪费上下文。
- **断了会说一声**：本来连着、游戏突然退出了，会播报一次「读不到新的遥测
  数据」，避免模型拿旧数据当现状。从来没连上过则完全静默。
- 想退回问答式就把 `auto_brief_enabled` 关掉。

## 说明

- 桥接服务只监听 `127.0.0.1`，**不对局域网或公网开放**
- 插件**不发送任何控制指令**，不会影响你的飞船
- Kerbal Space Program 是 Squad / Private Division 开发的商业游戏，
  本项目与官方无关，属于第三方爱好者作品
