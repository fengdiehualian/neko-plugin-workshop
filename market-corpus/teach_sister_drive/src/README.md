# 教妹妹开车 · N.E.K.O 插件

v0.1.0 首个公开版本。插件面板可以检测游戏并两步安装或卸载模组；完整的猫娘语音接管目前仅支持 N.E.K.O 源码版。插件要求新版 N.E.K.O，不兼容更新前的 Steam 版。

源码版使用插件自带的启动入口启用接管。旧 Steam 版兼容层没有随包分发，插件面板也不再回退到旧版接口；源码入口只在启动的主服务进程中加载插件页面和输入适配，不修改主程序文件。

从 N.E.K.O 源码目录运行（将路径替换为实际插件位置）：

```powershell
uv run python "$env:LOCALAPPDATA\N.E.K.O\.neko-plugin-installations\plugins\teach_sister_drive\launch_backend.py"
```

前端仍正常使用 `npm start`。检测游戏时会检查源码入口是否就绪；普通启动不会误显示接管可用。

## 本地安装模组

1. 在插件管理器导入本地测试包，进入「教妹妹开车 → 面板」，点击「① 检测游戏」。
2. 正常退出游戏，点击「② 安装模组」。模组与加载器随插件附带，无需编译或额外下载。

会自动读取 Steam 游戏库，也可以手动填写游戏目录。安装前检查游戏版本与文件 SHA256，更新前备份，失败时回滚。没有验证过的游戏更新会拒绝安装。

目前支持 Windows x64《教妹妹开车 Demo》，Steam AppID `3950270`、构建 `25985066`。支持的程序集哈希见 `release/mod-catalog.json`；安装不修改原始游戏程序集和存档。

需要卸载时，正常退出游戏，在面板点击「卸载模组」。先备份并移除本插件 DLL，保留共享 BepInEx 加载器、其他模组及游戏存档。备份保存在本插件的数据目录，发布包不包含用户数据。

## 当前接管范围

源码版启动入口会加载猫娘驾驶、聊天、表情、教程剧情保护和播放回执适配。它需要 N.E.K.O 源码环境及其依赖，不能用于更新前的 Steam 安装版。

Steam 版更新并完成实机验证后再开放对应接管入口。插件不会为旧版主程序补装 SDK，也不会修改主程序文件。

## 开发与许可

源码和 C# 模组保留在本仓库。模组编译需要合法安装的游戏程序集、BepInEx 和 MSBuild；变更模组版本后需重建 DLL 并更新清单哈希。Python 测试在 N.E.K.O 源码环境执行，浏览器测试使用其 plugin-manager 的 Playwright 开发依赖。

插件不携带宿主密钥，不记录原始对话作为诊断日志。Apache-2.0，加载器来源与许可见 [NOTICE.md](NOTICE.md)。
