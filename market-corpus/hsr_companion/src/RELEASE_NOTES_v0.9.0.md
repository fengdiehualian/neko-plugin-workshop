# 星铁游戏搭子 v0.9.0 — 后台感知公开测试版

## 主要变化

- 新增独立本地后台感知助手，无需开启 N.E.K.O. 语音或视频通话；
- 助手只监听 `127.0.0.1`，只读取前台星铁窗口，原始帧默认不落盘；
- 自动观察不再把原始 JPEG 推送给 N.E.K.O.，只投递本地验证后的场景、角色和事件；
- 本地 Windows 助手随插件提供并自动启动，玩家无需另外下载；
- 助手启动失败时保留插件内兼容捕获，避免功能中断；
- 保留 0.8 的外置知识库、角色严格校验、多帧稳定、纠错隔离和事件节奏控制；
- 面板收拢为“开始陪玩”主按钮；识别纠正、备用截图和设置默认折叠。

## 仍未完成

- 当前独立助手首先负责稳定窗口捕获，角色身份仍以 RapidOCR 和数据库实体校验为主；
- 专用角色图像模型、参考头像特征索引和战斗回合分析仍需后续资源组件；
- 特殊活动、过场演出和非标准分辨率可能返回未知；
- 本版本仍为公开测试版，不能保证识别所有角色或场景。
