# v0.9.2（公开测试）

## 本地角色识别修复（尚未发布）

- 使用 windows-capture 2.0.1（MIT）接入 Windows Graphics Capture，按游戏 HWND 读取窗口画面，不包含其他桌面窗口覆盖；不隐藏或移动猫娘、不注入游戏、不保存截图。
- 修复高 DPI 下虚拟坐标与真实采集像素不一致造成右侧 HUD 被裁掉的问题；窗口边框与客户区尺寸必须明确匹配。
- 本补丁需要更新独立助手。面板显示独立游戏画面采集状态；旧助手桌面帧、黑屏、过期帧及未知裁剪几何不会被提升为可识别画面，也不回退到桌面截图。
- 助手依赖和许可证随外部组件打包，不安装到 N.E.K.O. 本体环境；本地更新保留旧助手目录供恢复。
- 完整注册表名称优先于等级后缀规则，保留“银狼LV.999”的独立身份；探索 HUD 确认后重新读取全部队伍名字，不再只保留未知页面阶段的单个名字。
- 统一查询、静默上下文和面板共用最新的角色/场景证据；查询当前角色时不再混入模型自报候选、历史档案或知识搜索命中。
- 修复静止画面等待第二帧的问题：新助手按新的原生窗口采样递增帧号；无新帧时可独立重新采集窗口，不重复计算缓存截图。
- 未知或待确认的新场景撤销上次状态；最小化、关闭游戏、停用观察、重启、采集失败或超时使当前画面证据失效，不删除玩家档案和历史纠错。仅切换聊天不清空有效观察。
- 在 OCR 完成后再次检查游戏窗口仍可用且进程未变化；最小化、关闭或失去采集时，旧分析不得重新写入当前结果。切到猫娘聊天不再触发暂停。
- 右侧数据库确认的等级角色名与左侧任务导航文字可共同识别探索 HUD，不能仅凭一个名字判定场景。
- 单独放大读取左侧任务区，避免整屏 OCR 把任务与右侧标签合成跨屏文字行后丢失位置证据；未读到任务区锚点时仍返回未知。
- 本地分析最多等待 30 秒，超时与窗口不可用分别提示；当前事实有效期按采样时间计算，不因处理较慢而延长旧画面寿命。
- “右侧角色”“右边是谁”“还有谁”等追问纳入当前画面身份查询，不使用历史档案或知识搜索补出画面人物；没有识别结果时不得承诺恢复画面后一定认出。
- 面板区分等待确认、页面未支持、未识别、暂停和结果过期；这些状态与猫娘查询结果使用同一份数据。
- 角色名证据与场景分类解耦；未知场景中的右侧 HUD 可凭完整名字加等级标记独立确认名称。
- 正确解析 `银狼LV.`、`刃Lv.80` 等等级后缀；仍拒绝正文提及、未知名字与任意模糊猜名。
- 补充外部头像模板组件：复用 StarRailOneDragon 固定提交的 72 份图像，用现有 OpenCV 做特征和几何验证；下载状态持续显示，失败不影响文字识别。
- 保留角色证据范围，文字/头像冲突时不猜测当前角色。外部头像模板不等于通用 3D 角色识别模型。
- 规则回归、合成图像验证与真实截图验收分开报告。

- 恢复常驻视觉助手状态：已下载/未下载、运行/退出、连接/未连接、游戏画面读取状态。
- 下载和安装结果持续显示；失败明确说明原因，支持重试，不误报成功。
- 修复桌面正式版使用冻结宿主可执行程序启动助手源码的问题；独立助手在插件外部安装。
- 助手不可用时继续尝试备用识别；缺少窗口组件时明确提示，而不是误报未打开游戏。
- 等待助手实际连接后才报告启动成功；连接重试与观察任务避免相互干扰。
- 助手随所属插件进程退出；重启会停止所属进程树，避免单文件助手留下旧捕获进程。
- 补齐实际战斗画面的“敌方行动中 / 我方行动中 / 剩余行动值”提示识别。
- 提供独立 Windows 助手的可复用构建脚本、校验清单、版本记录和许可证文件。
- 补齐战斗/探索角色名区域，并放大读取 HUD 小字；对话正文提到角色不再当作当前角色。
- 未知/中断帧打断多帧确认，当前角色消失后不回放限流中的旧事件。
- 角色搭话因限流延迟时，只在角色仍在当前画面且事件未过期时重试。
- 沿用战雷的当前猫娘目标选择方式，增加独立于识别的“测试搭话”及请求状态；提交不等于已回复。
- 已提交不等于消息服务正常：主动请求前检查配置的本机发布端口，没有监听时明确提示需要重启 N.E.K.O.，不再显示提交成功。
- 资料快照更新至上游 4.6.0 固定提交 dbe8cdfcfb0bf657b9fe1cf92d5537f118ccb487；保留版本、日期、来源与旧包，不自动信任任意新提交。
- 自然语言查询角色时带出对应形态、技能、星魂、命途和属性；当前资料不覆盖完整剧情或活动攻略。

角色和场景识别仍在公开测试中。助手已连接不代表当前画面一定能识别，也不代表猫娘一定已发言。
