# 星铁游戏搭子 0.9.6 使用说明

本文说明 0.9.6 开发修订；此前安装的 0.9.5 候选不会随源码修改自动更新，本修订尚未安装或发布。

打开面板后，先查看“视觉助手”的安装、运行和连接状态。桌面版首次使用需点击
“下载视觉助手”，成功后再开始陪玩；不需要开启语音或视频通话。
源码环境可用随包源码启动助手，但这不等于独立助手已经下载。

> **公开测试提示：** 当前版本仍可能漏掉角色或特殊场景。角色身份只接受数据库验证
> 的明确证据；证据不足时应返回“不确定”。

0.9.5 会短暂保留自动场景搭话的候选，通过公开 SDK 检查最近用户提问；提问、页面失效或关闭主动陪伴时取消尚未提交的候选。
这个等待不用于直接回答；已交给 N.E.K.O. 的消息无法由插件保证撤回，重复发言仍需真实聊天验收。
恢复观察只静默更新连接状态，不再额外请求欢迎。暂停先撤销当前事实，再回收后台任务；
历史记录和玩家资料保留，不应作为暂停后的当前画面回答。

## 开始使用

1. 在 N.E.K.O. 中开启“用户插件”，再打开“星铁游戏搭子”面板。只启动单个插件、不打开总开关时，猫娘仍可能收不到主动消息。
2. 首次使用点击“下载视觉助手”，等待“已下载并安装 / 正在运行 / 已连接”。
3. 点击“开始陪玩”，然后正常打开或切回《崩坏：星穹铁道》。
4. 不需要开启 N.E.K.O. 的语音通话、麦克风或视频通话。

下载中、下载失败、校验失败和安装成功都会在面板保留提示。若发布页尚未提供
独立助手包，会明确显示下载失败原因；不会把启动源码误报成下载成功。
已安装但未连接时可点击“启动视觉助手”；“资料与维护”中可刷新状态或重启助手。
重启会短暂中断观察，不是普通检查。安装、运行和连接状态始终单独显示。

后台助手会随观察功能启动；独立窗口捕获可在切到聊天等其他应用时继续，游戏最小化、
关闭或用户暂停陪玩时不能继续提供当前画面。插件只把稳定场景、
数据库确认角色和重要事件交给猫娘，原始自动观察画面默认不进入聊天，也不会保存。

## 猫娘能知道什么

当前支持剧情、战斗、探索、角色详情、队伍编成、跃迁、结算、地图任务和加载状态。
页面文字不清晰、特殊演出或证据不足时会显示“暂时无法判断”。状态经过连续帧确认，
因此可能比画面变化晚几秒，但不会用一帧过渡画面轻易覆盖可信状态。

角色识别优先读取清晰名称，并可用单独下载的头像模板补充 HUD 识别。角色名带等级后缀、
场景未知时仍可在受限 HUD 区域独立核对。文字和头像冲突时不猜测；界面角色不等于当前
操控角色或账号拥有角色。模板只覆盖已收录的头像，不能据此声称能识别任意 3D 外观。

## 主动陪伴

“主动搭话”卡片内直接开启或关闭，不必进入设置。剧情、普通菜单变化和角色识别只更新
静默上下文。进入战斗、队伍准备、跃迁或结算等重要事件时，插件可以请求猫娘简短回应。
关闭主动搭话不会停止后台识别和状态同步；已交给猫娘的消息不能保证撤回。

## 故障诊断

“一键诊断”只读取当前状态及最近查询的分段耗时，不下载、不重启、不发言，也不重新识别。
诊断完成后单独点击“复制诊断结果”，复制的是页面上带检查时间的那份快照，不会再次诊断。
复制失败可展开诊断文本手动选择。报告只包含允许的状态和计时字段，不包含原始画面、
聊天内容、游戏文字、账号或本地路径。它不能证明猫娘已经说完，也不是完整聊天延迟统计。

截图上传、角色列表导入和测试搭话按钮已从日常面板移除；已有数据和后台兼容入口不删除。
资料更新、名字纠正和使用说明折叠收纳，下载进度、失败及成功提示仍保留。

## 识别错误

在面板填写“认成了谁”和“实际是谁”。文字或语音的未知别名可以保存；如果错误名称与
正确名称都是数据库中的真实角色，只保存为需要新证据确认的歧义。视觉纠正必须绑定
当时的角色区域指纹，不会把一个角色永久全局替换为另一个角色。

## 安全边界

- 插件和助手不修改、注入或操作游戏客户端；
- 不读取游戏内存，不抓取通信，不模拟键鼠；
- 本地助手只监听 `127.0.0.1`；
- 独立助手安装在插件包之外，下载来自插件自己的发布页，安装前进行 SHA-256 校验；
- 助手故障时仅停止或降级识别，不影响 N.E.K.O. 与游戏。
