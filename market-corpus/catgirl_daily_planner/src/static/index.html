📖 猫娘使用指南 ▼

📅 计划管理

工具名功能使用场景
catgirl_planner_create_plan创建/覆盖某天的完整计划"帮我制定今天的学习计划"
catgirl_planner_add_task给某天添加一条任务"下午3点加个健身任务"
catgirl_planner_list_today查看某天/今天的完整计划"我今天有什么安排？"
catgirl_planner_delete_task删除某条任务"取消明天的早会"
catgirl_planner_clear_plan清空某天的所有任务"今天计划全取消"

✅ 任务状态管理

工具名功能使用场景
catgirl_planner_mark_done标记任务为完成/跳过/恢复"数学复习做完了"
catgirl_planner_set_task_meta修改任务的分类/优先级/描述"把那个任务改成高优先级"
💡 任务状态：done = 已完成 ✓ | skipped = 已跳过 ⊘ | pending = 待办（恢复）○

🔔 自动播报

工具名功能使用场景
catgirl_planner_trigger_morning立即触发早安播报"猫娘，给我播报今天的计划"
catgirl_planner_trigger_goodnight立即触发晚安复盘"总结一下今天完成情况"
catgirl_planner_get_schedule查看当前播报时间配置"现在几点播报？"
catgirl_planner_set_schedule修改播报时间/昵称"改成7点叫我起床"

📋 模板快速铺计划

工具名功能使用场景
catgirl_planner_list_templates查看所有内置模板"有哪些模板可以用？"
catgirl_planner_apply_template应用模板到某天"明天用工作日模板"
🎯 内置模板：workday = 工作日（朝九晚五）| weekend = 休息日（轻松安排）| study = 学习日（专注学习）| fitness = 健身日（运动为主）

🔁 重复任务规则

工具名功能使用场景
catgirl_planner_add_recurring添加按星期重复的任务"每周一三五早上8点背单词"
catgirl_planner_list_recurring查看所有重复规则"我有哪些重复任务？"
catgirl_planner_delete_recurring删除重复规则"取消每周健身"

📊 统计与打卡

工具名功能使用场景
catgirl_planner_get_stats查看月度/近期完成率"这个月完成了多少？"
catgirl_planner_get_year_overview查看年历概览"今年打卡情况如何？"
catgirl_planner_list_calendar查看某周/某月的计划"这周有什么安排？"

💬 对话示例

你：猫娘，帮我安排明天的学习计划，早上复习高数，下午写论文，晚上健身
猫娘：调用 create_plan → 自动创建3个任务并设置提醒
你：今天任务完成了吗？
猫娘：调用 list_today → 列出所有任务及状态
你：每周一三五早上8点背单词
猫娘：调用 add_recurring → 创建重复规则，每天自动铺任务到计划里
