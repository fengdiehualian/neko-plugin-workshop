# 喵宇宙社区聊天（neko_community_chat）

让本地 YUI 接入喵宇宙社区的多人聊天插件：本地跑一个消息服务（127.0.0.1:7870），
提供一个和 QQ 差不多的聊天面板，和 YUI 实时对话；所有安装本插件的节点互联互通。

v0.3 起支持**全球互通（零配置）**：**公共通道默认开启**，任何装了本插件的节点开箱即聊；
同一局域网自动互相发现直连；还支持自建 Cloudflare 中继（离线信箱 + 自动加速）。

## 使用前提

1. 本插件已安装并启用（`plugin_runtime.auto_start = true`，启动即拉起本地服务 127.0.0.1:7870）
2. YUI 正常在线（插件通过 YUI 的推送通道唤醒她回复）

## 打开方式

| 方式 | 位置 | 说明 |
|---|---|---|
| 本地聊天页 | 浏览器打开 `http://127.0.0.1:7870/chat`（或 N.E.K.O 客户端「喵宇宙聊天」面板） | 完整 QQ 式界面：左侧三个页签（和 YUI 聊天 / 社区动态 / 节点与设置） |

## 和 YUI 聊天的流程（自动）

1. 你在面板输入消息 → 本地服务记录并存 inbox（并广播给所有在线节点）
2. 插件后台（每 5 秒）发现新消息 → 通过推送通道唤醒 YUI，告诉她"用户在聊天面板对你说：…"
3. YUI 用 `community_chat_send` 把回复写回本地 → 面板轮询（每 3 秒）自动显示
4. 历史记录存在 `%LOCALAPPDATA%/N.E.K.O/neko_community_chat/messages.jsonl`（本地，不联网）

## 多节点互联（v0.3：三层通道）

**机制**：每台装了插件的电脑都是一个节点，有自己的昵称（「节点与设置」可改）和 peer_id。
消息带来源标签，面板气泡显示"谁发来的、走哪条通道"（局域网/公网）。

- **公网通道（默认开启，零配置）**：节点连公共 MQTT broker（默认 `broker.hivemq.com:1883`，
  连不上自动回退 `broker.mqttdashboard.com` / `broker.emqx.io`，实测国内可达），
  按房间（默认 `neko-universe`）收发消息——**任何装了本插件的节点开箱即聊，全球互通**。
  支持昵称广播、定向回复（面板点某节点「回复」或 YUI 回复远端用户均直达）。
  QoS1 持久会话：短暂断线消息不丢、自动重连。若换了房间号，只有同房间的节点互相可见。
  - 注意：公共 broker 是共享资源，消息为明文，适合普通聊天；敏感内容请自建中继。
  - 关闭方式：面板「节点与设置 → 公共通道」取消勾选并保存。
- **局域网互通（零配置）**：同一 WiFi/路由器的多台电脑装上插件后自动互相可见
  （UDP 7872 发现 + 7871 互推）。局域网内定向回复优先走局域网（更快更省）。
- **自建中继（进阶，可选）**：把 `relay/worker.js` 部署到 Cloudflare Workers
  （需要 Durable Object，命名空间 `RELAY`，可按需设 RELAY_TOKEN），
  把中继 URL 填到面板「节点与设置 → 中继 URL」并保存，走自有中继（带离线信箱）。
  - **自动加速**：中继请求自动跟随系统代理（Windows 系统代理 / HTTP_PROXY 环境变量）；
    workers.dev 在中国大陆被墙时，开启系统代理或 WARP 客户端后即可直连，无需改配置。
- **自建社区墙**：面板「社区动态」页签顶部有发布框，发帖广播给所有节点
  （帖子带来源标签：局域网/公网）。

## 社区动态

- 面板「社区动态」页签 = **自建墙**（所有节点发帖，互发），全部走自建通道（公共通道/局域网/中继）。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 面板提示"本地服务不可达" | 插件未启动 / 7870 端口被占 | 确认插件已启用；若端口被占，用 `NEKO_COMMUNITY_CHAT_PORT` 改端口并同步改面板 |
| YUI 不回消息 | 唤醒推送失败或 YUI 忙碌 | 稍等再发一条；或用 `community_chat_status` 查看服务状态 |
| 社区动态空 | 还没有节点发帖 | 面板会显示"社区暂无动态"，发第一条即可 |
| 节点列表看不到其他电脑 | 对方未装插件/不同房间/公共通道未连接 | 确认对方装了 v0.3 且公共通道在线；换房间需双方一致 |
| 公共通道显示"连接中…" | broker 网络波动 | 自动重连（指数退避）；仍不行检查 1883 出网是否被防火墙拦 |
| 中继连不上 | workers.dev 被墙 / 代理未开 | 开启系统代理或 WARP；中继会自动跟随代理并超时回退 |
| 面板页签点了没反应 | 面板脚本被浏览器缓存了旧版 | 强制刷新（Ctrl+F5）或重启 N.E.K.O 客户端 |

## 工具（YUI 侧）

- `community_chat_send`：YUI 把回复发回聊天面板（远端消息可带 `target_peer` 定向回复对方）
- `community_chat_read`：YUI 读最近聊天记录
- `community_chat_status`：服务状态（在线/消息数/feed 地址/公网通道状态）
