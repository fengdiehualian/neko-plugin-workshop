# 猫娘姐妹：幸存者（neko_survivors）

自带完整游戏的弹幕生存肉鸽插件。打开插件面板 → 点「开始游戏」直接玩，
进度保存在浏览器里，完全本地运行。

## 玩法

- **WASD / 方向键** 移动，武器全自动开火
- **按住左键**：所有武器瞄准鼠标方向，松开恢复自动索敌
- 收集材料 → 升级 → 三合一合成更高品质武器
- 撑过 20 波围攻；**噩梦难度藏着一个隐藏 Boss**
- 难度四档：轻松 / 普通 / 困难 / 噩梦（噩梦会变成弹幕游戏）

## 技术

- 游戏本体是纯静态 HTML/JS（Canvas + WebAudio），全部打包在 `static/game/`
- Python 壳只有插件必需的入口类，零第三方依赖
- SDK / Live2D 是可选增强：插件面板内以纯游戏模式运行，一切正常

## 开发

游戏源码在仓库 [neko-brotato](../../../../) （猫娘工作室内部），
改完游戏后运行：

```bash
node scripts/build-plugin-static.mjs   # 在游戏仓库里执行，重新导出 static/game
```

## 测试

```bash
python -m pytest tests/
```
