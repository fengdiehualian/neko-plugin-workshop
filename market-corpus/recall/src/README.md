# Recall 陪伴式记忆与复习

> **当前状态：测试阶段（Beta）**  
> 核心学习流程已经可用，界面、复习安排与词库内容仍会根据测试反馈继续调整。

Recall 是 N.E.K.O. 的陪伴式英语词汇记忆插件。用户明确想背单词时，可以直接开始学习；词库选择、学习状态和复习安排由 Recall 在幕后处理。

## Demo

![Recall v0.2 学习流程演示](./media/recall-demo.gif)

Demo 展示“开始学习 → 选择盲盒 → 认识单词 → 回忆评分”的实际流程。画面中的角色仅为演示；安装后会跟随用户当前的 N.E.K.O. 角色。

## v0.2 已支持

- 内置离线 CET-4 核心词库，包含 3800+ 词条。
- 新词学习、到期复习与遗忘后的重新学习。
- 学习进度和跨天复习状态持久保存。
- 盲盒式抽取交互，避免机械地按固定顺序背诵。
- 独立学习窗口，并复用用户当前的 N.E.K.O. 角色名称、形象和头像。
- 陪伴对话可按需展开；收起时保留角色陪伴，不遮挡主要操作。

## 使用方式

安装并启用插件后，可以从插件市场进入 Recall，也可以直接对 N.E.K.O. 说“我想背四级”或“陪我复习单词”。

打开 Recall 后点击开始，选择一个盲盒即可进入本轮学习。完成当前一盒后，可以继续认识新词；已经学过的词会在合适的时间进入复习。

## 产品边界

Recall 只处理成体系的词汇学习与复习，不接管 N.E.K.O. 原有的长期记忆。人物关系、用户偏好、日常事实以及普通的“记住这件事”仍由 N.E.K.O. 自身处理。

社区知识库、本地私有知识库和伴学插件卡片交接已经预留接口，但不属于 v0.2 的可用功能。

## 数据与来源

- 学习记录保存在 Recall 自己的插件存储中。
- 内置词库可离线使用，不需要上传用户的学习记录。
- 角色资料由 N.E.K.O. 提供，Recall 不创建独立角色设定。
- 词库来源与许可信息见 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。

## 开发与发布

此仓库对应 N.E.K.O. 中的 `plugin/plugins/recall`。发布前可在 N.E.K.O. 仓库根目录运行：

```bash
uv run python -m plugin.neko_plugin_cli check --release --market-release /path/to/n.e.k.o_plugin_recall
```

推送与 `plugin.toml` 版本一致的标签后，仓库内置的 GitHub Actions 会生成 `recall.neko-plugin` 发布附件。

Recall 在测试阶段只发布到 N.E.K.O. Market 的 `beta` 渠道；达到稳定版标准后再切换到 `stable`。
