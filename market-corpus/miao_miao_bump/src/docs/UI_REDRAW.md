# 第一部分：①上下 UI 与整页比例

2026-10-21 更新。参考为 `docs/art/battle-ui-scoreboard-concept.png`，1672×941。运行版本仍为0.1.0.dev9，只保存在本机，未提交或推送GitHub。

## 本轮修正

此前UI将上下栏宽度绑定到实际水池，导致示例尺寸下上下栏只有约1074px宽，底栏80px高，头像约63px；局部图各自放大后看似接近，整页却明显失衡。该次比例验收不成立。本轮改为从完整参考画面统一缩放，再按原始像素尺度比整页、上栏、底栏和半透明叠图。

| 区域 | 1672×941基准位置 | 设计大小 |
| --- | --- | --- |
| 顶部记分牌 | x150，y46 | 1372×162 |
| 水池显示区 | x96，y212 | 1480×600 |
| 底栏 | x48，y826 | 1576×110 |
| 顶部猫头框 | 阵营区内 | 96×96 |
| 底栏猫头 | x84，y834 | 94×94 |

桌面整页采用同一缩放单位，分别保留这三种宽度和原图的主次关系；高窄或矮宽窗口将完整构图居中。741px以下使用独立紧凑排布，不将宽底栏硬压成窄长花边。底栏恢复30px名字、23px属性、27px中央提示及60px高按钮（均为设计尺寸）。底栏花饰用九切片保护端部。小屏和长语言另外分配文字空间；练习模式为较长的“重置水池”文案留空间。

水池通过地图配置改为1200×486宽池，出生点、复归区域、练习布局和真实池壁同步调整；角色和指针仍等比显示。未改变基础物理参数或战斗规则，但长宽变化会影响行进距离和路线。接口仍支持其他长宽比地图，见 [地图接口](MAPS.md)。

## 保留的交互与范围

- 头像／比分／轮次／HP实时更新；行动后彩色加勾，淘汰待复归才灰色加叉。
- 对手显示名林悠怡，仍使用本机电脑逻辑；未接入猫娘模型。
- 声音、设置、重开保持底栏入口；底部头像打开角色，模式与练习布局在设置中。
- 四项统计保持删除。Dark Reader页面保护声明、国际化和资源回退逻辑保留。
- 猫猫和水面素材本轮未替换，外形与水纹仍待后两部分；击飞／入水动画优化仍留下一版本。

## 验证与证据

最新自然开局见 `docs/art/battle-ui-v2.png`；同状态完整原图、三组对照、叠图、窗口测量与实机交互截图在 `tests/artifacts/ui-proportions/`（本机忽略目录）。原始整页和局部比较统一像素尺度，不把实现单独放大到参考宽度。具体尺寸和检查结果见根目录 `design-qa.md`。

47项现有Node检查通过，包括宽池出手、两种地图整局电脑对战、行动次数、碰撞伤害、积分和复归。CUA实际拖拽验证玩家出手、电脑回应、换猫与彩色勾；设置、练习布局、角色弹窗和重开已操作。九种窗口无整页滚动、操作越界或横向文字溢出；对战八种语言分别在桌面与手机检查，另检查练习较长按钮文案。

这次完成的是整页比例与UI排布修正，不等于整张概念场景已全部复刻，也不代替用户的观感判断或正式版本验收。
