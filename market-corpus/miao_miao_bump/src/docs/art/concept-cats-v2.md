# 概念图风格猫猫：首版实装

2026-10-21。用户授权进入猫猫美术部分，按①概念图中的模样还原，同时明确要求保留旧素材备用。当前为第一轮实装，仍待用户观感反馈；不是美术定稿。

## 参考与角色

主要参考 `battle-ui-scoreboard-concept.png` 内水池角色的圆脸、大头短身、眼睛和泳圈承托姿势；`character-concepts.png` 用于保持各自身份，未把概念图里的角色换成其他猫娘。

| 角色 | 保留内容 |
| --- | --- |
| 橘子 | 橘色短发与虎斑、琥珀眼、白花绿叶、头顶小橘猫、橘瓣泳圈 |
| 布丁 | 奶油／深棕重点色、双团子、蓝眼、小布丁配饰、头顶暹罗小猫、焦糖布丁泳圈 |
| 奶盖 | 奶白蓬松长发、灰蓝耳尖、蓝眼、淡紫蝴蝶结与花饰、头顶蓝双色布偶、淡紫泳圈 |

每人均有待机、受撞、回弹三帧。手搭在泳圈前沿，前沿遮住腰部，下半身不露出；尾巴主要藏在背后，没有从泳圈前沿长出。像素采样后保留方块边缘，未给素材加模糊滤镜。

## 文件与切换

新版默认文件位于 `static/assets/characters/concept-v2/`：

- `juzi-expressions.png` 与 `juzi.json`；生成源 `exec-31c9a5a5-4b34-45d5-88f5-0b5e1d889eeb.png`，2008×783。
- `pudding-expressions.png` 与 `pudding.json`；生成源 `exec-9f29e72b-ed23-4e9d-a92d-5bbb02527aca.png`，2032×774。
- `milkcap-expressions.png` 与 `milkcap.json`；生成源 `exec-41061e7b-c9f4-4339-acee-f08ad68c8739.png`，2005×784。

三张PNG由内置imagegen生成，带真实alpha，原样复制进项目。没有在磁盘上另做抠图、滤色、缩放或覆盖旧图；不同帧裁切由JSON声明，渲染时在canvas采样与硬化alpha，和原资源管线一致。完整逐张提示词保存在 [提示词记录](concept-cats-v2-prompts.json)。原生成图保留在工具默认生成目录。

旧版 `static/assets/{juzi,pudding,milkcap}.json` 和三张同名 `*-expressions.png` 原位保留，六个文件逐字节未变；校验值见 [旧文件校验记录](classic-assets-sha256.json)。URL加 `art=classic` 使用旧版，例如 `static/index.html?locale=zh-CN&art=classic`。不加该参数默认概念图v2。新版某人载入失败时仅该角色自动回退旧版；两套都失败则交回已有占位泳圈路径，不阻断其他角色。

## 渲染接口

新版图集已经包含泳圈，元数据声明 `integratedFloat: true`，实际水池、角色预览和飞出渲染均不会再叠一只程序泳圈。经典素材继续沿用原角色／泳圈分层，不能把整合图直接覆盖旧的角色PNG。

三人分别使用80×90、80×92、88×92游戏网格，源图采样比例近似一致；绘制框和泳圈中心按每人独立标定。新版头像使用独立正方形取景与64×64画布，头顶小猫与人脸都包含在内。名字、血条从元数据读取相对位置，跟随更紧凑的轮廓；角色预览按完整精灵边界等比适配。

泳圈是斜俯视椭圆的美术表现，基础碰撞仍为半径40的圆形，水平外径按80逻辑单位标定。没有把美术透视改成椭圆物理，也未修改攻击、血量、质量、技能、回合、地图或电脑规则。受撞切帧与有界挤压作用于完整新精灵，旧版仍走原分层反馈。
