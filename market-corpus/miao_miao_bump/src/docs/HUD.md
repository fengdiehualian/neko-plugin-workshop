# 第四阶段：猫头记分牌

0.1.0.dev9 本地开发，按用户选定的①顶部记分牌方向实现。本阶段不提交或推送 GitHub，版本集中整理时再按用户授权上传。

## 可见布局

顶部独立记分牌：左侧我方三只猫头与比分，右侧电脑三只猫头与比分，中间显示轮次、当前行动方、目标分。浅青／粉色队伍徽章带爪印与阵营文字，不只依赖颜色辨认敌我；水中角色仍保留 ◆／● 标识。

水池仍按地图配置和窗口剩余宽高等比显示，头像不压在水面上；底栏集中选中猫头像、名字、血量、攻击、被动，以及角色与表情、声音、设置和重开。小屏缩排，不要求滚动页面；极窄窗口将中央状态放到两队上方。

保留用户已确认的猫猫、泳圈与夏日水池资源，不把概念图整张贴成游戏背景，也不增加概念图中未实现的场景机关。比分、状态和角色选择均是实际可交互界面。

## 头像状态

| 对局状态 | 头像表现与操作 |
| --- | --- |
| 本轮尚可主动出手 | 彩色，名字可见；我方停稳且轮到我方时可点击或键盘选择 |
| 当前选中／正在发射的猫 | 明亮阵营边框，与底栏角色信息一致 |
| 本轮已行动 | 头像与名字保持彩色原样，只加绿色勾；无法重复主动出手 |
| 被淘汰、等待下一轮复归 | 灰色、叉号与“待复归”，和已行动区分；不允许选择 |
| 下一轮／合法复归 | 状态直接读取真实角色，恢复彩色与主动机会 |

水中存活猫保持彩色，继续传递运动、参与本方伤害。仅点击头像或取消瞄准不消耗机会。电脑头像展示真实状态，不能被玩家主动选中发射。

头像的完整可访问名称包含阵营、角色、本轮状态和当前／最大血量。原生按钮支持键盘选择和可见焦点；不可用状态使用原生 disabled，灰色不作为唯一信息。比分保留可访问文本，行动方变更由状态区域提示。

## 资源与地图边界

`MiaoArt.load().drawPortrait(context)` 复用角色待机帧的 48 × 56 游戏网格，默认取顶部 48 × 48，保留头顶小猫与猫娘脸部，最近邻绘制。替换素材可使用 `portraitBox` 调整网格内头像取景，不修改物理半径或战斗数据。

头像缺失时独立回退为角色名，不妨碍其他头像、选人或整局。记分牌为公共界面，不依赖夏日地图图片，已兼容方形测试地图；练习模式隐藏两队头像和比分，仅显示紧凑状态。

## 验证入口

`tests/scoreboard_browser_checks.py` 使用真实按钮、键盘、拖拽和只在测试响应内暴露的 Match 场景，检查选人、彩色加勾、叉号、复归、重开、语言、布局与资源失败。受控帧时钟在调整窗口后显式绘制一帧，避免把清空后尚未重绘的画布当作最终截图。

实际布局截图与报告保留在本机忽略目录 `tests/artifacts/`，视觉对照见项目根目录 [design-qa.md](../design-qa.md)。最终版本发布验收、人工试玩与平衡确认仍在下一阶段完成。

本次检查：记分牌专用浏览器检查通过，覆盖 12 种窗口、八种语言；原完整对战、轮次、练习与方形地图检查通过。宿主 pytest 8 项（包含 47 项共享规则）与固定 Ruff 通过；严格插件检查 0 错误，仅提示阶段改动尚在本地。实际 IAB 选人和重开已核对，无 error／warn 日志。

## 2026-10-20 试玩修正

用户反馈灰头像容易被理解为淘汰。已行动改为保留原头像颜色、边框和角色名，仅添加勾；行动机会仍正常消耗。灰度与叉号仅用于被淘汰待复归的角色。

用户同时指出实装与概念图的可爱程度有明显差距：目前接齐了功能与信息布局，整体框饰、字体、按钮、视觉密度和像素美术风格尚未充分还原。这是仍待完善的视觉工作，不能将功能／布局验证通过当成风格还原已获认可。本次先完成行动标记修正，未扩展重做整套美术，也未推送 GitHub。

## 2026-10-20 视觉还原迭代

按①补入独立的沙滩外围背景和奶油色花朵九切片边框，替换灰白网页底色与普通面板；标题改为描边游戏字，两队加入青／粉爪印徽章，放大比分并统一头像框、状态胶囊、选中角色卡和图标按钮。头像、比分、轮次、底栏均是可操作、可更新的真实界面。

记分牌和底栏跟随实际水池宽度，短窗口保留能容纳六头像的最小宽度；水池保持地图原始比例，不拉伸物理空间。小屏重新排布队伍和底栏，地图与全部操作留在一屏。选中角色资料分行并预留空间，瞄准提示使用简短译文和固定高度，避免点击／拖拽时提示换行挤动水池。

已行动仍保持彩色头像、角色名及绿色勾；淘汰待复归才灰色加叉。此次只改视觉及与其关联的布局稳定性，击飞与入水表现继续留待下一版本打磨。素材、许可和替换入口见 [界面皮肤素材](art/ui-skin-prompts.md)，实际对照及剩余差异见 [视觉检查](../design-qa.md)。仅本地修改，未提交或推送 GitHub。
