# 两侧 UI 与水池比例

2026-10-21，用户选定第三版轻量两侧布局，并确认左侧增加血量条后授权接入。当前仍为本机 `0.1.0.dev9`，未提交或推送 GitHub。

## 采用的布局

- 移除整条底栏。左侧放选中猫猫的头像、名字、HP数字与薄荷绿血条、攻击、技能和拖拽提示。
- 右侧声音、设置、重开为独立圆形按钮，沿用真实功能。头像继续打开角色与表情弹窗。
- 顶部保留双方猫头、比分与轮次；已行动保持彩色加勾，淘汰规则不变。名字与比分各有内部留白。
- 以1920×960网页可用区域作为桌面基准，模拟常见1920×1080显示器的浏览器最大化窗口，不以内置浏览器窄侧栏决定比例。其他桌面尺寸等比缩放；窄竖屏采用紧凑的无边框信息区与侧排按钮。
- 清空两侧控件背后的繁杂躺椅／饮品，仅作为阅读衬底调整；原背景、旧底栏、旧猫猫素材全部保留。

确认图：[第三版＋血条](art/side-hud-concept-v1.png)。实机：[完整桌面画面](art/side-hud-implemented-v1.png)。确认稿用于布局与信息关系；没有在本轮重新绘制猫猫或升级水面纹理。

## 比例与地图

当前夏日水池为1200×636逻辑单位，实际水面边界left36、top36、right1164、bottom600，即1128×564，宽高比2∶1。出生点、复归区域和练习位置同步调整，仍由同一地图配置驱动瞄准、碰撞、电脑和指针换算。其他长宽比地图继续在显示槽内等比适配，不将圆圈拉成椭圆。

开局阵型已修正为左右镜像的三行：橘子在上、布丁居中稍靠前、奶盖在下。我方为(270,200)、(400,350)、(270,500)，对方为(930,200)、(800,350)、(930,500)。重开恢复这套阵型；复归仍优先使用对应出生点，位置被占用时沿用现有的最近合法位置规则。实机见[阵型修正版](art/formation-implemented-v1.png)。

泳圈半径40、水阻、弹性、速度、质量、技能和回合规则不变。场地纵深改变会改变路线与撞墙次数：原浅角度参考出手在新场地撞墙一次，两个斜向参考出手均至少三次，最后自然停稳；没有为保持旧次数调整物理参数。旧1200×486宽池保留为`tests/fixtures/wide-pool.json`，旧960×600参考也继续校验。

## 替换入口

- `static/layout.css`管理新版布局，旧皮肤素材保留。
- `static/maps.js`管理物理地图大小、边界与出生点。
- `static/assets/ui/side-surfaces.json`管理侧栏胶囊与圆按钮的源图裁切区域；运行时取样使用，不覆盖原PNG。缺失时仍可使用基本控件背景。
- 三套猫猫继续通过现有角色元数据替换，`art=classic`仍可切回旧素材。

新增底片与背景由内置ImageGen生成，提示词及来源记录见[资源提示词](art/side-hud-assets-prompts.json)。攻击与血量图标使用现有Lucide／Font Awesome图标体系及原许可证。

## 验证

- 48项Node物理、战斗、地图、轮次与积分检查通过，含新水池斜向反弹和历史宽池回归。
- 10项Python素材／宿主路由检查通过；旧六个角色文件哈希未变。Windows受限环境的异步事件循环无法初始化套接字，停止该次检查后在普通本机环境重跑通过。
- 浏览器按1920×960、1536×824、1366×650、1280×720、844×390、390×844、320×568核对；页面无滚动，检查对象无横向溢出。日文、葡萄牙文长猫名发现溢出后已缩小，定向复查通过。
- 八语言布局、角色切换、真实猫头拖拽发射、电脑回应、彩色行动勾、声音开关、设置、练习模式和重开均已检查；真实扣血后的HP数字／条形进度一致。
- 浏览器核对使用CUA本地Chromium预览；Edge自动查看接口不可用，因此没有宣称直接验证了Edge或Dark Reader扩展本身。

本机证据在忽略目录`tests/artifacts/side-hud/`。同尺度整屏与局部对比结论见根目录`design-qa.md`。测试通过不代替用户对美感与手感的反馈；水面、角色重绘和淘汰动画精修不在本轮范围内。
