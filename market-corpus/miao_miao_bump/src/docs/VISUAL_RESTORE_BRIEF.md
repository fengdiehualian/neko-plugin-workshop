# 视觉还原与对手身份：最新确认

2026-10-20，依据用户再次提供的①概念图：`docs/art/battle-ui-scoreboard-concept.png`。最初只记录美术与接管要求并修改名字；随后用户明确分成 UI、猫猫、水面三部分，授权先重绘 UI。当前上下 UI 已接入一轮重绘，猫猫和水面继续保持现有资源。

## 还原的重点

1. **顶部 UI**：还原参考的整体框体、两队头像框、阵营徽章、比分、中央轮次与行动提示，以及它们的比例、间距、字重和像素装饰。不能用一套“颜色相近”的新框代替原设计。
2. **底部 UI**：还原参考中的选中猫头像、名字、血量／攻击／技能信息、中央拖拽提示和右侧声音／设置／重开，保持统一的线条、奶油色底板和信息密度。真实数据与按钮继续独立可交互。
3. **猫猫的画法**：继续是橘子、布丁、奶盖及各自原型猫、头顶小猫、发型、配色和配饰。按概念图重画其头身比、圆脸与五官比例、线条粗细、像素密度、角色与泳圈的比例及浮水姿态；目标是概念图那种模样，而不是换成另外三只猫，也不是仅放大当前精灵。
4. **水面质感**：允许重新制作，不要求从概念图抠水面。目标是通透、有深浅层次、自然焦散与碎光、柔和涟漪和角色接水关系，避免当前平铺水纹与大块重复亮线的廉价感。画面仍需符合像素风，不能靠模糊滤镜掩盖问题。

外围沙滩、花、棕榈和躺椅不是此次复刻的核心。后续优先完善上／下 UI、三只猫的画法和水面，不将工作扩成拆完每件外围装饰。

## 已确认的状态规则继续有效

- 参考图里已行动头像的灰色表现由用户之前的决定覆盖：保持彩色头像与角色名，只加勾。
- 灰度与叉号用于淘汰待复归；选中角色高亮，状态读取真实比赛。
- 设置和操作位于下方，完整地图与必要操作同屏可见；不恢复已删除的四项统计。
- 击飞和完整入水动画的优化仍留下一版本。静态浮水姿态可以随角色美术重画，与完整入水动画是两项工作。
- 地图／角色资源可替换，视觉改动不自行改变伤害、技能、出手机会或胜负规则。

## 对手名字与未来猫娘接管

用户要求对方使用猫娘名字。当前 N.E.K.O 角色配置的“当前猫娘”为 **林悠怡**，因此本轮游戏中的“电脑／CPU”队名、行动提示、说明、胜负文案与可访问名称统一显示林悠怡。

名字集中在各语言包的 `opponent.name`；有关对手的文案使用 `{opponent}`，由现有国际化层替换，避免在每句文案里写死名字。今后换显示名或界面时可单独调整。

此次只读取本机当前名字作为开发时命名依据，并保存为游戏显示文案；没有新增运行时宿主配置读取、模型请求、聊天、角色控制或陪玩接入。当前仍是原来的本机电脑选线、发射与回合流程，显示名不代表猫娘已经控制游戏。

以后计划由猫娘接管对方，届时可修改队伍身份和 UI，将猫娘控制与对局规则分开；具体控制协议、动作来源和交互另行设计。本轮不提前实现。
