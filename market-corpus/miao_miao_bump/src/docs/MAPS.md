## 当前接口

`static/maps.js` 提供浏览器的 `MiaoMaps` 和 Node 的同一模块。默认地图标识为 `summer-pool`。

- `register(definition)`：校验、复制并冻结配置，注册稳定标识；重复标识或无效配置明确报错，不留部分注册状态。
- `get(idOrDefinition)`：获取注册地图或校验完整定义；无参数返回默认地图。未知标识返回默认地图。
- `resolve(id)`：返回 `{ map, fallback, requestedId }`，供界面提示未知地图回退。
- `list()`：取得正式注册地图。返回的新列表不允许改变内部注册表。

要添加同类矩形地图，在游戏启动前调用 `MiaoMaps.register(...)`，然后通过页面参数 `map=地图标识` 开局。默认进入夏日水池。当前只有一张正式地图，因此不额外添加只有一个选项的地图选择器；以后增加正式地图时，再把注册表接入开局设置，不能在运动中直接热换。

配置字段：

| 字段 | 当前约定 |
| --- | --- |
| `schemaVersion` | 当前为 1 |
| `id`、`nameKey` | 稳定标识、插件国际化名称键；新增正式名称同步八种语言 |
| `art` | `{ metadata: 'assets/某地图.json' }`，本插件内的相对路径；也可为 null，使用程序绘制 |
| `world` | 逻辑宽高和水面 `bounds`；半径固定 40，不由图片驱动 |
| `spawns` | 两组各三个 `{ x, y }`，顺序对应橘子、布丁、奶盖；不在地图中配置攻击和血量 |
| `spawnRegions` | 双方合法出生／未来复归中心区域，边界至少距离池壁一个半径 |
| `practiceLayouts` | 可选的 free／wall／duel／chain／corner；省略时按场地生成并校验 |
| `colliders`、`mechanics` | 扩展字段，目前必须为空数组；非空明确拒绝，静态障碍物与机关尚未实现 |

完整的第二份配置见 [方形测试场地](../tests/fixtures/square-map.json)。它只由测试注入，不出现在正式地图注册表。新地图必须有合法的六个出生点，不能穿墙、重叠或落在己方出生区域之外；练习布局也要通过同样的碰撞范围检查。

## 数据如何使用

- `PoolWorld({ map })` 根据当前地图建立四面池壁与练习布局；`Match({ map })` 从地图生成双方出生阵容。
- `firstContact(..., map)` 的瞄准边界与电脑的直射／反射选线读取同一场地，不能依赖默认夏日坐标。
- `MiaoArt.loadPool(map)` 从配置加载贴图，池沿分区对齐真实水面；备用绘制也使用同一地图。
- 游戏按当前逻辑宽高换算鼠标／触摸坐标及画布比例。重开和切换练习保留地图。
- 物理模块保留 WIDTH／HEIGHT／BOUNDS／LAYOUTS 作为旧接口的默认地图别名；新调用必须读取实例的 `map.world`。运行中的场地不通过修改这些别名切换。

页面选择未知标识时给出国际化回退提示。只缺失图片、元数据或图片元数据不合法时，使用备用画面，但继续保留所选地图的有效边界和出生点。所有资源在开始游戏前完成载入，不允许边绘制旧图边建立新物理。

以后实现复归时，直接使用本接口的 spawns／spawnRegions；当前位置占用检查和复归时机仍由对战规则实现，本阶段没有提前加入复归功能。

## 本阶段验证

- 32 项 Node 检查通过，含原有物理／战斗规则和 6 项地图检查。
- 改造前记录的撞墙、连撞、自由布局参考出手，其碰撞次数、停稳时间与最终位置保持一致。
- 8 项插件 Python 检查通过，覆盖新增地图脚本的宿主资源路由。
- 原练习浏览器检查通过：参考连撞 7 次、约 5.879 秒，八种语言／窗口、鼠标、触摸、暂停、清理和资源回退正常。
- 原对战浏览器检查通过：9 次玩家出手、总第 17 次行动获胜，结果重开恢复完整六人。
- 方形场地的真实浏览器检查通过：800 × 800 逻辑画面、不同池壁／出生点、猫头点击、电脑换边、练习撞墙、八种窗口及真实触摸。未知地图回退覆盖八种语言和手机窗口。
- 方形场地的图片／元数据缺失以及元数据损坏时，备用画面保持方形碰撞数据，三位角色继续正常游玩。

浏览器报告和截图保存在本机 `tests/artifacts/`，不作为正式地图资源或美术定稿。当前检查仍以 Chromium 为主。

## 2026-10-21：示例图宽池比例

夏日水池逻辑尺寸由960×600调整为1200×486，水面边界为 left36、top36、right1164、bottom450。出生点、复归区域和练习布局同步写入同一地图配置；瞄准、电脑、指针换算、碰撞和绘制继续读取这份配置。界面基准中的1480×600显示区与它等比匹配，没有将圆形碰撞体压成椭圆。其他比例地图仍通过原接口缩放到显示区内。

水阻、池壁／泳圈弹性、发射速度、质量和半径均未调整。场地长宽改变会改变撞墙距离、路线和一发内的碰撞次数，不能宣称新地图每一发都与旧场地相同；版本收尾仍需实际手感反馈。原960×600参考出手保留为测试内的历史地图配置，继续逐项核对旧碰撞次数、时间、终点。新增宽池的浅角度／斜向出手检查分别至少反弹2／3次并自然停稳，另有两种地图的整局电脑对战检查。
