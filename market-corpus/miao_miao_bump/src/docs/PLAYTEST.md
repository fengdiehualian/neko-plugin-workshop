# 0.1.0 试玩与验证记录

当前版本：`0.1.0.dev8`。默认本机 3 对 3 按当前行动阵营结算新碰撞伤害；静止队友和慢速补刀也可触发。攻击、血量、三种被动、电脑出手、回合与胜负重开保留，自由练习仍无伤害。详见 [对战规则与验证](BATTLE_DEV7.md)。

## 打开方式

### N.E.K.O 插件界面

将仓库放在 `plugin/plugins/miao_miao_bump/`，刷新插件管理器列表，进入「喵喵碰碰大作战」面板。启动插件后也会提供「打开碰撞练习场」入口。

游戏使用公开 SDK 注册静态资源；面板不需要后端动作权限。相关资源与翻译路由已通过宿主路由集成测试；用户当前主程序中的最终显示仍应按上述步骤实机确认。

### 独立本机预览

在 N.E.K.O 仓库根目录运行：

```bash
uv run python -m http.server 48921 --bind 127.0.0.1 --directory plugin/plugins/miao_miao_bump
```

打开 `http://127.0.0.1:48921/static/index.html?locale=zh-CN`。停止服务后本机链接失效。

启动目录应是整个插件目录，才能同时读取 `static/` 与 `i18n/`；直接双击 HTML 不支持加载语言文件。

## 默认对战

◆ 为我方，● 为电脑；双方同时通过蓝／粉血条区分。玩家先手，拖拽己方猫猫发射，全场停稳后电脑出手。撞击过程中查看血条、伤害数字与减伤提示，底栏查看角色血量、攻击和被动，角色弹窗查看完整说明。敌方全员败退获胜，己方全员败退失败；重开恢复完整六人。

我方行动时，敌人碰到任意我方猫猫就按她的攻击力扣血，即使她静止或没被选中；电脑行动时反过来。同阵营不互伤，持续贴住不连扣，分开后再碰可以再次扣血。新接触没有速度门槛。

对战固定使用默认物理参数与角色被动。想调手感时切换「自由练习」，模式切换会结束旧的一发，练习设置不会带入对战。音效可通过水池下方按钮关闭。

## 自由练习

1. 按住一个泳圈，向后拖拽。
2. 看方向箭头和首次接触位置，松手发射；拖拽距离决定强弱，不显示力度条或数值。
3. 等泳圈全部停稳，再发射任意一只。
4. Esc、右键可以取消瞄准；重置可以立即结束当前出手。
5. 切换固定布局，或在「调整手感」里改变参数。移动中暂时锁定调参。

瞄准线只提示方向与首次接触，不保证低力度能抵达该位置。先碰到池壁时，额外提示一小段反射方向，不预演后续连锁。

## 第二步：三只猫的暂用像素样稿

- `dev5` 补齐布丁（重点色暹罗猫）与奶盖（蓝双色布偶猫）：均有头顶小猫、待机／受撞／回弹三帧，与橘子采用相同绘制网格和尺寸。各自 PNG、JSON 独立，可替换。
- `dev6` 补齐夏日水池像素地图：橘黄／奶油／淡紫池沿、猫爪印与花叶角饰。池沿对齐原来的物理边界；地图图片或配置失效时，退回原练习水池。两种失败路径、角色显示、八种视口与触摸发射均通过浏览器检查，连锁参考出手仍为 7 次碰撞、5.879 秒。
- 三人的头部都可点击选择；表情弹窗随所选角色切换。单个图片失效仅该角色回退，另外两只照常显示；全部失效也能继续发射。
- 2026-10-20 验证：8 项插件测试通过；浏览器确认三人九个表情、头部选择、实际撞击切帧、八种视口无页面滚动、触摸发射及单张／全部图片失效回退。连锁参考出手仍为 7 次碰撞、5.879 秒；无页面错误或外部资源请求。

- 头顶小橘猫、橘色短发、花叶配饰和条纹尾巴。试玩反馈后改为 48 × 56 游戏像素网格、最近邻采样与透明边缘硬化，再按 2 倍绘制到 96 × 112；角色移动对齐像素网格。
- 撞击后短暂切到受撞表情，再回弹、恢复待机。泳圈沿接触方向挤压，幅度随撞击强弱变化；两只泳圈都会有反馈。
- 水池在窗口剩余宽高内等比缩放，完整地图、重开和底栏无需页面滚动即可看到。底栏提供玩法、练习布局、当前角色和弹窗入口；四项统计已在 dev7 移除。
- 三种表情通过底栏「表情预览」独立查看，不改变水池内的运动；详细参数通过「调整手感」打开，关闭或按 Esc 返回。弹窗不改变地图大小和页面高度，矮屏幕中的长设置内容在弹窗内滚动。
- 橘子的可见头部也可点击发射；头发和配饰不参与物理碰撞。「调整手感」可显示真正的泳圈碰撞圆。
- 泳圈半径由 28 扩大为 40，画面与碰撞范围同步放大，墙角测试布局同步留出间距。质量、水阻、弹性与最大发射速度沿用原值；接触位置与参考出手结果会随半径变化。减少动态效果偏好会关闭挤压与晃动，保留表情提示。
- 图片加载失败时回退为占位泳圈，练习仍可继续。资源与生成提示见 [美术说明](art/README.md)。

## 自由练习默认参数

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 场地 | 960 × 600 逻辑像素 | 显示缩放不改变物理尺寸 |
| 水面边界 | x：44～916，y：44～556 | 泳圈中心还需向内留出自身半径 |
| 泳圈半径 | 40 | 与放大后的泳圈外缘基本对应 |
| 三只质量 | 各 1 | 初始没有角色技能差异 |
| 水阻 | 0.80 /秒 | 速度按时间指数衰减 |
| 泳圈弹性 | 0.94 | 泳圈之间的反弹程度 |
| 池壁弹性 | 0.90 | 独立于泳圈弹性调节 |
| 最大发射速度 | 1600 逻辑像素/秒 | 向后拖 180 逻辑像素达到最大力度 |
| 拖拽死区 | 6 逻辑像素 | 避免轻点误发射 |
| 物理步长 | 1/240 秒 | 与显示帧率分离 |
| 停稳判定 | 全场速度低于 12，持续 0.22 秒 | 消除最后的低速微动 |

无碰撞次数上限。明显碰撞计数过滤了低速贴靠和短时间接触抖动，不代表每次物理接触都会计数。

## 参考出手

三圈连撞布局，选橘子，水平向右发射。默认参数下的定向模拟：

| 初始速度 | 明显碰撞次数 | 停稳时间 |
| --- | ---: | ---: |
| 800 | 5 | 约 4.421 秒 |
| 1100 | 5 | 约 3.642 秒 |
| 1600 | 7 | 约 5.879 秒 |

放大泳圈后，真实浏览器用鼠标拉满向右发射的结果：7 次明显碰撞，约 5.879 秒停稳。后续调参时可以用这条路线作对照；碰撞次数并不是越多越好，仍需检查方向是否清楚、等待是否舒服。

## 当前限制与反馈重点

- 自动浏览器检查使用 Chromium；其他浏览器尚未逐一验证。
- 手机支持基础触摸，但小屏幕中的泳圈较小，当前以桌面试玩为主。
- 不模拟真实水流或软体变形；泳圈采用圆形刚体。
- 页面内参数刷新即恢复默认，不提供存档。
- 瞄准提示不包含水阻下的精确停止点。

本轮重点反馈：伤害与回合是否看得明白，血条是否显眼，三种被动是否有感觉，电脑难度与一局时长是否合适。原地图大小和美术辨识度仍可继续反馈，精修不阻塞玩法。
