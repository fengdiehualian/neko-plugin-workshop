# 喵喵碰碰大作战 v0.1.0

猫娘套泳圈，小猫满池弹。首个正式版本带来完整的本机三对三泳圈碰撞对战。

## 本版内容

- 橘子、布丁、奶盖三位像素猫娘，各自拥有血量、攻击与被动。
- 拖拽弹射、队友连撞、池壁反弹和水阻自然停稳。
- 每猫每轮一次主动出手，击退计分，下一轮满血复归，先得 5 分获胜。
- 夏日泳池、像素三表情、顶部猫头记分牌与两侧操作区。
- 自由练习、参数调整、音效开关及八种语言。

后续计划接入 N.E.K.O 的猫娘，让猫娘作为对手参与对战。本版先使用本机电脑逻辑，不调用模型，也不需要额外账号或外部网络服务。

## 下载与安装

下载本次 Release 附件中的 [**miao_miao_bump.neko-plugin**](https://github.com/WhiteFrostune/n.e.k.o_plugin_miao_miao_bump/releases/download/v0.1.0/miao_miao_bump.neko-plugin)，通过 N.E.K.O 插件管理器导入，刷新列表并启动游戏。

`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。GitHub 自动生成的 Source code 压缩包是源码，不是可直接导入的插件包。

## 验证与已知限制

已完成自然开局到第七轮 4∶5 的完整鼠标对局、结算重开、运动中重开、练习切换，以及规则、资源和包完整性检查。

本版仅支持本机电脑对战和一张正式地图，不保存进度。击飞与复归采用基础表现，更清楚的击飞、完整入水和浮稳动画将在后续版本优化。实际手机触摸、不同浏览器、Dark Reader 与扬声器听感尚未全部覆盖。

完整规则、角色技能与素材说明见仓库 README。
