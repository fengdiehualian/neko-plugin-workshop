## 1. 版本目标

0.1.0 是可以亲手试玩的碰撞手感原型。

玩家在水池中选择一个泳圈，向后拖拽调整方向和力度，松手发射。泳圈能撞到其他泳圈，把运动传递出去，也能撞墙反弹；水阻让运动逐渐衰减，最终全场停稳，再进行下一次发射。

这版需要回答：

1. 选择、瞄准、发射是否直观、跟手？
2. 泳圈之间撞击和擦边的结果是否清楚、有弹性？
3. 合适的路线下，是否能连续弹上几次？
4. 最后是否能自然停下来，让人愿意再发射一次？

角色美术方向已经确定。本版用占位图形先验证运动与碰撞，后续再放入正式角色图。

## 2. 本版交付物

- 一个独立 N.E.K.O 插件，版本为 `0.1.0`，可通过插件界面打开试玩。
- 一个固定矩形水池，以及橘子、布丁、奶盖三个占位泳圈。
- 选择、拖拽瞄准、发射、碰撞、水阻衰减、停稳的完整交互。
- 重置、测试布局选择、恢复默认参数等基础操作。
- 可折叠的手感调试区，方便边玩边调整参数。
- 简短的试玩说明、已知限制和针对碰撞稳定性的检查结果。

交付时提供实际打开方式。核心试玩不依赖模型调用或外部网络。

## 3. 试玩画面

水池占据主要区域，采用便于判断角度和距离的正俯视平面。界面随可用空间等比缩放，物理场地尺寸保持不变。

| 对象 | 占位表现 |
| --- | --- |
| 橘子 | 橘色圆形泳圈，标注名字 |
| 布丁 | 黄色圆形泳圈，标注名字 |
| 奶盖 | 淡紫色圆形泳圈，标注名字 |
| 池壁 | 清楚的充气边框，内缘与实际碰撞边界对应 |
| 当前选择 | 描边或光圈，配合方向箭头；原力度条已于 dev7 按反馈移除 |
| 运动反馈 | 简单水纹、尾迹和碰撞闪动 |

占位泳圈先采用相同半径和质量，建立易比较的基础手感。名字和颜色仅用于辨认，不代表已经实现角色技能。

正式像素角色、头顶小猫、配饰和复杂水面纹理在后续版本制作。泳圈挤压动画暂不作为本版完成条件。

## 4. 操作约定

1. 全场停稳时，在泳圈上按下鼠标左键，选中并开始瞄准。
2. 向后拖拽，箭头指向与拖拽相反的发射方向；拖得越远，力度越大。
3. 力度有最大值，超过最大拖拽距离后不再增加。
4. 松手后发射。轻点或拖拽距离过小，只选择，不发射。
5. 按 Esc 或右键可取消瞄准；失去指针或触摸被系统取消时也取消，不能误发射。
6. 泳圈运动期间暂停选择和发射，全场停稳后恢复。
7. 随时可以重置，立即回到当前布局的初始状态。

优先完成桌面鼠标操作，基础触摸拖拽使用同样的方向、力度和取消规则。

### 瞄准辅助

- 必须显示初始方向、力度和首次预计接触位置。
- 预览应考虑泳圈半径，与实际碰撞边界对应。
- 首先碰到另一只泳圈时，预览停在接触处。
- 第一段射线先碰到池壁时，可再显示一次反射方向；此增强项不阻塞基础原型验收。
- 不预演后续整场碰撞，也不预测完整停止位置。

## 5. 物理规则与手感

以圆形刚体实现泳圈。使用固定物理步长，将绘制和物理更新分开；限制发射强度，并通过合理步长或子步进避免高速穿透。

### 基础规则

- 场地内没有向下坠落的重力，泳圈在水面平面滑行。
- 泳圈之间正常碰撞，运动根据质量和接触方向传递。
- 正面撞击与擦边撞击呈现不同的分离方向。
- 撞墙有反弹，撞击过程中损失一部分动能。
- 水阻随运动持续生效，衰减不依赖显示帧率。
- 不设“最多碰撞几次”的上限。
- 低速持续一小段时间后进入停稳状态，消除最后的爬行与微抖。

### 第一轮调试目标

| 项目 | 目标 |
| --- | --- |
| 小力度 | 可以轻推近处泳圈，不会一松手就横穿水池 |
| 中力度 | 命中后还有可见余力，能观察到后续运动传递 |
| 大力度 | 在固定参考布局和合适角度下，争取出现约 3～5 次明显碰撞，包含撞猫和撞墙 |
| 运动时长 | 典型参考出手约 4～7 秒停稳，具体数值按试玩调整 |
| 结束过程 | 明显减速后停稳，不突然刹住，也不长时间微动 |

以上数字是调参目标，需要在固定布局中记录实测表现。碰撞数量不作为任意路线的保证，也不能用接触抖动或微碰凑数。

### 质量差异预留

调试区可以改变所选泳圈的质量，观察重球和轻球的碰撞差异。第一轮保持三者相同；基础手感稳定后再测试差异。

质量实验使用明确且一致的发射约定：同一力度先给相同初始速度，再观察质量不同造成的运动传递差异。角色正式上线前，再根据平衡需要评估发射规则。

本版不把质量调试称为橘子的技能，也不提前实现减伤或角色成长。

## 6. 测试布局与调试区

提供固定、可重复的布局，避免每次都靠随机摆放判断手感。

| 布局 | 用途 |
| --- | --- |
| 单圈撞墙 | 看滑行距离、反弹和自然衰减 |
| 两圈对撞 | 看正面碰撞、擦边、质量与运动传递 |
| 三圈连撞 | 看一发能否带动多个泳圈继续运动 |
| 墙角拥挤 | 检查卡住、重叠、抖动和异常加速 |

正常试玩默认显示三个泳圈；单圈、两圈布局是专项检查模式。

调试区默认收起，包含：水阻、泳圈弹性、池壁弹性、最大发射速度、所选泳圈质量，以及恢复默认参数。

物理参数在停稳时修改，运动中调整项暂时禁用。必要时显示本次出手耗时、有效碰撞次数和当前最大速度，帮助复现问题。

调参结果本版可以只保存在当前页面内，刷新回到默认值；先不增加账号或长期存档。

## 9. 稳定性与验证

### 必须覆盖的检查

- 最高允许速度下，泳圈不穿过另一个泳圈或池壁。
- 多个泳圈互相挤压、贴墙或进入墙角时，不持续重叠或自行加速。
- 同一布局、参数和输入在不同显示帧率下，结果保持在合理容差内。
- 浏览器窗口缩放后，选中位置、拖拽方向和实际发射一致。
- 鼠标拖出画布、Esc、右键和触摸取消不会误发射或留下卡住的瞄准状态。
- 页面隐藏时暂停演算并取消未完成瞄准；返回后平稳恢复，不补算隐藏期间的大段时间。
- 重置会清除速度、尾迹、选择和未结束的出手；旧回调不能干扰新布局。
- 关闭游戏页面时，清理动画循环和事件监听，重新打开不会重复运行。

对发射向量、衰减、停稳和高速碰撞等关键逻辑进行必要的定向验证，再在实际游戏页面中检查输入、缩放与连续试玩。保留默认参数和参考出手记录，方便下一轮比较。
