# 猫爪副驾 (neko_pawpilot)

欧卡2（Euro Truck Simulator 2）猫娘副驾驶陪玩插件。遥测感知驾驶、事故急救、
超时提醒、路线规划、画面畅聊、猫娘智驾，让每趟长途都有猫娘陪伴。

## 特性

- 遥测实时感知：车速/油量/损伤/任务/世界坐标（SCS SDK 共享内存）
- 21 种驾驶事件：超速/急刹/事故/超时/罚款/加油/接货/到货…
- 事故叙事链：撞击瞬间 → 伤情检查 → 维修评估 → 事后安慰
- 每单小挑战：油耗/不超速/零急刹赌约，输赢记录
- 行程总结 + 旅程账本 + 驾驶画像 + 成就里程碑
- 画面畅聊：OCR 识别屏幕内容自动找话题、美景拍照
- 地图定位：解析 base_map.scs（74k 道路 + 2k 设施），高速/服务区/红绿灯提示
- 猫娘人设：宿主导入（名字/特质/口头禅），可选播报口吻（傲娇/冰山/话痨/温柔/严厉/安静）
- 猫娘智驾：提议 → 同意 → 自动巡航；被抢方向盘自动让渡，连抢 3 次自动交还
- 遥测自动导入：插件自动把 scs-sdk-plugin DLL 装进游戏目录，玩家零手动配置
- 四层仲裁 + 安全门 + 双通道推送（宿主 LLM 润色/直出气泡）

## 安装

1. 将本插件放入 N.E.K.O 插件目录并启用（首次启动自动导入遥测 DLL）
2. 若游戏运行中无法写入，面板会提示关闭游戏后重试

## 配置

- 运行参数在 `plugin.toml [neko_pawpilot]` 段，改后即时生效（config_change）
- 面板设置（播报开关/口吻/频率/类别）存 `data/config/ui_settings.json`，可在面板或直接改文件

## 开发

- 架构与功能设计：见方案文档
- 地图解析工具：`adapters/map_extractor/`（.NET 10 + TruckLib，发布含 self-contained exe）
- 测试：`python -m pytest tests/`（本地独立跑，不依赖宿主 SDK）
