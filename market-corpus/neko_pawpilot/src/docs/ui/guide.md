# 猫爪副驾使用指南

欧卡2 猫娘副驾驶陪玩插件：遥测感知驾驶，让每趟长途都有猫娘陪伴。

## 快速开始

1. 安装 [scs-sdk-plugin](https://github.com/truckermudgeon/scs-sdk-plugin) 的
   `scs-telemetry.dll` 到游戏 `bin/win_x64/plugins/` 目录
2. 启动游戏，插件自动检测遥测连接
3. 面板实时显示车速/油量/任务/损伤，驾驶事件自动推送

## 功能

- 超速/急刹/事故/超时/低油量实时提醒
- 接单路线预览、服务区建议、路线选择
- 每单小挑战（油耗/不超速/零急刹赌约）
- 到货行程总结 + 旅程账本 + 驾驶画像 + 成就里程碑
- 画面畅聊：OCR 识别屏幕内容自动找话题
- 地图定位：高速/国道识别 + 前方服务区提示

## 设置

面板「设置」页可切换人设模式（温柔/话痨/严厉/安静）、
播报开关（dry_run 试运行/正式）、播报频率和类别。

## 常见问题

- 没有推送？检查插件是否开启（默认 dry_run 试运行）
- 游戏未连接？确认 scs-telemetry.dll 已安装且游戏在运行
