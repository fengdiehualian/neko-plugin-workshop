# 猫娘实况相册 (Neko Live Album)

像女友一样**双向拍照**的实况相册插件。

## 功能

- **📸 拍她**：点快门按钮抓拍猫娘的反应实况（2.5 秒 canvas 录制 + 封面帧）。她会害羞捂脸、主动摆 pose、或者假装嫌弃——反应真实发生在按下快门的瞬间。
- **🤳 她拍你**：闲置或被摸头多次后，她会主动开口请求拍一张你。授权后前置摄像头 3 秒倒计时拍摄，照片带她的专属备注（"这张笑得最好看，收藏了 ♡"）。
- **实况相册**：iPhone 相册式网格，**长按播放实况**；她拍的卡片有"她拍的"角标；详情页含元数据（时间、台词、她当时的心情）；支持 Web Share 导出。
- **持久化**：相册通过 IndexedDB 保存在面板中，刷新/重开不丢失。
- **可互动猫娘**：canvas 手绘 chibi 猫娘，呼吸、眨眼、摇尾巴、摸头爱心特效。

## LLM 入口

| 入口 | 说明 |
|------|------|
| `album_guide` | 向主人解释相册玩法（主人问起时猫娘自动调用） |
| `photo_react` | 按场景（shy/pose/happy/annoyed/compliment）返回猫娘的反应台词 |

## 使用说明

1. 安装后在插件面板打开「实况相册」。
2. 「她拍你」功能需要浏览器摄像头权限；在 iPhone 上通过远程访问使用时需要 HTTPS（建议配合 cloudflared 内网穿透扫码打开）。
3. iOS Safari 14.3+ 支持实况录制；不支持的浏览器自动降级为静态快照卡。

## 隐私说明

- 猫娘拍你的画面仅保存在本地浏览器 IndexedDB，不上传任何服务器。
- 使用「保存/分享」导出时才离开本地。
- 删除照片时她会不高兴，但不会阻拦你。
