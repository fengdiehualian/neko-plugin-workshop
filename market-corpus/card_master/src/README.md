# 卡牌大师（card_master）

让 N.E.K.O 的猫娘（YUI）**自主学习和练习各类卡牌游戏**——德州扑克、斗地主、Kards、掼蛋。

装上这个插件后，YUI 可以创建虚拟牌局、发牌、出牌、计算胜率、获取出牌建议、自我对弈训练，还能查询 Kards 的真实规则和卡组检查。

---

## ✨ 功能特性

### 德州扑克（完整牌局模拟）
- **创建牌局**：2-10 人，自定义盲注和玩家，支持随机种子复现
- **完整流程**：翻牌前→翻牌→转牌→河牌→摊牌，下注/跟注/加注/弃牌/全下
- **牌型评估**：7 选 5 最佳牌型，支持任意 5/7 张牌
- **胜率计算**：蒙特卡洛模拟，支持 1-N 个对手
- **出牌建议**：综合胜率 + 底池赔率 + 位置，给出 fold/check/call/raise 建议及理由
- **自我对弈**：AI vs AI 对弈，YUI 可观察学习每步决策
- **下一手牌**：移动庄家位，连续多手牌

### Kards（真实规则学习辅助）
> 所有规则数据来自 Kards 官方 wiki（wiki.biligame.com/kards）和官方教程（decks.kards.com），不编造。

- **完整规则查询**：基本规则、指挥点系统、三条战线、卡牌类型、5种单位类型、学习路径
- **能力关键词**：20+ 个关键词解释（闪击、部署、亡计、守护、伏击、冲击、重甲、烟幕、压制、钳击、山地等）
- **国家特色**：9 个国家（5主要国 + 4盟国）的玩法风格和特色
- **卡组检查**：验证卡组是否合法（40张=1总部+39张，1主国+1盟国，国家有效性）

### 掼蛋
- 完整规则查询（牌型、逢人配、升级、进贡/还贡、抗贡等）

### 斗地主（完整牌局模拟）
- **发牌**：3人一副牌54张，每人17张+3张底牌
- **叫地主**：轮流叫分1/2/3或不叫，最高分当地主拿底牌
- **完整牌型识别**：单张/对子/三张/三带一/三带二/顺子/连对/飞机/飞机带翅膀/四带二/炸弹/王炸，共14种牌型
- **出牌验证**：自动判断牌型是否合法、能否压过上一手
- **牌局状态机**：叫地主→出牌→胜负判定，地主vs两个农民
- **牌型识别工具**：输入任意牌组合，自动识别是什么牌型
- **支持纯点数出牌**：输入"3 3 3 4"即可，AI自动从手中选对应花色

### 🎮 实时打牌（live 模式）——YUI 自己打牌
> 让 YUI 在获得电脑鼠标/键盘控制权后，**自己操作真实游戏**打牌。

- **live_session**：开启实时打牌会话（德州扑克 / 斗地主 / Kards 三选一）
- **live_report**：YUI 从屏幕读取局面（截图/OCR/读界面）→ 结构化上报 → 插件返回**决策建议 + 鼠标操作步骤**
- **live_action_done**：确认动作已执行（成功/失败），失败时给补救指引
- **live_status**：查看会话回合数、动作历史、最近局面
- **doudizhu_live_advice**：斗地主独立出牌建议（完整候选枚举 + 身份策略 + 炸弹/王炸保留）
- **kards_live_advice**：Kards 独立回合建议（按优先级：攻击→部署→命令卡，附检查清单，规则全部来自官方 wiki）

**工作流程**：YUI 获得鼠标控制权 → `live_session` 开会话 → 截图读局面 → `live_report` 上报 → 按插件给的 steps 点鼠标 → `live_action_done` 确认 → 等对手行动 → 重新上报，如此循环。

---

### 🕹️ 内置斗地主小游戏——对战两个 YUI 人机（浏览器面板）
> 无需鼠标操控权限。开局自动打开**欢乐斗地主风格浏览器面板**（客户端插件面板 → 斗地主；显示你的手牌、底牌、AI 手牌数、上一手；AI 在面板内自动出牌，你点击选牌后按「出牌」或「不要」），也可以全程用对话玩。

- **dd_game_start**：开一局小游戏（`role` 参数：`auto` 随机分配身份 / `landlord` 我当地主 / `farmer` 我当农民），自动发牌、分配身份、展示手牌，并打开浏览器面板
- **dd_game_play**：出牌（文字/纯点数均可，支持"不要/过"）。**交互边界：两个 YUI_AI 的牌由插件自动出，你只出"你"的牌**——你出牌成功后插件会自动让两个 AI 依次出到轮到你
- **dd_game_advance**：对话模式下推进 AI 回合（面板里 AI 会自动进行，无需调用）
- **dd_game_state**：查看当前局面与战绩（胜/负）
- **面板操作**：插件面板（Hosted UI）→「再来一局」开新局；点手牌选牌（可多选）→「出牌」；有上一手时可「不要」

**AI 策略**：完整 14 种牌型候选枚举 + 身份策略（地主激进、农民配合保留大牌）+ 炸弹/王炸只在关键时使用。

**玩法示例**：
- 「来一局斗地主小游戏」（自动分配身份 + 打开面板）
- 「我当地主，开一局」
- 「出 3♠ 5♠ 7♠」「不要」
- 「现在什么局面」「我赢了几局」

## 🔒 安全与设计

- **纯本地模拟**：所有牌局在本地内存中运行，不联网、不涉及真实金钱
- **牌局状态不持久化**：插件重启后牌局丢失（属预期，每次对话可新开）
- **Kards 规则来源可追溯**：全部来自官方 wiki，不编造机制
- **蒙特卡洛可复现**：支持 seed 参数，相同种子产生相同牌局
- **AI 回合有界**：内置 200 步上限防止异常死循环

## 👩‍💻 开发

源码：

```text
https://github.com/1-dcjiang/n.e.k.o_plugin_card_master
```

结构：
- `__init__.py` — 插件主类 + 26 个 LLM 工具
- `engine.py` — 德州扑克引擎（牌组/牌型评估/牌局状态机/胜率/自我对弈/suggest_from_state 纯函数）
- `kards.py` — Kards 规则数据（官方 wiki）+ 查询函数 + 卡组检查
- `doudizhu.py` — 斗地主引擎（牌型识别/状态机/suggest_play 实时出牌建议）
- `live.py` — 实时打牌决策引擎（会话管理 + 三种游戏决策器 + 鼠标操作指引）

许可证：Apache 2.0
