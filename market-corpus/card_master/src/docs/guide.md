# 斗地主 · 卡牌大师

## 怎么玩

1. 点面板里的「再来一局」，或对 YUI 说“来一局斗地主”。
2. 开局发牌进入**叫地主**：轮到你时点「不叫 / 叫1分 / 叫2分 / 叫3分」（叫3分直接当地主），AI 会按手牌强度自动叫分；叫分最高者当地主并拿 3 张底牌（共 20 张）。对话模式用 dd_game_bid 叫分。
3. 地主确定后进入出牌。轮到你时，**点击手牌选牌**（可多选，选中会浮起），再按「出牌」。
   - 上一手有牌时，按「不要」表示不出（先手时不能不出）。
   - 也可以直接打字对 YUI 说：`出 3♠ 5♠ 7♠`、`不要`。
4. 两个 AI（YUI_左 / YUI_右）的牌**由插件自动出**（先手优先出组合牌型清牌），你只出你自己的牌。
5. 出完牌自动判胜负并记录战绩（面板与对话战绩共享），点「再来一局」继续。

## 牌型

单张 / 对子 / 三张 / 三带一 / 三带二 / 顺子（5+）/ 连对（3+ 对）/ 飞机 / 飞机带翅膀 / 四带二 / 炸弹 / 王炸。

- 大王 > 小王 > 2 > A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3
- 炸弹 > 普通牌型；王炸（双王）最大。

# Kards 自动对局（自己打牌）

让 YUI 在 Kards 真实对局中**自己打完整局**：定位游戏窗口 → 识别局面（指挥点/双方总部/手牌/战线）→ 按官方规则决策 → 真实操作（出牌/攻击/结束回合）→ 等待对手 → 继续下回合。

## 使用前提

1. 已安装 Kards 游戏本体（Steam，appid 544810）并登录
2. **启动游戏并进入一局对局**（训练 / 打 AI / 好友对战均可，主菜单或组牌界面不行）
3. 首次使用前先**标定**（见下），否则数字识别不到会如实提示、不瞎猜

## 第一步：标定（只需做一次）

对 YUI 说「**标定 Kards**」（kards_calibrate），插件会：

- 自动定位并前置游戏窗口
- 截图保存到插件目录 `templates/kards/`：全屏（full.png）、指挥点/双方总部/结束回合按钮/手牌行裁剪图
- 把当前布局写入 `kards_layout.json`（可手动调整坐标）

**数字标定**：把裁剪图里的单个数字（0-9）裁成 `digit_0.png` … `digit_9.png` 放到 `templates/kards/` 目录即完成。未标定前相关数值显示「未识别」，自动对局会如实报告，不会乱猜。

窗口缩放/分辨率变化后，重新标定一次。

## 开始自动对局

对 YUI 说「**开始打 Kards，打 N 回合**」（kards_auto_play，N 默认 1、最大 5）：

- 插件优先走**内存通道**（KARDS_API / UE4SS）：读内存拿卡名/费用/攻防真数据，出牌/攻击/结束回合纯代码操作，不碰鼠标
- 没装内存通道则自动回退**读屏+键鼠**：拖拽出牌（真人等价）、点选攻击、点结束回合
- 每回合执行前真实截图/读内存验证；识别不到就**立即停止如实汇报**，绝不盲点

## 查看局面

对 YUI 说「**Kards 现在什么局面**」（kards_auto_status，只读不点击）：指挥点、双方总部、手牌数、战线占用、是否自己回合。

## 停止条件（不瞎点、不挂机、不编状态）

- 识别不到手牌/窗口/内存服务 → 立即停止并说明原因
- 连续 3 回合无实质推进（局面无变化且没做出部署/攻击）→ 停止交还控制
- 等待自己回合超时 → 停止
- 未识别数字 → 如实报告「未识别」，不猜测数值

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 报「未找到 Kards 窗口」 | 游戏没启动或没进入对局：先开游戏进一局再试 |
| 数值显示「未识别」 | 数字模板没标定：先跑「标定 Kards」并补 digit 模板 |
| 报「KARDS_API 服务不可用」 | 没装 UE4SS 内存通道：已自动回退读屏+键鼠，可继续用 |
| 自动对局中途停下 | 正常安全机制：识别不到/无推进/超时会如实停下，按提示处理 |
| 显示「连续 N 回合无推进」 | 游戏卡在弹窗/结算界面或不在对局：回游戏确认后再开始 |
