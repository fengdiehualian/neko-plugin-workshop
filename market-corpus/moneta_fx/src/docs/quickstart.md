# MONETA FX 使用指南

MONETA FX 是一个**虚构**外汇模拟交易室。所有行情、资金与成交都是游戏数据，不对应任何真实市场。

## 快速开始

1. 在插件面板中点击「登录 / 注册」，创建普通账户，或使用开发者密钥进入行情控制台。
2. 左侧选择货币对（默认 EUR/USD），右侧设定手数、止损与止盈。
3. 点击「买入」或「卖出」完成下单，持仓会出现在下方表格中。
4. 切到「账户分析」查看已实现盈亏、胜率、盈利因子与净值曲线。

## 三种入口

| 入口 | 说明 |
| --- | --- |
| 登录 | 已有普通账户，进入共享虚构市场。 |
| 创建账户 | 新账户，获得 100,000 USD 模拟资金。 |
| 开发者登录 | 使用开发者密钥，解锁行情控制台与账户管理。 |

## 交易规则

- **杠杆**：1:10 至 1:500，仅空仓且无挂单时可修改。
- **点差**：按货币对动态计算，可用倍率调整。
- **滑点**：市价成交在 0 至上限之间随机产生不利滑点。
- **佣金**：每手每边收取一次，部分平仓按实际手数收取。
- **隔夜费**：UTC 22:00 结算，周三三倍，周末不结算。
- **强平**：保证金水平低于 50% 时自动平掉亏损最大的持仓。

## 订单类型

- **市价单**：按当前可成交价立即成交。
- **限价单**：买入挂单价需低于当前卖出价，卖出需高于当前买入价。
- **突破单**：与限价单方向相反，越过触发价才成交。

## 行情控制台（开发者）

- **直接调整价格**：单次可调至当前价的 50%–200%，相关交叉汇率联动。
- **编排走势**：以当前价为起点，在指定模拟秒内到达目标涨跌幅。
- **时间与波动**：1× / 5× / 20× / 100× 倍速，暂停时钟，调整波动强度。
- **虚构事件**：美元走强、欧元利好、日元干预、流动性风暴。

## 数据与存档

共享市场由服务端持续撮合：关闭面板后，挂单、止损与强平仍然有效；服务停止期间模拟时钟冻结，重启后只补绘图表，不会补成交或补扣费。
