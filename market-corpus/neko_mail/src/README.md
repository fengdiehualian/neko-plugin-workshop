# 📧 猫娘邮件秘书 (Neko Mail)

让猫娘帮你管理 QQ 邮箱，生成邮件摘要、判断优先级、标记已读、发送邮件（支持附件）。

## ✨ 特性

- 🌸 **清新诗意的前端界面** - 白、蓝、粉渐变色，浪漫可爱风格
- 🌍 **支持 i18n 多语言** - 中文、英文、日文、韩文、繁体中文、西班牙文、葡萄牙文、俄文
- 📊 **智能邮件摘要** - 按优先级分类（高/中/低），猫娘友好播报
- 🔍 **关键词搜索** - 搜索主题、发件人、正文
- ✉️ **发送邮件** - 支持收件人、抄送、主题、正文、**附件**
- 🏷️ **优先级判断** - 自动识别紧急邮件（学校、导师、HR、面试、offer 等）
- 📎 **附件支持** - 发送和识别邮件附件，支持中文文件名
- 🔄 **标记已读** - 一键标记邮件为已读
- 🔔 **新邮件轮询** - 定时检查新邮件并推送通知
- 🛡️ **去重校验** - 防止旧邮件重复推送
- 🎯 **基线校准** - 手动/自动校准轮询基线

## 📦 安装

### 方法 1: 从插件市场安装（推荐）

在 N.E.K.O 插件市场搜索「猫娘邮件秘书」或「neko_mail」，点击安装即可。


## 🔧 配置指南

### 第一步：获取 QQ 邮箱授权码

1. 登录 [QQ 邮箱网页版](https://mail.qq.com)
2. 点击右上角「设置」→「账户」
3. 向下滚动找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务」
4. 点击「开启」IMAP/SMTP 服务
5. 按提示用手机发送短信验证
6. 验证成功后会生成一个 **16 位授权码**
7. ⚠️ **重要**：复制并妥善保存授权码，只显示一次！

### 第二步：编辑配置文件

编辑插件目录下的 `plugin.toml` 文件：

```toml
[neko_mail]
# ═══════════════════════════════════════════
# 必填配置（必须正确填写才能使用）
# ═══════════════════════════════════════════

# QQ 邮箱地址（你的QQ号@qq.com）
email_addr = "123456789@qq.com"

# QQ 邮箱授权码（16位，在 QQ 邮箱设置中生成）
auth_code = "abcdefghijklmnop"

# ═══════════════════════════════════════════
# 可选配置（使用默认值即可）
# ═══════════════════════════════════════════

# IMAP 服务器（收件）
imap_server = "imap.qq.com"
imap_port = 993

# SMTP 服务器（发件）
smtp_server = "smtp.qq.com"
smtp_port = 465

# 高优先级发件人（逗号分隔，匹配发件人地址中的任意子串）
# 例如：导师、HR、老板的邮箱
high_priority_senders = "teacher@edu.cn,hr@company.com"

# 要忽略的文件夹（逗号分隔）
ignore_folders = ""

# 猫娘对用户的称呼（支持猫娘自主决定或与用户协商）
master_name = "主人"

# 猫娘的自称
catgirl_name = "喵喵"

# 新邮件轮询间隔（秒），默认 300 秒（5 分钟）
# 设为 60 表示每分钟检查一次，设为 600 表示每 10 分钟检查一次
polling_interval = 300
```

### 第三步：重启 N.E.K.O

重启后，插件会自动加载并连接邮箱。首次连接成功后，猫娘会开始定时检查新邮件。

## 🔔 新邮件推送机制

### 工作原理

1. **轮询检查**：每隔设定的时间间隔（默认 5 分钟）检查一次新邮件
2. **双条件判定**：只有同时满足以下条件才判定为新邮件：
   - UID 大于上次记录的基线
   - 邮件状态为未读
3. **去重校验**：同一封邮件不会重复推送
4. **自动校准**：轮询重启时自动校准基线到当前最新 UID

### 轮询配置

- **修改轮询间隔**：在 `plugin.toml` 中修改 `polling_interval`（单位：秒）
- **手动校准基线**：如果发现旧邮件被重复推送，可以说「校准轮询基线」
- **停止轮询**：可以说「停止邮件轮询」
- **查看状态**：可以说「查看轮询状态」

### 常见场景

**场景 1：旧邮件重复推送**
```
你：猫娘，为什么老邮件一直推送？
猫娘：让我帮你校准一下轮询基线~
（执行 calibrate_baseline）
```

**场景 2：想更频繁检查新邮件**
```
你：猫娘，把邮件检查改成每分钟一次
猫娘：好的，正在调整轮询间隔为 60 秒~
（执行 start_polling，interval_seconds=60）
```

## 🎨 优先级判断规则

### 高优先级 (HIGH)

满足任一条件：
- 发件人域名含 `edu.cn` / `学校` / `教务处` / `导师` / `hr` / `boss`
- 主题含：`紧急`、`重要`、`截止`、`deadline`、`面试`、`offer`、`挂科`、`补考`、`成绩`
- 发件人在 `high_priority_senders` 配置中

### 低优先级 (LOW)

满足任一条件：
- 发件人含 `noreply` / `no-reply` / `notification` / `newsletter` / `marketing` / `ads`
- 主题含：`推广`、`订阅`、`unsubscribe`、`广告`、`优惠`、`促销`、`账单已出`

### 中优先级 (MEDIUM)

其余邮件

## 🔒 安全说明

- **授权码安全**：授权码仅存储在本地 `plugin.toml`，不会上传或外泄
- **连接加密**：使用 SSL/TLS 加密连接 IMAP/SMTP 服务器
- **只读模式**：默认以只读模式获取邮件，仅在标记已读时写入
- **发信确认**：发送邮件前，建议让猫娘确认收件人和内容

## 🐛 常见问题

### Q: 提示「授权码错误」

A: 检查 `plugin.toml` 中的 `auth_code` 是否正确。注意是**授权码**而不是 QQ 密码。授权码需要在 QQ 邮箱网页版设置中单独生成。

### Q: 连接超时

A: 检查网络连接，确保能访问 `imap.qq.com:993` 和 `smtp.qq.com:465`。如果使用代理，需要配置代理。

### Q: 看不到某些文件夹

A: 某些系统文件夹（如 `[Gmail]`）会被自动过滤。如需查看，可修改 `plugin.toml` 中的 `ignore_folders` 配置。

### Q: 邮件正文乱码

A: 插件支持 UTF-8、GBK、GB2312、Big5、ISO-8859-1 等常见编码，会自动识别。如果仍有乱码，请提 issue。

### Q: 旧邮件被重复推送

A: 对猫娘说「校准轮询基线」即可解决。这是因为轮询重启时基线可能回退，校准后会恢复正常。

### Q: 新邮件没有推送

A: 检查轮询是否已启动（对猫娘说「查看轮询状态」）。如果已启动但仍未推送，可能是邮件已被标记为已读，或者 UID 未超过基线。

### Q: 附件发送失败

A: 检查附件文件路径是否正确，文件是否存在。QQ 邮箱对附件大小有限制（通常 50MB），超大文件会发送失败。
