# 塔罗牌占卜（tarot）

神秘的塔罗牌占卜插件，提供标准塔罗牌、黄金裔塔罗牌（翁法罗斯·逐火之旅）、生辰八字、星座运势等占卜服务。Web UI：`http://127.0.0.1:48916/plugin/tarot/ui/`

## 功能一览（13 个占卜入口）

| 模块 | 说明 |
|------|------|
| 标准塔罗牌 | 78 张公版 RWS 韦特全卡组，牌面图渲染，支持单张/三张牌阵 |
| 黄金裔塔罗 | 翁法罗斯·逐火之旅主题牌组，聚焦角色剧情与人物塑造 |
| 生辰八字 | 四柱排盘、五行分析 |
| 星座运势 | 十二星座每日运势 + 程序化生成的深空星图卡片（真实 J2000 恒星数据） |
| 周公解梦 | 本地意象库解梦 |
| 姓名五格 | 五格剖象法，Unihan 两万汉字笔画兜底，支持四字名 |
| 智能起名 | 基于笔画数理的起名建议 |
| 梅花易数 | 以数起卦，六爻卦象卡片，本卦/变卦/互卦完整解读 |
| 姻缘占卜 | 双人姓名缘分指数与解读 |
| 观音灵签 | 随机抽签 + 签文解读 |

## 特色

- 全部占卜逻辑为**本地确定性算法**，无外部 API 依赖
- 通过 `@llm_tool` 注册 10 个猫娘可直接调用的占卜工具
- Web UI 卡片式渲染（塔罗牌面、卦象图、星座星图）
- 占卜历史持久化（`[plugin.store]`）

## 开发说明

- `plugin.toml`：插件元数据，entry = `plugins.tarot:TarotReaderPlugin`
- `static/`：Web UI 与图片资源（RWS 牌面、星座星图）
- `image/`：黄金裔塔罗牌面图
- 冒烟测试：`pytest tests/test_smoke.py`
