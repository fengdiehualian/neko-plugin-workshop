# 功能建议：支持将插件图片排在本轮文字回复末尾

我们正在开发 N.E.K.O 表情包插件，希望实现“文字全部显示完，再显示表情包”，而不是固定延迟发图。

## 当前问题

插件通过 `push_message` 发图，图片可能出现在正常回复开头或中间。
仅等待后端 `turn end` 也不够：分段模式下，前端仍可能有文字正在排队显示。

## 希望提供的能力

- 工具调用上下文提供可靠的本轮回复标识。
- 插件可提前登记图片，由宿主在该轮最后一段文字显示后有序投递，兼容合并和分段模式。
- 明确处理打断、取消与重复登记，避免重复发图或把旧图插进下一轮回复。

工具及时返回，不阻塞正常文字；图片保持 `ai_behavior="blind"`，不反灌模型。
原有即时发送行为不变，仅显式请求尾发时使用新能力。

## 协作意向

想先确认这一接口方向是否适合宿主；设计确认后，我们愿意提交实现与回归测试 PR。
