# 表情包管理 0.9.2

猫娘现在先阅读候选图片的用途与语气，再按自己回复的意思选择具体图片。
插件 ID 保持 `sticker_manager`。

## 更新

- 分类和关键词查询返回逐图说明，猫娘确认具体 ID 后才发送。无匹配、没有合适候选或指定图片不可用时，不随机换图补发。
- 重新核看内置 190 张表情的动画，更新用途说明和标签，区分动作发起者、对象、情绪强度，以及适用和不适用的语境。原始图片与发送动画未改动。
- 补充动作、对象、发生阶段和语气的匹配要求，避免只因同属开心或亲昵就使用图片。
- 在工具描述、提醒和回执中要求不在正文或括号动作里叙述找图、选图和发送过程；调用后只续接未说完的话。
- 查询排除已禁用、近期使用和非激活区图片。发送日志记录具体图片 ID，便于核对。

## 安装与更新

从插件市场更新，或下载本次 GitHub Release 的 `sticker_manager.neko-plugin`，
在宿主插件管理中覆盖导入。正常更新保留用户配置、图库和使用记录，请勿卸载清除数据。
更新并重启插件后，建议开启新会话，让新工具说明生效。

此前本地 0.9.3 为未发布的测试编号；正式 0.9.2 包含其已测试修复。
该测试版用户手动导入正式包时，需要确认替换较高的本地版本号。

## 验证与边界

发布前本地验证：950 项 Python 测试通过、2 项跳过；22 项面板回归通过。
Ruff、SDK 检查、隔离发布构建、载荷哈希和 Hosted TSX 检查均通过。
正式发行结果以远程 Verify、Release 工作流和市场版本记录为准。

实机测试记录有 39 个用户轮次、11 次查图和 9 次成功提交，
已保存回复中未再出现选图旁白。部分图片仍存在动作匹配偏差，
且该轮主要是亲昵互动，不能代表难过、安慰等场景已经全部验收。

选图仍依赖当前回复模型；关键词召回不是语义向量检索。
插件指令不能保证模型永不外显操作，也不能拦截宿主文字流。
发送仍默认即时提交，不保证图片位于全部文字或语音结束之后。
积极度、提醒频率、冷却、概率和去重规则沿用现有设置。
