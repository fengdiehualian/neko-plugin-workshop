# 表情包管理 0.9.3

图库面板更简洁，选图更重视具体动作、对象和发生阶段，并修复空候选后的操作旁白诱因。
插件 ID 保持 `sticker_manager`。本版本仅在 GitHub 发行，不通知插件市场。

## 更新

- 面板改为“图库 / 设置”，集中搜索、分类筛选与导入；次要管理、提醒控制和诊断按需展开。
  浏览收藏区不会自动改变猫娘使用的区，详情返回保留筛选与选择。
- 设置中增加独立发送冷却，可设 0–3600 秒，0 关闭，保存后立即生效；提醒间隔单独控制。
- 区分泡茶、递茶、自己喝茶，等待收到与已经收到／拆开，等待来访与见面问候。
  宽泛情绪不以未提及的红包、奖杯、礼盒、问候、干杯和饮料等情节补位。
- 补充常用情绪近义词和完整已知情绪组合的召回；具体动作、对象、阶段和近期去重仍优先。
  猫娘继续阅读逐图说明并指定图片 ID，没有合适候选时不随机补发。
- 空候选回执改为内部续聊指令，要求不在正文或括号动作里叙述查图失败。
- 空白、分隔符或超长标签不再触发批量增删请求，避免面板报无有效修改错误。

## 安装与更新

下载本次 Release 的 `sticker_manager.neko-plugin`，在宿主插件管理中覆盖导入。
正常更新保留用户配置、图库与发送记录，请勿卸载清除数据；更新后建议开始新会话。
已有测试版本可直接手动覆盖导入；保留原发送冷却、积极度、提醒、概率与最近去重设置。

## 验证与边界

发布前本地验证：1071 项 Python 测试通过、2 项跳过；29 项面板交互回归通过。
真实浏览器覆盖桌面、390/320 像素窄屏、深色模式与英文设置，以及批量空标签按钮状态。
Ruff、SDK 检查、隔离发布构建、Hosted TSX 和导入包载荷哈希校验通过。
标准 GitHub Verify / Release 工作流另行验证，发行完成后核对远程资产与标签源码版本。
关键词召回不是向量语义检索；图片是否贴切仍依赖回复模型阅读说明。
空候选隐私要求属于模型指令，插件无法拦截宿主文字流，不能保证操作旁白永不出现。
内置单纯开心和期待图片仍有限，最近去重后可以没有候选，不为提高频率放宽匹配。
图片默认即时提交，不保证位于全部文字或语音结束之后。
