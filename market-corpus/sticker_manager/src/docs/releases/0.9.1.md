# 表情包管理 0.9.1

四项图库、套图导入与图片发送问题的维护更新，插件 ID 保持 `sticker_manager`。

## 修复

- 修复宿主不同线程同时修改图库或记录使用台账时，写盘及失败回滚可能覆盖另一项成功操作的问题。
- 修复带 manifest 的套图超过 512 张时，超出图片被静默截断的问题。超出部分现在计为拒收；部分导入的收件箱源包保留。全库超过 512 张可导出图片时明确拒绝导出。
- 修复向另一区导入同名分类的新图片时，图片静默进入原分类所在区的问题。现在计为拒收；相同图片仍按重复处理，已删除的目标区也不会回退到当前激活区。
- 修复大图上传期间被禁用、删除或移出激活区后，工具仍发送旧图片的问题。提交前重新检查当前状态；面板明确试发仍允许发送非激活区的图片。

导入拒收和导出超限提示同步更新。新增 27 项针对并发、导入和发送时序的回归用例。

## 安装与更新

从插件市场更新，或下载本次 GitHub Release 中的 `sticker_manager.neko-plugin`，
在 N.E.K.O 插件管理中确认替换同 ID 插件。源码 ZIP 不是导入包。

正常覆盖更新保留用户配置与图库；请勿先卸载并清除数据。升级前建议停止插件并备份用户数据。
本次未调整官方收藏素材、配置默认值或发送顺序。

## 验证与边界

发布前本地验证：926 项 Python 测试通过、2 项跳过；22 项面板回归通过；
Ruff、SDK 检查、隔离构建、安装包哈希和 Hosted TSX 检查通过。
本次按维护者要求不进行真实宿主对话测试；自动回归不等同于安装版实机验收。

工具发图仍默认即时提交，不保证在全部文字或 TTS 结束后发送。
分类名仍全库唯一，单套图导入上限仍为 512 张；未增加自动分类改名或分卷导出。
需要宿主支持 Hosted TSX、LLM Tool Calling 和图片消息接口。

原创源码使用 Apache-2.0。随包素材和用户导入图片不由源码许可证授权，
