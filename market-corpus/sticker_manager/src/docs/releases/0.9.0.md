# 表情包管理 0.9.0

首次插件市场 stable 发行，插件 ID 为 `sticker_manager`。

## 功能

- YUI 通过聊天工具按分类或关键词挑选并发送表情包。
- 管理面板支持分区、分类、搜索、批量整理和图片详情编辑。
- 支持 PNG、JPG、GIF、WebP，保留收藏原图和动画；提供套图 ZIP 导入与导出。
- 提供三档配图积极度、冷却、最近去重和提醒设置；发送总开关默认关闭。
- 内置收藏按分片随包提供，无需额外下载或手动合并。

## 安装与更新

从插件市场安装，或下载 Release 中的 `sticker_manager.neko-plugin`，
在 N.E.K.O 插件管理中导入。源码 ZIP 不是安装包。
启动插件后，在管理面板开启发送总开关，建议开始新对话测试工具调用。

正常覆盖更新保留用户配置与图库，请勿先卸载并清除数据。
`0.9.0` 是版本重定号，低于历史 `0.20.x` 开发版本；
已有开发版用户可能需要明确确认手动替换。

## 已知限制

- 工具发图默认即时提交，可能早于回复的剩余文字，不保证在最后一句文字或语音后发送。
- 动图发送受内联预算限制，发送版可能压缩或缩小；超预算动图默认拒绝，不压平成首帧。
- 需要宿主支持 Hosted TSX、LLM Tool Calling 和图片消息接口；
  SDK 范围声明不代表所有历史安装版均已实测。
