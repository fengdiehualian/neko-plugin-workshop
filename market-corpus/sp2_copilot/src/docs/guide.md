# 上手指南 · 和猫娘一起开飞机（简单飞机2副驾驶）

这个插件让猫娘坐在《简单飞机2 SimplePlanes 2》的右座当副驾驶：读仪表、判阶段、扫告警、跑检查单、做导航。

**它是只读的。** 插件不会向游戏发送任何指令，飞机始终由你驾驶。副驾驶负责看和说，动手的永远是你。

## 三步跑起来

1. 安装配套的 **SP2-Bridge 模组**，并启动一次游戏让模组加载。
   协议见插件目录下的 `docs/bridge-protocol.md`；本地调试可以用 `tools/mock_bridge.py` 起一个模拟服务，不用开游戏也能试。
2. 在 N.E.K.O. 的插件页面启动 **和猫娘一起开飞机(简单飞机2副驾驶)**。
3. 打开「副驾驶仪表盘」面板，点「检测连接」。看到「已连接」就成了。

连不上时依次确认：游戏正在运行 → 模组已装好 → 装完重启过游戏 → 模组端口和插件里的 `bridge_url` 一致（默认 `http://127.0.0.1:21580`）。

## 面板能做什么

- **总览**：连接状态、飞行阶段、姿态仪、关键数字、告警列表
- **仪表**：空速 / 真空速 / 地速、离地高度 / 海拔、迎角、侧滑、G 值、马赫，以及操纵面与构型
- **检查单**：按当前阶段列出该做的事，逐项标 已完成 / 待办 / 读不到
- **导航**：目标方位与距离、最近机场、风向风速
- **设置**：桥接地址、超时、刷新间隔，以及六个告警阈值

面板默认每 3 秒自动刷新一次，可以在「设置」里改，也可以在总览页临时关掉。

## 对话里可以怎么问

- 「我现在飞得怎么样」
- 「姿态正常吗」「是不是要失速了」
- 「有什么要提醒我的吗」
- 「下一步该干什么」「检查单」
- 「还有多远」「该往哪边转」
- 「油还够吗」「发动机有没有事」
- 「帮我总结一下」

## 关于告警阈值

面板「设置」里的六个阈值只影响**什么时候提醒你**，不影响游戏本身。

机体自带限速数据（Vne、失速速度、最大 G、襟翼与起落架限速）时，插件按机体数据判；**机体没给就不判**，不会拿现实航空的数字套上去 —— 这是故意的，因为《简单飞机2》是游戏物理，现实数字在这里没有意义。

## 建议使用工具调用能力较强的模型

轻量模型可能出现「说要提醒但其实没调工具」的情况。遇到这种反馈，第一件事是确认用的是什么模型。

《简单飞机2》目前处于抢先体验阶段，游戏更新后物理和数据都可能变化，插件以**运行时读到的数值**为准，不会硬编任何游戏常量。
