# 和猫娘一起开飞机（简单飞机2副驾驶）

让猫娘坐在《简单飞机2 SimplePlanes 2》的右座，当你的副驾驶：读仪表、判阶段、报检查单、扫告警、做导航。

**这个插件是只读的** —— 它只读数据、只给提醒，不会碰你的操纵杆。
飞机始终由你驾驶。

---

## 它能做什么

| 你说 | 她会做什么 |
| --- | --- |
| 「我现在飞得怎么样」 | 读出离地高度、海拔、空速、升降率、航向、油门，以及当前飞行阶段 |
| 「姿态正常吗」 | 报俯仰、滚转、迎角、侧滑、G 值、马赫数 |
| 「有什么要提醒我的吗」 | 扫一遍告警：失速、超速、过载、近地、坡度、起落架、油量…… |
| 「下一步该干什么」 | 按当前阶段跑检查单，逐项标出 已完成 / 待办 / 读不到 |
| 「还有多远」 | 给出到目标的距离、方位、「往哪边转多少度」和预计到达时间 |
| 「油还够吗」 | 报油量百分比、发动机运转情况、机体损伤 |
| 「帮我总结一下」 | 一次给全：阶段 + 告警 + 检查单 + 导航建议 |

她会**给出判断**，而不只是念数字。比如你在进近时收着起落架往下掉，她会直接说：

> 【紧急】离地 150 m 且在下降，但起落架还是收起的 —— 放起落架。

---

## 关于「只读」

本插件没有任何一个工具会给游戏发送指令。这不是保守，是刻意的设计：

- 副驾驶的职责是**看、算、提醒**，动手的是机长（也就是你）
- 《简单飞机2》还在抢先体验，物理与数据随时会变，把操纵权交给外部程序风险太高
- 所以面板上也**没有**任何「帮我操作」的按钮

如果你看到猫娘说「我帮你放了起落架」，那是模型在胡说 —— 请当成 bug 反馈。

## 安装

需要**两部分**配合。

### 1. 游戏侧：SP2-Bridge 模组

模组在游戏内监听 `http://127.0.0.1:21580`，按 `docs/bridge-protocol.md` 提供只读遥测接口。

配套模组仓库：
**[LShangPiao/N.E.K.O-SP2-Bridge](https://github.com/LShangPiao/N.E.K.O-SP2-Bridge)**

它是 BepInEx 5（Mono）插件，装法见它自己的 README（`install.ps1` 一步到位）。
协议文档也写得足够细，任何语言照着实现都能接 —— 模组本身不依赖 N.E.K.O.。

装好并重启游戏后，浏览器打开 <http://127.0.0.1:21580/ping>，看到 `{"ok":true,...}` 就说明模组在正常工作。

> 模组目前**尚未在实机上完成字段确认**：姿态、速度、迎角、过载这类由几何关系
> 推算的字段开箱即用，空速、油量、发动机等字段需要用它的 `/probe` 接口确认一次
> 真实字段名。详见模组 README 的「现状」一节。

**没装模组也想先试试？** 起一个模拟服务就行：

```powershell
python tools/mock_bridge.py --scenario cruise
```

它按同样协议提供假数据，面板会动起来，告警和检查单也能看到效果。
`--scenario` 可选 `cruise` / `approach` / `stall` / `ground`。

### 2. 本插件

在 N.E.K.O 插件中心导入安装，然后在插件页启动。

### 验证

打开「副驾驶仪表盘」面板，点「检测连接」，看到「已连接」就成了。

连不上时依次确认：游戏正在运行 → 模组已装好 → 装完重启过游戏 → 模组端口和插件里的 `bridge_url` 一致。

## 配置

在 N.E.K.O 的插件设置里（或面板的「设置」页）可以改：

- **bridge_url** —— 模组监听的地址，默认 `http://127.0.0.1:21580`
- **timeout_seconds** —— 请求超时，默认 12 秒
- **poll_interval_seconds** —— 面板自动刷新间隔，默认 3 秒
- **auto_brief_enabled** —— 自动播报开关，默认开
- **auto_brief_interval_seconds** —— 自动播报间隔，默认 20 秒
- **告警阈值** —— 近地高度、下降率、坡度、低油量、迎角、超速预警比例

> 改端口要改**两处**：模组侧的配置和这里的 `bridge_url`。

阈值只影响「什么时候提醒你」，不影响游戏本身。

### 自动播报：为什么它不用你开口

以前是「你问一句、它读一次」。现在游戏一开，插件就在后台每隔
`auto_brief_interval_seconds` 读一次仪表，把压成一小段的状态放进角色的上下文
（`push_message` 的 `ai_behavior="read"`）：不打断对话、不弹提示，但**你下一句话
说出口的时候，它已经知道飞机现在什么高度、什么速度、有没有告警**。

同一时刻只会保留最新一条，所以不用担心上下文被喂爆；游戏没开时完全不播报。
不想要就在设置里把 `auto_brief_enabled` 关掉，退回问答式。

## 关于限速数据

插件的所有超速 / 过载告警**只以机体自带的 `limits` 数据为准**。
机体没给 Vne、失速速度、最大 G，插件就**不判**，界面上显示「机体未提供」——
绝不会拿现实航空的数字往上套。

《简单飞机2》是游戏物理，现实里的 Vne、失速速度在这里没有意义。
宁可说「不知道」，也不给一个看起来很像真的假数字。

---

## 建议使用工具调用能力较强的模型

轻量模型可能出现「说要提醒但其实没调工具」的情况。
遇到这种反馈，第一件事是确认用的是什么模型。
