# 猫娘广告部：杂鱼桌面占领计划

用户主动开局的复古广告整蛊小游戏。支持安全词退出。

在 N.E.K.O. 主界面体验广告套广告、资讯弹窗、多层假叉页游广告，以及当前猫娘的嘲讽与吃瘪反馈。

广告内容为猫娘计划宣传与真实插件市场推荐。用户主动开局，可以尝试关窗、拖开广告，也可以点进宣传内容；随时输入安全词或使用退出快捷键结束。

## 版本状态

当前版本为 **v0.2.0**，游戏已接入猫娘主界面。已有 v0.1.0 标签对应早期独立游戏页原型。升级前请阅读下方使用条件与已知限制；本版本不包含 Steam 宿主程序的修复。

## 当前功能

- **主界面广告**：保留原有基础弹窗、广告套广告、含猫量体检和插件推荐，新增资讯类与页游类两种模板，同时最多显示三张广告。
- **资讯广告**：纯文字排版，包含栏目、标题、摘要和推荐区；文字内容与版式分别维护。
- **多层假叉广告**：每张页游广告有三个 ×，创建时随机确定唯一真关闭，在该窗口存续期间保持不变。
- **关窗整蛊**：假关闭、关闭按钮躲避、关掉后再赠送一张等交互。
- **正式宣传海报**：已接入猫娘计划与插件市场海报。ad1.0 基础图文广告和 ad2.0 页游广告共用约 1.45:1 的图片规格，保留各自外观；资讯仍为纯文字。
- **真实宣传跳转**：广告标题、正文、整张图片和宣传按钮可进入对应宣传页或插件详情页。图片和按钮指向同一目标，点 × 不会同时打开链接。
- **当前猫娘反馈**：使用当前角色的文字气泡、表情和宿主语音链路；语音关闭或不可用时仍可使用文字反馈。
- **独立启停**：一键启动／关闭插件与开始／结束本局分开。启用后先待命，不会直接弹广告。
- **随时退出**：支持安全词、自定义 Windows 全局退出快捷键和真正的结束入口。
- **本地网页**：插件面板保留控制功能，通过带“（网页）”注释的按钮进入独立本地广告部网页，查看广告样张与宣传导航；游戏仍在猫娘主界面进行。
- **断连防护**：待机和游戏中均有固定重试宽限，退出使用本局标识与停止确认，防止迟到回复误关新局或复活旧局。实际 Steam 宿主仍有待处理的请求收尾问题，见下方已知限制。

插件推荐取自市场实际数据，夸张标题属于戏仿；市场不可用时使用内置猫娘计划宣传。链接由用户点击打开，不自动安装插件。

桌面宿主通过系统默认浏览器打开宣传页，使用浏览器自身的标签页和关闭按钮；普通网页模式打开当前浏览器的新标签页。打开失败会提示错误，不回退到宿主的无边框子窗口。

## 使用条件与开局

当前开发版需要兼容的 N.E.K.O 插件 SDK、Windows 全局热键支持，以及额外配置的主界面桥接。静态资源无需单独前端构建。

主界面桥接需要在宿主 `index.html` 与 `chat.html` 中加入本插件的静态脚本引用。**仅安装插件包不会自动完成主界面接入**；桥接连接前，营业台不允许开局。接入前应备份宿主模板，宿主更新覆盖模板后需重新核对桥接引用。

1. 在宿主中安装开发版插件与主界面桥接，重新加载猫娘主界面。
2. 在插件管理器启动「猫娘广告部：杂鱼桌面占领计划」并打开营业台。启用插件只进入待命，不会自动弹广告。
3. 确认主界面已连接，检查或自定义退出快捷键，并选择是否启用语音反馈。
4. 阅读退出说明，点击「杂鱼♡让本喵占领桌面！」，首张广告随后出现在猫娘主界面。

插件就绪后，也可从主界面左上角入口开局或结束。**结束本局后插件继续待命；停用插件则同时结束本局。**

## 随时退出

> 输入安全词「广告下班」或按 Ctrl + Shift + 1 可以立即结束。

自定义快捷键后，以开局说明中实际显示的组合为准。

- **文字安全词**：在主界面或独立聊天窗口输入“广告下班”，支持粘贴和中文输入法，无需等待猫娘回复。
- **退出快捷键**：默认使用主键盘上方的数字 1。组合可自定义；全局热键注册失败会阻止开局，游戏中改键失败时保留原组合。
- **结束入口**：主界面入口内与营业台的结束按钮，或停止插件，均可结束本局。
- **语音安全词**：收到宿主语音转写事件后也会识别，但依赖转写成功；文字与全局快捷键不依赖模型回答。

安全词先在页面清除广告、计时器和广告语音，再通知插件；停止请求绑定原来的一局，并有限重试。全局退出快捷键由插件监听，页面另有退出状态观察通道。退出会作废本局的迟到响应与音频，不清空正常聊天语音。

广告跳转与短暂失焦会暂停新弹窗和广告语音，返回后继续。切换猫娘、关闭或刷新页面、停止插件会结束本局，重新加载或重启不会自动续局。

单次状态请求最多等待 6 秒；首次查询失败后进入 20 秒重连宽限，后续失败不会重新计时，只有有效的新查询成功才清除故障计时。持续失联时页面结束本局，后台另有 30 秒无有效心跳结束机制。恢复连接后需要用户重新确认开局，不自动续局。

完全无法连接后台时，页面安全词仍可先本地清场，后台的停止确认则需等待恢复连接或租约到期；全局快捷键需要插件进程仍在运行。安全词与真正的退出入口不属于假按钮机关。

当前其他平台尚未接入全局退出热键，因此不能开始桌宠广告游戏。

## 当前猫娘语音

待机时静默预生成当前猫娘的九类反馈，覆盖开场、关窗机关、查看广告、成功关闭和猫娘吃瘪等事件，沿用当前角色的语音配置。面板显示准备进度，并可继续／重试准备；切换角色后重新准备对应语音。

互动优先使用已准备的音频，按事件选句并排队，避免连续重复“等、等等……”和新反馈频繁打断上一句。首次准备仍依赖宿主语音服务；准备失败、关闭语音或暂时失焦时，以文字反馈为准。

## 已知限制与验收范围

- 实际 Steam 宿主的旧编译构建仍存在请求收尾可能卡住的问题；本次插件侧重连与退出防护不能视为已修好该宿主缺陷。宿主源码修复与实际 Steam 构建替换需要分别验收。
- 插件内部竖向面板在部分尺寸下的裁切与遮挡问题留到下一版本修正。
- 主界面接入、跨窗口输入和全局热键依赖宿主与系统环境。隔离浏览器测试、音频文件有效性检查不能代替实际桌宠操作与听音验收。

## 开发与验证

- `plugin.toml`：SDK 版本、面板和动作声明。
- `session.py` / `desktop.py`：本局状态、主界面连接、开局与退出。
- `hotkey.py` / `speech.py`：Windows 全局退出热键与当前角色语音适配。
- `static/engine.js`：广告内容、机关与暂停状态机。
- `static/ad-templates.js`：资讯与页游广告模板。
- `static/desktop-bridge.js` / `static/desktop.css`：主界面浮层、输入监听和猫娘反馈。
- `static/main.js`：营业台操作。
- `static/website.html` / `static/site.js` / `static/site.css`：独立本地网页。

将源码放在宿主的 `plugin/plugins/neko_ads/` 后，使用宿主开发环境，在宿主项目根目录运行：

```text
python -m pytest -q plugin/plugins/neko_ads/tests
node --test plugin/plugins/neko_ads/tests/*.test.cjs
node plugin/plugins/neko_ads/tests/ad-templates.browser.cjs
node plugin/plugins/neko_ads/tests/links.browser.cjs
node plugin/plugins/neko_ads/tests/controls.browser.cjs
node plugin/plugins/neko_ads/tests/connection.browser.cjs
```

回归覆盖迟到状态回复、请求失败与超时、持续失联、安全词、默认及自定义快捷键、全局热键释放、语音取消、多个 × 与广告链接。浏览器测试复用宿主 `frontend/plugin-manager` 的 Playwright 与本机 Edge，使用隔离测试页面，不打开用户真实聊天或实际宣传站点。

实际宿主验收还需检查主界面弹窗、当前猫娘反馈、跨窗口安全词和全局退出，不能仅以插件进程启动成功作为通过依据。
