# 🎣 猫爪渔力陪玩 (neko_fishpower)

> 渔力全开（How to Fish）猫娘陪玩插件——不是播报机器，是陪着你钓鱼的猫娘。
> N.E.K.O 插件 · 游戏遥测感知 · 屏幕情景互动 · 全程陪钓

## ✨ 功能特点

- 🐱 **猫娘陪钓**：抛竿、等鱼、收线、上鱼——全程有猫娘陪着你，像朋友一样
- 👀 **屏幕情景互动**：猫娘会看你的屏幕，看到鱼种/Boss/图鉴就自然聊两句（OCR 感知）
- 🧠 **懂游戏的知识库**：收线技巧/饵料学问/烤鱼/赌场/Boss 战/图鉴收集——她真的懂
- 🎯 **只在值得说的时候开口**：稀有鱼/新图鉴/Boss/大输赢才说话，不刷屏不复读
- 🎭 **多口吻切换**：傲娇/萝莉/御姐/冰山……15 种口吻可单选可融合
- 📊 **完整面板**：状态/活动/成就/口吻/播报/LLM 配置，暗亮主题

## 🎣 怎么玩

打开《渔力全开》，猫娘自动连接感知游戏状态。直接聊天即可：

- 「**钓到什么了**」→ 查看当前状态
- 「**什么饵钓鲨鱼**」→ 知识库回答
- 「**我跟你赌**」→ 猫娘陪你打赌（赢了唱歌）
- 「**傲娇点**」→ 切换口吻

## 🔧 安装

1. 将 `neko_fishpower` 发布包放入 `N.E.K.O` 插件目录
2. 启动 N.E.K.O → 插件管理 → 启用「猫爪渔力陪玩」
3. 启动《渔力全开》，开钓吧喵~

## ⚙️ 前置

- **游戏**：《渔力全开》（How to Fish, Steam）
- **mod**：`mod/` 源码编译的 `NekoFishpower.dll` 放入游戏 BepInEx/plugins
- 屏幕互动需要 mss + 宿主 RapidOCR（自动下载模型）
