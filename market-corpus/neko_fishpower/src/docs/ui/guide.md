# 🎣 猫爪渔力陪玩（neko_fishpower）使用指南

渔力全开（How to Fish）的猫娘钓鱼陪玩插件：mod 读取游戏状态，猫娘陪你钓鱼、赌鱼、烤鱼、打 Boss，全程播报不冷场。

## 快速开始

1. **装 BepInEx 5**：用你现有的 BepInEx 5 整合包（arcxingye HowToFish100Players 带 BepInEx 5.4.23.5），把 `BepInEx/`、`winhttp.dll`、`doorstop_config.ini` 解压到游戏 exe 所在目录（`How to Fish\` 内层）
2. **放 mod**：把编译好的 `NekoFishpower.dll` 放到 `BepInEx/plugins/`（与 HowToFish100Players.dll 共存）
3. **装插件**：把本插件放入宿主插件目录，重启宿主
4. **开游戏**：启动渔力全开，mod 会自动监听 TCP 9877

> mod 编译：`dotnet build -p:GAME_DIR="游戏exe所在目录"`（netstandard2.1，BepInEx 5 Mono 兼容）。
> 首次运行 mod 会自动把全物种图鉴推给插件（知识库自动生成）。

| 事件 | 猫娘反应 |
|------|---------|
| 抛竿 / 咬钩 | "浮漂动了！来了来了喵！" |
| **上钩** | "钓到鲈鱼了喵！2.3kg，值 45 金币（图鉴新鱼！）" |
| 跑鱼 / 海鸥抢鱼 | "跑掉了喵…" / "海鸥叼走你的鱼了！！" |
| 卖鱼 | "卖鱼入账 45 金币喵" |
| 赌场（轮盘/老虎机） | "轮盘开奖：红色！" |
| 烤鱼 | "鱼烤好啦喵！香气扑鼻！" |

| 图鉴新鱼 | "图鉴新鱼：鲱鱼！23/87 了喵！" |

## 常用指令

- 「钓到什么了」→ 当前钓鱼状态
- 「这鱼值钱吗」「什么饵钓鲨鱼」→ 知识库问答
- 「开启/关闭播报」→ dry_run 开关
- 「傲娇点/话痨点」→ 切换口吻（可组合）

## 面板

- **总览**：状态卡（岛屿/金币/图鉴/鱼饵/手持/Boss/赌场）+ 最近渔获
- **口吻**：多选融合（傲娇+话痨…）
- **播报**：dry_run 开关、频率、类别开关
- **LLM 配置**：配置自建 LLM 深度问答，留空自动降级模板

## 开发

- `mod/`：BepInEx C# mod（hook 游戏事件 → TCP 推送）
- 插件架构参考 neko_pawpilot（遥测/仲裁/口吻/LLM 三级链路）
