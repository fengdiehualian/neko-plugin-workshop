## 第一次设置

1. 点击「新建」，填预设名称，备注可不填。
2. 选择核心 API 和辅助 API，再展开「API 管理簿」填写对应的 Key。
3. 如果要指定模型，展开「自定义模型与跟随方式」，打开「启用自定义 API」，选择厂商并填写模型 ID；选「自定义」时，还要填地址和 Key。使用内置模型可以跳过这一步。
4. 点击顶部「保存预设」。保存后会自动测试，鼠标移到灯上可以查看功能、模型和结果。
5. 想让 N.E.K.O 使用这套配置，点击「应用到 N.E.K.O」并确认。

> 保存是存到插件里；应用才会切换 N.E.K.O 的配置。

## 已有配置怎么新建

- 「基于当前 API 页面新建」：带入 N.E.K.O 已保存的服务商、模型设置和自定义 API 开关状态，Key 需要自己填写。
- 「复制一个预设」：选择要复制的预设，点击「创建副本」。Key 也会一起复制，然后可以改名称和备注。

## 添加自己的厂商

1. 在「API 管理簿」末尾点击「＋」，填写名称、连接地址和 Key，再点「保存厂商」。
2. 保存后，厂商会以绿色名称出现在列表里。📝 用来编辑，× 用来删除；删除后还要保存预设。
3. 到下方模型的厂商下拉框中选择它，再填模型 ID。

「保存厂商」会一起保存当前预设的修改。厂商只添加在插件中，应用时才把地址、Key 和模型 ID 填到 N.E.K.O。

如果 × 不能点，先把使用它的模型切换到其他厂商，或点击「恢复为跟随核心／辅助 API」。

## 日常切换

点击左侧要用的预设，再点「应用到 N.E.K.O」。修改过内容时，先保存。切换可能结束正在进行的对话，建议聊完再切换。

关闭「启用自定义 API」会保留填写内容，应用时本体也保持关闭。GPT-SoVITS 沿用本体的独立启用方式。

灯的颜色：绿是连通，红是失败，黄是未测试，蓝是测试中，灰是未启用或不支持测试。需要重测时，点击「测试连通性」。

已保存的 Key 不会显示出来，保持不动即可；输入新 Key 会替换，点击「清空 Key」才会删除。
