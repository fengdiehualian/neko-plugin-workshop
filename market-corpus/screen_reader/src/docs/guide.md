# 屏幕阅读器（screen_reader）使用说明

让 YUI 看见你的电脑屏幕：截图、窗口识别、文字识别（可选）。

## 能做什么

| 操作 | 说明 |
|---|---|
| 全屏截图 | 截取整个屏幕，返回 PNG 文件路径，YUI 的视觉能力可直接查看 |
| 前台窗口截图 | 截取当前活动窗口（如某软件、网页、游戏的界面） |
| 前台窗口识别 | 返回当前窗口的标题、进程名、PID、尺寸 |
| OCR 文字识别（可选） | 提取屏幕中的文字（弹窗、聊天、代码、文档等） |

## 怎么用

直接对 YUI 说：

- 「看看我屏幕」「截个屏」「帮我看看这个界面」→ 全屏截图
- 「把这个窗口截下来」→ 前台窗口截图
- 「现在前台是什么窗口」→ 窗口识别
- 「把这段弹窗文字读出来」「识别屏幕上这段字」→ OCR（需 Tesseract）

## 截图存哪

截图保存在：

```
%LOCALAPPDATA%\N.E.K.O\screen_reader\captures\
```

按时间命名，YUI 返回路径后可交给视觉能力直接查看，也可由你自行打开。

## OCR 引擎安装（可选）

OCR 需要 Tesseract-OCR 引擎：

1. 下载安装 [Tesseract-OCR](https://github.com/tesseract-ocr/tesseract/releases)（Windows 安装包，勾选 Chinese Simplified 语言包）
2. 安装后确保 `tesseract.exe` 在 PATH 中
3. 重启 N.E.K.O，OCR 即可用

未安装时自动降级：OCR 请求会返回截图路径，YUI 改用视觉能力直接看画面。

## 安全说明

- 只在对话中按需截屏，不做静默持续录制
- 截图仅保存在本机，不上传任何第三方服务
- 不采集输入框中的密码、验证码等敏感输入画面
