# 记账猫娘 · neko_ledger

让猫娘帮你记账，而且会**按花销的离谱程度换语气**。

```
记账，面条10元        →  记好啦～「面条」10 元，喵～
记账，面包300元       →  面包 300 元？！这个价格是不是有点夸张了呀……喵～
记账，猫粮120元       →  嘶——猫粮 120 元？！人家可是猫诶！哈气！
```

## 三种语气

| 触发条件 | 语气 | 例子 |
|---|---|---|
| 日常花销 | **可爱卖萌** | 记好啦～「面条」10 元，喵～ |
| 金额离谱 | **吐槽乱花钱** | 面包 300 元？！你确定没按错小数点吗？ |
| 猫咪 / AI 相关 | **哈气** | 这钱花得人家尾巴都炸起来了，哈气！ |

猫咪和 AI 类花销会哈气是有理由的 —— **猫娘自己既是猫又是 AI**，
所以「猫粮」和「API 订阅」这类开销触发她的角色内梗。

## 人设优先（重要）

用户的人设可能明确写着「绝对不生气 / 温柔」。插件会**读当前猫娘的人设**，
检测到这类约束时把哈气**降级为温和的念叨**：

```
默认：    猫粮 120 元？！人家可是猫诶！哈气！
降级后：  猫粮 120 元呀……唔，人家有一点点心疼，不过记好啦喵～
```

降级是**显式**的：结果里会带 `hiss_downgraded` 字段说明原因，不做静默处理。

判定逻辑在 `_tone.persona_allows_hiss()`，顺序很重要：

1. **先**找「不生气 / 不会生气 / 不擅长生气 / 温柔」这类**否定式**
2. **再**找「会生气 / 生气时」这类肯定式

顺序反了会把温柔人设误判成可以哈气 —— 因为「生气」这个词往往正好
出现在「不会生气」这种否定句里。测试里专门覆盖了这个边界。

也可以用 `check_persona` 入口直接问插件：「这个猫娘能哈气吗？依据是什么？」

## 「离谱」怎么判定

两个独立条件，命中任一即算离谱（都能在配置里调）：

| 条件 | 默认值 | 说明 |
|---|---|---|
| 绝对金额 | `> 200 元` | 简单直接 |
| 相对同类 | `≥ 同类均值 × 4` | 需要至少 3 条同类记录，样本太少不判 |

比如你平时外卖 15 元，某天记了 80 元的外卖，就会触发同类倍数（5.3 倍）。

## 聊天里怎么用

插件注册了 4 个 LLM 工具，正常说话就行：

| 工具 | 会命中的说法 |
|---|---|
| `add_expense` | 记账，面条10元 / 买了个键盘399 / 今天打车25块 / 花了50吃饭 |
| `expense_summary` | 今天花了多少 / 这个月开销 / 本周记账 |
| `recent_expenses` | 最近记了什么 / 上一笔是什么 |
| `delete_last_expense` | 记错了 / 删掉刚才那笔 / 撤销 |

金额解析支持口语写法：

- `10元` `10块` `￥10` `十元` `一百二十元`
- 省略单位：`买了个键盘399`（只在消费动词之后才认，避免把版本号当金额）
- 角：`两块五` = 2.5、`十块五` = 10.5

## 分类

内置 10 个分类，按关键词匹配：**猫咪 / AI / 餐饮 / 交通 / 购物 / 居住 / 娱乐 / 医疗 / 学习 / 其他**。

猫咪和 AI 两类会触发哈气，其余按金额判定。

## 数据存放

账本存在插件自己的目录：

```
%LOCALAPPDATA%\N.E.K.O\plugins\neko_ledger\ledger.db
```

**不写角色卡。** 记账是插件自己的数据，没有理由动用户的人设 ——
这一点和「喵语十级」那类需要改人设的插件有本质区别。

## 配置

```toml
[ledger]
absolute_threshold = 200.0    # 离谱金额阈值
category_multiplier = 4.0     # 同类倍数阈值
min_samples = 3               # 同类判定最少样本
snark_enabled = true          # 吐槽开关
hiss_enabled = true           # 哈气开关
respect_persona = true        # ★ 尊重人设，人设不让生气就不哈气
cat_suffix = ""               # 句尾落款，留空则随机
emoji = true                  # 日常记账配表情
catgirl = ""                  # 留空 = 当前猫娘
```

想预览效果又不想写进账本，用 `preview_expense` 入口。

## 入口点

| 入口 | 作用 |
|---|---|
| `add_expense` | 记一笔 |
| `preview_expense` | 预览语气（不写库） |
| `expense_summary` | 花销汇总 |
| `recent_expenses` | 最近记录 |
| `ledger_status` | 账本状态 + 当前语气设置 |
| `check_persona` | 人设哈气许可 + 依据 |

## 已知限制

1. **金额解析靠规则，不是万能。** 复杂表述（「打八折后 120」「AA 制我付一半」）
   解析不出来时会明确报错，让你换种说法，**不会猜金额** —— 猜错比不识别更糟。
2. **分类靠关键词。** 冷门条目会落到「其他」，不影响记账，只是统计粗一点。
3. **语气由模型输出。** 插件把台词和语气标签交给猫娘，最终措辞可能被她的人设润色。
   如果她人设很强烈，可能不完全照念。
4. **人设检测是启发式的。** 它找关键词，不是理解语义。如果你的猫娘用很特别的措辞
   表达「不会生气」（不包含常见词），检测可能漏掉 —— 这时可以手动关掉 `hiss_enabled`。
5. 只记支出，不记收入。
