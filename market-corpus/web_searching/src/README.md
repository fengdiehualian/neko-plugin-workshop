# 联网搜索插件

独立开发的联网搜索插件，让猫娘具备联网搜索能力。注册为 @llm_tool，猫娘可在遇到知识盲区时主动调用。

## 功能特性

- **智能引擎选择**：根据查询语言自动选择最佳搜索引擎
  - 中文查询：知乎 → 百度 → 搜狗 → Bing → DuckDuckGo
  - 英文查询：DuckDuckGo → Bing → 百度
- **多引擎支持**：集成知乎、百度、搜狗、Bing、DuckDuckGo 五大搜索引擎
- **智能去重**：基于 URL 规范化去除重复结果
- **摘要提取**：自动从正文提取关键摘要
- **页面抓取**：fetch_page_content 工具可抓取任意 URL 正文

## 版本历史

## 配置说明

插件会自动根据用户 IP 选择搜索引擎，无需额外配置。
