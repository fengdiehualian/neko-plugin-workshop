# 猫娘语音频道桥 0.7.1

此插件与 Windows EXE 分开安装。导入 `.neko-plugin` 后，打开连接面板，粘贴 EXE 复制的连接链接；自动启动后台，无需手动调用插件入口。

称呼、角色和语音服务沿用猫娘配置。默认仅回应当前猫娘称呼，可在 EXE 关闭过滤。免费模式使用本体现有语音会话；不包含后续版本的本地 ASR / 文字中转方案。

虚拟音频线模式：本体输出 CABLE Input → EXE 采集 CABLE Output → KOOK 内置虚拟麦克风。首次使用按 EXE 配置向导完成试音。详细说明见仓库 `docs/使用说明.md`。

频道昵称提示通过宿主 SDK 提交；提交成功不代表模型已消费，不能保证多人称呼准确或隔离记忆。本分支面向一对一使用。

本源码依据 0.7.1 开发记录恢复；发布插件是重新构建的标准包，不是留存原始二进制。宿主接口参考提交 `cd17a21164ae5e734040042efd2b7cb810944e9f`。测试：`python -m unittest discover -s tests -v`。
