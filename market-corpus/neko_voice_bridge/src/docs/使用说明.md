# 猫娘语音桥 · Windows 桌面版 0.7.1

推荐普通用户使用 **NekoVoiceBridge-Setup-0.7.1-x64.exe** 中文安装程序。安装至当前用户目录，生成桌面和开始菜单快捷方式，可在 Windows“已安装的应用”中卸载。普通安装不需要管理员权限。

本次历史版本发布提供安装版 EXE，不另附便携目录。不要同时启动两份语音桥。

**neko_voice_bridge.neko-plugin 仍独立提供**，请在猫娘插件管理器导入 0.7.1 并重启插件进程。程序连接后会检查版本；版本不匹配时会暂停启动接收并显示更新提示，不需要重新登录账号或重新安装声卡。

首次启动自动显示四步配置向导：连接猫娘 → 选择并确认输出线路 → 登录 KOOK 并入房 → 测试频道声音。最后须用另一账号听到声音后亲自点击完成；检测到音频包并不等于对方一定听到。向导可暂时收起，也可通过右上角“配置向导”重新打开。

升级前先退出旧程序，再运行新安装包。安装、升级和卸载均保留原有配对、KOOK 登录、过滤设置和诊断；不会卸载猫娘插件或虚拟声卡，也不会自动清除账号数据。卸载只删除程序文件和快捷方式。不自动添加开机启动或后台更新。

本版无代码签名，Windows 下载/运行时可能显示发布者未知或安全提示；正式大范围发布前应使用发布者自己的签名证书。本地已验证 ASAR 内程序及安装包内容，**Windows 实际安装、覆盖升级和卸载仍需在测试机上验收**。语音功能基于用户已确认可用的 0.6.1 链路。

多人频道会逐句提交频道昵称，并要求猫娘回复朋友时先叫对方昵称；对本人的称呼沿用人类档案。不需要账号绑定。该规则通过本体上下文执行，真实多人效果仍需测试，本体记忆仍共用。

---

程序支持 VB-CABLE 虚拟音频线输出，针对“猫娘本体能回复，但插件拿不到回复音频、KOOK 无声”的情况。插件和 EXE 必须一起更新到 0.7.1。没有修改 N.E.K.O 本体，也不需要另买语音 API。

Windows 10/11 x64；EXE 包自带运行时，不需要 Python、Node、FFmpeg 或额外浏览器。虚拟音频线模式需要额外安装 VB-CABLE 驱动（首次安装需要管理员权限和重启）；驱动不在便携包内。猫娘本体仍需单独安装。

## 更新

1. 退出旧 EXE，运行新版安装程序。
2. 将单独交付的 `neko_voice_bridge.neko-plugin` 导入猫娘插件管理器，重启插件进程，确认面板版本是 0.7.1。
3. 原配对仍有效；若未连接，在 EXE 复制连接链接，粘贴到插件连接面板。无需调用插件入口。

## 虚拟音频线设置

1. 点击 EXE 的“打开驱动官网”，从 [VB-Audio 官网](https://vb-audio.com/Cable/) 下载 VB-CABLE Windows 驱动，按官方说明安装并重启。
2. 在 **猫娘计划的输出设备** 中选择 **CABLE Input (VB-Audio Virtual Cable)**。不要改 Windows 默认输出。保持猫娘窗口打开，停止猫娘桌面麦克风。
3. 在 EXE 的“猫娘输出线路”中点击“刷新虚拟设备”，选择 **CABLE Output (VB-Audio Virtual Cable)**，点击“启用虚拟音频线”。每次重启 EXE 后需重新启用；不会偷偷恢复录音。
4. 打开 EXE 内的 KOOK 窗口，登录专用账号、加入频道、开启麦克风。KOOK 输入仍选 **猫娘语音桥（内置虚拟麦克风）**，因为程序需在发送前按称呼过滤。这里不要改选系统 CABLE Output。
5. 点击“开始接收”。在另一个账号/设备上试听。

声音路径：**猫娘 CABLE Input → 系统音频线 CABLE Output → EXE 收集整句并检查称呼 → KOOK 内置虚拟麦克风 → 频道**。

CABLE Input 是播放端，CABLE Output 是录音端，名字容易看反。只有猫娘应向这条音频线输出；不要把系统、KOOK 或其他程序送入同一条线，不要开启 Windows“侦听此设备”。正确配置时猫娘不再通过原扬声器播放；EXE 自己也不会在本机监听采集的声音。用第二个设备听频道时，该设备当然仍会播放频道声音。

## 按顺序验证

1. **测试频道提示音**：只检查 EXE → KOOK。另一个账号应听到一声提示音。如果听不到，先检查 KOOK 静音、频道发言权限和发言模式；首次试音建议自由发言并关闭降噪。
2. **测试本体 → 音频线 → KOOK**：点击后，在猫娘本体用文字让她说一句简短的话。这个测试暂时暂停频道收音，不检查称呼。输入音量条应跳动；等本体安静 2.5 秒后，整句声音发往频道。
3. **正常频道对话**：在另一个账号上说“当前猫娘称呼 + 问题”。称呼自动同步猫娘设置。检查频道显示名、识别结果和发送状态。

“检测到音频包发出”代表本地发送证据，不能代替另一个账号确认听到声音。

- 本体说话时音量条不动：先检查输出是否真的设为 CABLE Input、选择的录音端是否对应、Windows 桌面应用麦克风权限是否允许。
- 音量条动，但 KOOK 无声：看频道提示音结果及发送错误。导出诊断会包含音频线帧数/音量/错误和 KOOK 发送状态。
- `NEKO_CABLE_NO_AUDIO`：等待超时，没有收到音频线声音。
- `NEKO_CABLE_DEVICE_LOST`：设备停止或采集帧中断，停止接收后重新启用。
- `NEKO_CABLE_UPDATE_PLUGIN`：插件过旧，请更新独立插件包。
- `NEKO_HOST_NO_TRANSCRIPT`：本体没有把识别结果返回插件；换输出设备不能解决这个输入/转写问题。

## 当前行为与限制

- 默认仍是插件音频模式；选择启用后才切到虚拟音频线模式。切换需先停止接收。
- 虚拟音频线模式保持本体语音会话到采集结束，如果本体向插件返回完整、匹配的回复音频，则直接使用；否则继续等音频线收集整句。两路只选一路发送，防止重复回复。仍需要本体返回本轮转写，才能检查称呼和关联成员音轨。
- 默认开启“仅回应称呼”；关闭后无需叫名字也可回复，音轨来源检查仍保留。开关在 EXE 的“猫娘语音服务”内，自动保存并同步到插件面板，切换时取消待处理对话。本体本身可能已经生成回复，这属于共用会话行为。
- 按句缓冲，会增加延迟；以 2.5 秒静音结束，含尾部静音最长 30 秒，长停顿可能截断一句。超长或设备中断时拒绝发送残缺缓冲。当前只串行处理一句，不支持多人同时持续对话。
- 同一条系统音频线没有角色/句子标识，只能专供当前猫娘使用。不能可靠隔离同时说话的多个角色或本体主动发言。
- 停止接收会丢弃本轮缓冲并取消频道发送；采集保持就绪以显示音量，但不保留录音。点击“切回插件音频”或退出 EXE 会释放采集设备。若需恢复本机扬声器，请同时在猫娘中切回原输出设备。
- 音频仅在内存暂存；导出诊断不含录音、发言原文、昵称、设备 ID 或配对密钥。
- 已完成本地 Chromium 模拟音频线 → 采集 → 进程通信 → WebRTC 发送测试；用户已确认 0.6.1 的真实频道双向语音可用。0.7.1 安装版仍需在 Windows 测试机验证安装、升级、卸载及频道回归。

驱动安装依据：[VB-Audio 官方下载与安装说明](https://vb-audio.com/Cable/)。EXE 只打开官网，不自动安装驱动、不修改系统默认设备。

## 称呼过滤开关

在“猫娘语音服务”把“仅回应称呼”切到“关闭”，即可尝试无需叫名字的频道对话。默认开启过滤，升级保留已有选择。若对话失败，导出诊断并附同时段本体日志；诊断记录过滤开关与最终音频来源。
