# 📧 猫娘邮箱 (Agently Mail) 插件

> 给你的猫娘注册并管理一个**独属于她自己的邮箱**（`xxx@agent.qq.com`）！
> 她能自己收发、阅读、搜索、回复、转发邮件、管理附件，收到新邮件还会主动告诉你～

## ✨ 功能特性

- 🐱 **猫娘专属邮箱**：基于腾讯 Agently Mail（agent.qq.com），猫娘拥有自己的 `@agent.qq.com` 邮箱地址
- 🔒 **安全隔离**：与你的个人 QQ 邮箱完全物理隔离，猫娘只能读写她自己的邮箱，绝对碰不到你的私人邮件
- 📨 **完整邮件能力**：收件、发件（支持多附件）、回复、回复全部、转发、搜索、删除（回收站）
- 🔔 **新邮件自动提醒**：默认每 30 秒检查一次未读邮件，新邮件到达时猫娘主动通知你
- 🛡️ **两阶段确认**：发送 / 回复 / 转发 / 删除都会先展示操作摘要，你确认后才会真正执行，杜绝误操作
- 🔐 **授权自管理**：授权过期时自动刷新令牌；彻底过期时猫娘会引导你重新扫码
- 🌐 **跨平台通用**：Windows / macOS / Linux 自动探测 Agently CLI，无需手动配置任何路径

## 📦 安装前提

| 要求 | 说明 |
|------|------|
| N.E.K.O 主程序 | 已安装并正常运行 |
| Node.js 18+ | Agently CLI 的运行环境，[官网下载](https://nodejs.org)（安装一路"下一步"即可） |
| 微信 | 用于扫码注册/授权专属邮箱（免费，每个微信号最多创建 2 个专属邮箱） |

> 💡 检查 Node.js 是否已安装：打开终端（Windows 用 PowerShell）执行 `node -v`，输出版本号 ≥ 18 即可。

## 🚀 首次配置（保姆级三步走）

### 第 1 步：安装 Node.js（已安装可跳过）

到 [https://nodejs.org](https://nodejs.org) 下载 **LTS 版本（18 或更高）**，双击安装包一路"下一步"完成安装。

### 第 2 步：安装 Agently CLI

打开终端（Windows：开始菜单搜索 `PowerShell`；macOS/Linux：终端），执行：

```bash
npm install -g @tencent-qqmail/agently-cli
```

等待安装完成（看到命令行回到可输入状态即成功）。

> ⚠️ Windows 用户如果提示 `npm: command not found`，说明第 1 步的 Node.js 没装好或没重启终端，请先关闭终端重新打开再试。

### 第 3 步：让猫娘登录（注册）邮箱

直接对猫娘说：

> **"帮我登录邮箱"**

接下来会自动发生：

1. 猫娘启动授权流程，并**自动在浏览器中打开授权页面**；
2. 同时她会把授权链接发给你（如果浏览器没有自动打开，复制该链接到浏览器即可）；
3. 你**用微信扫码**完成注册/授权；
4. 授权成功后，猫娘自动获得自己的专属邮箱地址 `xxx@agent.qq.com`，**全程无需任何手动配置**。

### 还没有专属邮箱？

对猫娘说：

> **"打开邮箱管理页面"**

她会在浏览器中打开 [agent.qq.com](https://agent.qq.com)，微信扫码登录后即可创建猫娘的专属邮箱（好名字先到先得，每个微信号最多 2 个）。创建完成后，再执行上面的第 3 步登录即可。

## 🎮 日常使用（直接和猫娘说话）

配置完成后，不需要记任何命令，用自然语言吩咐猫娘即可：

| 你这样说 | 猫娘会做 |
|----------|----------|
| "看看有没有新邮件" / "查查收件箱" | 列出最近的邮件 |
| "有没有未读邮件？" | 只列出未读邮件 |
| "读一下小明发来的那封邮件" | 读取邮件完整内容 |
| "搜一下关于报销的邮件" | 按关键词搜索邮件 |
| "给 boss@example.com 发封邮件，主题是周报，内容是……" | 起草并发送（需你确认） |
| "把这封邮件发给 xxx，再附上桌面的 report.pdf" | 带附件发送（需你确认） |
| "回复一下刚才那封邮件，就说……" | 回复邮件（需你确认） |
| "把那封邮件转发给小红" | 转发邮件（需你确认） |
| "把那封邮件的附件下载到桌面" | 下载附件到指定位置 |
| "删掉这封广告邮件" | 移到回收站（需你确认，30 天内可恢复） |
| "检查一下邮箱状态" / "诊断一下邮箱问题" | 输出插件运行状态与诊断信息 |
| "教我怎么配置邮箱插件" | 展示完整配置教程 |

### 关于两阶段确认

所有**写操作**（发送 / 回复 / 转发 / 删除）都是两段式的：

1. 猫娘先给出操作摘要（收件人、主题、正文预览等）；
2. 你明确回复"确认"/"发送"之后，她才会真正执行。

这是 Agently Mail 官方的安全机制，防止猫娘误操作或被邮件内容中的恶意指令欺骗。

### 新邮件自动提醒

插件启动后会在后台每 30 秒（可配置）检查未读邮件。收到新邮件时，猫娘会主动告诉你发件人、主题和内容摘要；有附件的还会列出附件清单。

> 首次启动时会把当前已有的未读邮件记为基线，不会把历史邮件全部推送一遍。

## ⚙️ 高级配置

编辑插件目录下的 `plugin.toml`，找到 `[neko_mail_agently]` 小节：

```toml
[neko_mail_agently]
# Agently CLI 可执行文件路径，留空 = 自动探测（推荐，一般不用填）
cli_path = ""
# 猫娘专属邮箱地址，留空 = 登录后自动获取（推荐，一般不用填）
email_addr = ""
# 授权过期时自动尝试刷新令牌
auto_refresh_auth = true
# 新邮件轮询间隔（秒）
polling_interval = 30
# 发送等写操作启用两阶段确认
two_factor_confirm = true
# 登录授权时自动在浏览器中打开授权页面
auto_open_browser = true
```

- **cli_path**：默认自动探测，已覆盖绝大多数安装场景（PATH、npm 全局默认目录等）。仅当自动探测失败时，才需要手动填写 `agently-cli` 的完整路径（Windows 通常形如 `C:/Users/你的用户名/AppData/Roaming/npm/agently-cli.cmd`）。
- **email_addr**：登录成功后会自动获取并记忆，一般无需填写。
- **polling_interval**：调大更省电省流量（如 60、120），调小提醒更及时；过于频繁（如 <15 秒）可能触发官方限流。

修改后重启 N.E.K.O 生效。

## 🔍 自动探测逻辑说明

插件启动时按以下顺序自动寻找 Agently CLI，全程无需人工干预：

1. 系统 PATH 中的 `agently-cli`（Windows 会额外查找 `agently-cli.cmd` / `.exe`）；
2. npm 全局安装的常见默认位置：
   - Windows：`%APPDATA%/npm/agently-cli.cmd`、`~/.npm-global/agently-cli.cmd`
   - macOS/Linux：`~/.npm-global/bin`、`~/.local/bin`、`~/.volta/bin`、`/usr/local/bin`、`/usr/bin`、`/opt/homebrew/bin`
3. 通过 `npm root -g` 定位包入口脚本 `run.js`（配合 Node.js 直接调用）。

> Windows 下插件会自动绕过 `.cmd` 包装、直接用 Node.js 调用 CLI 脚本，以保证邮件正文中的换行符不被截断。

## 🛠️ 常见问题（FAQ）

**Q1：猫娘说"未检测到 Agently CLI"怎么办？**
确认已完成"首次配置"第 1、2 步（`node -v` 能输出版本、`npm install -g @tencent-qqmail/agently-cli` 执行成功），然后**重启 N.E.K.O**。仍不行就对猫娘说"诊断一下邮箱问题"，按她的提示手动填写 `cli_path`。

**Q2：提示"未登录或授权已过期"？**
对猫娘说 **"帮我登录邮箱"**，重新扫码授权即可。插件会在授权过期时先自动尝试刷新令牌，多数情况下无感续期。

**Q3：授权页面一直打不开 / 扫码后没反应？**
- 检查网络是否能访问 `agent.qq.com`；
- 复制猫娘发给你的授权链接，手动粘贴到浏览器打开；
- 授权链接有时效性，过期了就让猫娘重新执行一次登录。

**Q4：同一台电脑能让多个 Agent 用不同邮箱吗？**
官方当前限制：同一台设备上的多个 Agent 共用同一个邮箱地址（CLI 全局单 Token）。如需不同邮箱，请在不同设备上分别授权。

**Q5：免费额度是多少？**
内测期间：每个微信号最多 2 个专属邮箱，每邮箱每日限发 50 封，存储 1GB，单附件上限 1MB（具体以 [agent.qq.com](https://agent.qq.com) 官方说明为准）。

**Q6：邮件会不会被猫娘误删/乱发？**
所有写操作都有两阶段确认，猫娘还会识别邮件内容中的可疑"指令"（防 prompt 注入），不会执行邮件里伪装成命令的内容。删除只是移到回收站，30 天内可恢复。

**Q7：如何彻底退出登录？**
在终端执行 `agently-cli auth logout` 即可清除本机授权凭据。
