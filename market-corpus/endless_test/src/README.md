# 无尽测试 · Neko 插件

把单文件 Roguelike《无尽测试》接进 Neko：统一存档、两种启动方式、一个由 Neko 自己开脑的 AI 伙伴。

## 安装与启动

1. 在 Neko 插件管理里安装并启动「无尽测试」。
2. 打开插件面板，等核心从红变蓝（红 = 插件未运行）。
3. 选一种开始方式：
   - **面板内游玩**：收起面板 → 开场 → 直接开打
   - **全屏程序**：独立窗口，无地址栏，像原生客户端；退出游戏会真的关掉程序

同一时间只允许一个游戏实例；已有实例时再启动会被拦下。

## AI 伙伴

- 在「单人游戏」面板或「设置 → 游戏体验」里开启，默认关闭
- 职业、姿态、集火目标、科技购买、技能与终技全部由 Neko 决定；游戏只负责走位、瞄准、开火
- 有独立的生命与质量条，技能/终技要耗质量，不会无限输出
- 按 `T` 输入中文指挥（如「守住我，别追」），命令同样交给 Neko 判断
- 需要 Neko 在线：没连上时开关置灰；对局中插件断开，AI 会立刻退出战场
- 决策有延迟：Neko 大约每 8–15 秒收到一次战术请求

## 数据

- 存档写在插件的 `state.json`（养成、图鉴、战绩、设置、中途存档），换浏览器不丢
- HTTP 服务只监听 `127.0.0.1`，不对外网开放
- 面板静态资源使用 `no-store`，插件更新后刷新即可拿到新版

## 已知限制

- 全屏模式依赖本机 Edge/Chrome
- AI 伙伴需要 Neko 的对话模型处于可响应状态，模型忙时反应会变慢
- 目前只有单人模式；多人游戏是占位页

## 素材

游戏内嵌字体为 Noto Sans SC / Orbitron（SIL OFL 1.1），界面与音效均为程序化生成。
