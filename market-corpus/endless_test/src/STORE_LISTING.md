# 商店展示信息草稿

**名称**：无尽测试

**一句话简介**：带 Neko AI 伙伴的单文件 Roguelike：8 职业、60 节点科技树、4 个 Boss，统一存档，面板/全屏双入口。

**分类**：游戏 / 单机

**详细说明**：

《无尽测试》是一个可以直接在 Neko 里开打的 Roguelike 射击游戏。

- **两种启动方式**：插件面板内游玩，或弹出独立全屏程序（无地址栏、无标题栏，退出即关程序）
- **统一存档**：养成、图鉴、战绩、设置、中途存档都保存在插件里，换浏览器不丢
- **8 个职业**：刃 / 炮击 / 场控 / 链接 / 重装 / 游击 / 蚀刻 / 相位，每局自由构筑，60 节点科技树
- **AI 伙伴**：Neko 自己选职业、决定战术与科技、决定什么时候放技能；有独立生命与质量条，可以按 T 用中文指挥
- **12 页图鉴**：怪物、精英词缀、事件、职业、区域、技能、元素、终极节点、混合节点、AI 伙伴、难度、术语
- **4 个 Boss**：PRISM → HEX TYRANT → FRACTAL → NEXUS，带阶段与失衡条

**已知限制**：AI 伙伴需要 Neko 在线且模型可响应；全屏模式依赖本机 Edge/Chrome；目前只有单人模式。

**推荐截图**：面板双入口、对局画面、AI 伙伴 HUD、图鉴、Boss 战。
