MINECRAFT AUTONOMOUS · JAVA 1.21.1

让猫娘走进 Minecraft

Node 运行环境、游戏执行核心、3D 观战、贴图、音效音乐和 YUI 模型都在完整包里。没有 Python、Git 或 npm，也可以使用。

1 · 资源已经准备好

通过「一键安装.cmd」打开本页，表示资源校验和安装已成功。安装器自动使用较短的当前用户缓存目录，无需管理员权限、注册表修改或手动开启长路径。以后不用重复准备；升级时先停止旧版游玩，再运行新版安装入口，保留已有配置和数据。

如果你是直接打开本页，请先完整解压安装包，再双击「一键安装.cmd」；不要在压缩包内直接运行。

2 · 导入 Neko 插件

打开已经安装的 N.E.K.O，在「插件中心 → 导入」选择同目录的 @PLUGIN_FILE@。不要把源码目录直接复制进去。

找到插件安装包

首次使用，在 Neko 的「插件 API」保存一个支持工具调用的模型，并在本插件「配置」页绑定 decision。升级后若显示旧离线环境不匹配，先点击插件里的「使用已安装的新版运行环境」；账号、模型、记忆和数据保留，不会自动开始游戏。已有模型槽可以直接复用；支持图像时也可绑定 vision。

3 · 选择服务器，开始自主游玩

进入插件「配置与控制」。本机服务器默认 127.0.0.1:25565，也可选千灯纪公网预设或填写自己的服务器。离线昵称留空会自动生成并保存。

点击「开始自主游玩」。默认开启当前猫娘解说、自动打开 3D 观战，持续运行到你点击停止。角色、外观、扩展资料和进阶模型选项均可稍后调整。

仍需本人已有的 Neko、可用规划模型和有权进入的 Java 1.21.1 服务器。本包不包含 Minecraft 服务端、私人世界、账号密码或共享 API 密钥。正版账号由本人完成 Microsoft 官方授权；浏览器音效和音乐需要允许播放。Neko 自定义端口在插件高级设置中修改。
