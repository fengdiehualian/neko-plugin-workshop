## 本次改变

模型使用官方插件用途 `decision` / `vision` / `fast`，不读取主 API 或辅助 API 的密钥。公开角色资料、已选择的记忆和近期消息通过显式上下文进入 MC 规划；每个使用者沿用自己的猫娘与现有 TTS。配置见 [模型、人设与角色声音](model-and-voice.md)。

普通台词复用同一次 MC 规划响应，支持正文 JSON 与工具调用专用字段。MC 控制器在原生参数校验和执行前去掉宿主语音字段，身体队列仍由独立框架和原生核心负责。语音与动作均按真实回执记录，不互相冒充完成。

现场进一步确认官方定时回调的事件循环会在回调返回时关闭。0.6.2 让独立语音定时线程等待自己已领取的有界发送任务，避免台词在发出前被取消；不阻塞 MC 身体或额外请求解说模型。停止、换角色/世界、用户新意图、死亡代际及有效期仍会撤销旧台词，确认不明不重发。

## 收件人步骤

1. 完整解压 ZIP，先停止旧版插件的自主游玩，再运行最外层 `prepare.cmd`。它准备资源，不启动游戏或模型。
2. 在 Neko 插件中心导入同目录的 `.neko-plugin`，保留既有私有配置。不要把 Git 仓库目录直接复制进去。
3. 在「插件 API」创建模型，在本插件详情绑定 `decision`；可选 `vision`、`fast`。配置服务器/本人账号，按需开启当前猫娘的规划台词并填写本机 Neko 地址。
4. 显式启动。默认不自动登录或运行；正版授权由本人走官方流程，浏览器音频需要播放许可。千灯纪仍是按实际数据启用的独立扩展，标准 Minecraft 默认可用。

正式交付还需将通过验收的完整附件随对应公开 Release 提供，并按官方 Market 流程提审。本说明及本地候选本身不代表那些外部步骤已完成。
