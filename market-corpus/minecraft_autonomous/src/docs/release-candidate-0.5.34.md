# 0.5.34 动作衔接维护候选

此前协调器从上一轮规划结束计普通决策冷却。短任务已经成功结束、或子目标报告完成后恢复父目标时，仍可能额外停等默认 10 秒，再开始下一次规划。

本候选固定 `agent-mc-autonomy` 0.1.51 / `05f5d47cf7502b29b9f61c05f7c6e235efb60f21`。协调器在已跟踪的身体任务收到成功终态、或真实目标发生切换时允许一次立即衔接。新一轮开始即消耗该机会，重复终态不能再次触发。普通观察、失败重试、服务退避、显式停止和未知动作交付仍保留原约束；运行中的原生任务继续执行，不新增身体队列或推测性模型请求。

修复位于独立框架，薄适配器只固定依赖。Neko 主程序和 SDK 无代码改动。核心仍为经校验的 0.5.4 / `7e8b9750015bb31b7307da6dfb03a90302ce9cef`，上游检出更新与实际运行包分别记录。

7 项定向回归、441 项源码测试和 441 项隔离 wheel 消费测试已通过，覆盖短任务接续、观察节流、失败与模型退避、重复回执和目标切换。适配器检查及现场部署以独立运行回执为准。

该修改仅去掉多余冷却，模型推理耗时、错误参数、缺少材料和规划质量仍影响动作间隔。长期无人值守生存、全新机器安装和完整场景一致性尚未通过；不据此打 tag、发布 Release 或提交 Market。
