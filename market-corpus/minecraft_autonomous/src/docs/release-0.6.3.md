# 0.6.3：首次使用与完整交付

## 玩家体验

- 完整 Windows x64 离线包新增「一键安装.cmd」与中文入门页；原有 prepare.cmd 保留。一次准备 Node、后端、观战、1.21.1 贴图/声音/音乐、浏览器与 YUI 外观，不需要构建工具。
- 首页集中连接、模型绑定入口、开始、停止与观战。外观、角色、扩展、观战诊断和统计折叠。

- 新配置默认不限决策轮数，持续到显式停止；自定义有限轮数保留。导入、保存及插件加载都不自动开始游戏。

## 安装仍有明确前提

需要已有 Neko、可用规划模型和可进入的 Java 1.21.1 服务器。首次通过 Neko 官方 Plugin API 保存/复用模型槽，在插件配置页绑定 decision；支持图片时可绑定 vision。主/辅助 API 的凭据不私自复制给插件。

包中不含 Minecraft 服务端、模型权重、私人世界、共享账号/密码/密钥。千灯纪只是可选连接预设，专用能力依实际扩展数据启用。浏览器播放音频需要允许，正版账号由本人完成官方授权。
