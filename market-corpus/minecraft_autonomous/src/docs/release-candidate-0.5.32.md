# 0.5.32 维护候选

2026-10-15 的现场记录显示：鱼获、进食与自然回血已实际发生，但随后连续的预执行拒绝让游戏队列长时间为空，模型仍反复提出把熟鱼当作合成产物的计划。运行层需要减少这些无效提案在后续输入中的重复。

固定依赖为 `agent-mc-autonomy` 0.1.49，源码 `2643d960e1076a4d58e5f6d26ead80ba7e7161e1`；游戏核心继续使用已验证的 0.5.4，源码 `7e8b9750015bb31b7307da6dfb03a90302ce9cef`。可视化仍是显式配置的独立来源，Neko 主程序和 SDK 无补丁。

本次运行层改动：

- 压缩大型回执时保留原生的未入队标记。
- 有未解决错误时，仅保留最新一组明确未执行的单独行动交流；较早的同类提案不再反复放进请求。
- 保留已受理任务、未知回执、查询及混合调用。原文仍存档，有限的原文查询入口和当前纠错保留在动态尾部，固定前缀不变。

源码与隔离 wheel 均通过 425 项离线测试，涵盖完整调用配对、原文留存、未知结果保护和宿主独立性。这些测试不调用模型或游戏。

薄插件通过 58 项 Python 测试、4 项界面数据测试、Ruff 和官方 `check --release --market-release`。候选安装包为 `minecraft_autonomous-0.5.32.neko-plugin`，SHA256 `622bb6161df61f6846ede0d0ed160fd31a65d0efbbfb7cf511bcc7a1e94647ba`，载荷哈希校验通过，未包含私有运行目录。官方 CLI 仍提示 `[plugin].models` 字段未识别，以及未设置 tag 对齐环境；没有因此修改 SDK 或创建 tag。

现场已通过正常停止和排空流程更换独立执行器；本地配置、世界存档与核心版本保留。自然产生的规划请求已实际省略旧拒绝交流，系统提示及工具目录的固定前缀哈希保持一致，后续容器取物和存鱼有原生终态回执。Neko 的 5,273 个受保护文件与主程序、插件管理器、测试服、模型四组进程身份保持不变。模型仍有缺少前置材料的提案，因此只确认这次输入精简机制已部署并触发，不宣称自主生存问题已全部解决。

插件检查、部署和现场观察分别记录。输入精简不保证模型会作出正确的下一步决策，也不等于长期自主生存通过。清洁机器安装、完整观战功能及无需维护反馈的持续生存仍是发布待办；尚未创建发布 tag、GitHub Release 或 Market 版本。
