# 可复制的首次投稿文案

名称：Minecraft Autonomous / 我的世界自主生存

仓库：jcs130/n.e.k.o_plugin_minecraft_autonomous

简介：让 N.E.K.O 以自然语言目标参与 Minecraft Java 1.21.1。独立 MC 框架负责实际动作、原生队列和细化规划；Neko 负责高层决策、反馈与角色解说。

功能说明：

默认通过标准 Mineflayer 接入普通 Java 1.21.1 服务器。可投递目标、插入新反馈、查询生命与饥饿、背包、位置、原生动作进度、模型用量及完整回执。支持 Neko 公共模型槽或显式配置的模型提供商；可选图像模型缺失时回退文字事实，可选快决策模型缺失时使用规则。独立框架可脱离 Neko 运行，插件保持薄适配，不修改 Neko 主程序或 SDK。观战支持已配置的同账号共享可视化；服务器专用技能、魔力和资源只根据实际连接数据启用。

使用要求：

N.E.K.O、Node.js >=22、显式安装并通过固定哈希检查的 MC 核心、允许该账号接入的 Java 1.21.1 服务器，以及支持工具调用的规划模型。安装默认不开启自主游玩，需要用户配置服务器与模型后手动启动。完整 3D 观战需要另行准备共享 renderer 与匹配的原版资源。

当前投稿状态：

发布候选准备中；长期自主生存、清洁机器安装与完整观战一致性仍需实际验收。本说明不把短时动作、模型声明或单元测试描述为已完成无人值守长期生存。最终投稿时按最新验收结果更新这一段。

隐私说明：

游戏账号认证、模型密钥和本地存档仅保存在用户配置/运行目录，不进入插件源码或发布包。模型调用只使用用户配置的提供商；可选远程记忆与快决策服务需显式配置。不会把工具回执和内部规划发到游戏公屏。
