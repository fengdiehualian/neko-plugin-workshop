# 0.5.36 维护候选

此前复用 Neko 模型网关没有继承主脑的语义上下文，身体规划主要得到通用生存规则和现场。此版固定 `agent-mc-autonomy 0.1.53`（`minecraft-ai-friend@f206b2b2c846fb3f23b06010ef43c7834ca6ff60`），把主脑选出的身份、人格、当前关注和相关记忆带进实际规划请求。

- Neko 继续拥有人格、个人记忆、高层判断、解说与官方语音；插件通过既有复盘工具回传有界材料，不修改宿主程序/SDK，也不另跑总结模型。
- 公共角色接口需显式配置；空配置使用主脑的人格投影。两者均注明来源，不声称复制了完整主脑请求。
- 中立共享端口和上下文预算只在 MC friend 维护。人格放固定前缀，变化信息放末尾；相关记忆最多六条并保留原 ID、来源、原文。
- 投影绑定运行会话及当前意图，十分钟过期。关闭共享或切换角色会清除旧投影，用户新反馈使旧投影失效。公开状态只有计数/哈希，没有私人正文。
- 离线回归：核心源码及隔离 wheel 各 458 项，薄适配器 69 项。覆盖真实 controller 请求、review 到 mailbox 的版本绑定、隐私输出、停止/过期/切换角色和配置竞争。

仍需按运行回执检验人格与选出的记忆实际进入自然规划、主脑自然表达及长期生存。离线通过、人物满血或通知受理均不等于长期生活验收；未创建 tag、Release 或 Market 提交。
