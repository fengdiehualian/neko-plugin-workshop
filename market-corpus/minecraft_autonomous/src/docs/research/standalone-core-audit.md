作者：jcs130。Minecraft 执行插件来自用户自己的 `minecraft-ai-friend` 项目；
Cortico 是曾经接入的宿主，不作为本插件的作者或产品来源。
本仓库的 N.E.K.O 脚手架及实际第三方依赖分别保留其许可证。

基线：`7889ce261a2309d94400b739c6198468d8271d83:packages/agent-mc-world`。
这个基线的运行依赖和公共类型已独立，但仅检查 import 还不够：
默认资源路径、环境变量、全局标记、脚本格式和聊天唤醒条件仍留有旧约定。

## 本次改动

- `backend/patches/0001-independent-minecraft-core.patch` 是可审查的源码补丁。
  构建从固定 Git 提交提取原文，核对补丁 SHA256 后应用，再编译和生成类型。
  原提交和补丁分别记录，绝不把修改后的源码称为未改动的上游发行包。
- 资源目录使用 `agent-mc-resources`，启动器、全局 Symbol、浏览器对象、DOM 标记及内部钩子使用独立命名。
  凭据子进程使用 `AGENT_MC_CREDENTIAL_FILE`；显式浏览器路径使用 `AGENT_MC_BROWSER_EXECUTABLE`。
  不回读旧框架环境变量，也不扫描旧服务端口。
- SDK 删除旧宿主配置/数据迁移入口；只接受 `agent-mc.procedure/v1`，拒绝旧宿主脚本格式。
  没有自动转换、删除或重写已有脚本、凭据、账号、身体身份及执行账本。
- 聊天唤醒按配置的角色/账号名称判断，删除写死的旧角色别名。
- 可选的方块权限扩展使用 `agent_mc:break_acl`；必须有匹配的服务端实现。
  保护拒绝、过期权限的 unknown 判定和动作前权限检查继续保留。
- 受管本地世界标记名改为 `agent-mc-realm.json`。本插件固定关闭本地开服和客户端启动，
  不读取现有存档。如果其他软件要迁移旧存档，须另行显式保留原 UUID，不能自动重新认领。
- 发布归档采用文件允许清单：独立源码、运行产物、公开类型和必要许可证。
  不携带旧 Fabric 客户端模组、旧宿主迁移工具、旧部署脚本、旧发行配置和旧框架来源清单。
  包内 README 指向独立项目和实际构建方式。
- 插件默认版本及核心默认协议为 Minecraft 1.21.1；内置 1.20.6 viewer 资源不随包发布。
  外部现代化页面仍需单独验证身份与版本；本次没有改动外部可视化仓库。

## 复现和边界

`backend/build.py` 在打包前运行 `backend/check-core.mjs`，审查源码、编译产物、公开类型、
文件清单、默认配置、权限边界、脚本格式及公开导出；加载阶段禁止网络与旧框架导入。
安装器同时核验归档、基础提交、补丁摘要及每个编译文件；没有清理补丁的旧包会被拒绝。
原始上游 checkout 和旧运行目录保留，作为可追溯基线，不进入插件的运行路径。

本次实测：207 个源文件、196 个运行文件及 241 个公共类型文件通过审计；
归档共 651 个文件，扫描其中 500 个自有代码/文档文件，旧框架标识为 0。
58 项核心回归和 43 项插件测试通过。全新目录安装后的真实 MCP stdio 能列出 24 个工具，
保持 disconnected / Minecraft 1.21.1；并发状态查询、等待取消通过，网络与旧框架加载均被禁止。
这些结果不代表真实进服、长期生存或外部观战页面绑定已经通过。

仓库仍可能搜索到旧名称：删除补丁的减号行、否定测试、禁止导入的检查器、历史研究说明。
这些用来解释并防止旧依赖回流，不会加载框架、读取旧配置或执行迁移。
新构建的运行源码和公开类型必须通过零旧标识审计。
