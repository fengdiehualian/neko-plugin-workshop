# 0.6.70 公开测试版

下载 `Minecraft-Autonomous-0.6.70-Windows-x64-offline.zip`，完整解压后运行「一键安装.cmd」，再在 Neko 插件中心导入同目录的 Windows x64 / CPython 3.11 `.neko-plugin`。完整包包含 Node、固定游戏核心及依赖、共享 3D 观战、1.21.1 原版贴图、音效/音乐、浏览器运行时和 YUI 普通皮肤/YSM。无需另索取资源或手工准备 vendor。

首次仍需本人已有的 Neko、支持工具调用的模型和可以进入的 Java 1.21.1 服务器。插件复用官方 `decision` 模型绑定，支持本机 OpenAI 兼容服务；多模态可绑定 `vision`，快决策未配置时使用规则反射。不会预设作者的付费模型、API 密钥、账号或世界，也不会在导入、保存或重开 Neko 时自动进服。

相对 0.6.6 的主要修复：

- 规划与身体执行允许在受保护的有限条件下重叠；同一阶段的普通主脑修订不再浪费正在进行的推理。继续使用唯一的原生动作队列，危险、停止、新阶段与真正用户反馈仍及时处理。
- 保留服务器消息、拒绝和原生失败证据；没有实际变化的观察不再伪装成恢复。未派发的坏 JSON 不作为有效工具示例回灌，纠正仍有次数边界。
- 修复逐技能字段错误合并，支持正常查找、攻击和交互目标；副手换装使用原版交换协议，保留严格槽位和游标确认及差异诊断。
- 修复背包预览盾牌位置、千灯纪背包入口识别及对应图标；专属规则和素材留在可选扩展，不改变普通服务器语义。
- 三叉戟使用原版 GUI 资源，罗盘按实际维度、时间与目标关系选择原版纹理帧；16 色旗帜及服务器实际同步的图案层正确解析。协议 767 的旗帜组件经过真实二进制往返测试。
- 修复生命上限与当前生命冲突时只显示一颗心的问题；界面容纳当前读数并明确标注不一致，不猜造服务器正确上限。

固定来源：自主框架 `0.2.65 / c5429b56e7a49eb5be16b513fb24332d0f73b7d4`；游戏核心 `0.5.7-rc.52 / bba59bb92a0b83d0321671a19f272eef38400cd1`；共享观战 `dd7c4011abe4e5e7498fe60740b0c23abe7fbb3f`。本版将最新观战源清单和完整离线运行资源一起交付，运行时不依赖作者本机的 renderer 覆盖路径。

已验证的图标范围包括实服背包 31 个非空格的图像、罗盘、三叉戟和可选扩展物品；旗帜额外使用隔离浏览器夹具检查普通染色、图案层和透明材质，不把夹具称为实服持有物。原始协议、实际观测、模型输出、任务受理、任务终态和目标成功分别记录。

已知限制：长期无人干预生存、规划效率、Microsoft 本人账号全流程、全部自定义物品模型和 YSM 手持特效仍需继续验收。未知服务器人物头/自定义模型不猜造图标；部分特殊手持模型尚不支持。服务器生命上限读数不一致仍需服务端核对。网页音效/音乐受浏览器播放权限约束；自然音频生成完成不等于本轮桌面实际播放已确认。GitHub 发布与 Market 的检查、审核和上架分别记录。

插件保持薄适配；本版不修改 Neko 主程序或 SDK。升级前先正常停止旧版游玩，再准备新版资源并按官方流程导入，保留用户配置、账号和历史。
