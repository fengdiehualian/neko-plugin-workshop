# 0.6.6 公开测试版

普通用户下载 `Minecraft-Autonomous-0.6.6-Windows-x64-offline.zip`，完整解压并双击「一键安装.cmd」，再按中文入门页在 Neko 插件中心导入同目录的 Windows x64 / CPython 3.11 `.neko-plugin`。Node、后端及依赖、观战、贴图、音效/音乐、浏览器和 YUI 外观均随完整包提供，无需额外索取资源、安装 npm 或手工准备 vendor。首次仍需已有 Neko、可用规划模型和可进入的服务器；服务器、模型权重、私人配置和账号会话不随包提供。

相对 0.6.3：

- 脚下支撑根据实际碰撞和接触位置判断，覆盖边缘、半砖、雪层等情形；未知或尚未加载的数据不再冒称确定的空气。
- 服务器拒绝和原始错误进入匹配的动作回执、当前事实和复盘，不被后续查询覆盖。聊天引用、玩家台词和 HUD 状态不会直接冒充服务器权限错误。
- 近期消息以有界索引和原文查询入口进入每轮决策的动态尾部；纯查询或思考不再计作身体行动进展。共享消息接口与执行屏障保持一致。
- 同步共享水中状态判断，以及下述固定观战来源；继续保留通用 Mineflayer 与千灯纪可选扩展的边界。

- 检查并同步共享观战主干 `b5a41c37d8f503df5344762bd5df5e61c1734f4b`。兼容观战的手持地图默认折叠，展开后才绘图，并如实区分服务器原图、未收到像素及未支持的标记图层。
- 固定自治框架 `1fb12b8136155d2fefdb6ae4b4882ee09ba57359` / `0.2.4`，更新观战 Git 归档、源码摘要及 327 文件清单。Minecraft 引擎保持 `0.5.7-rc.7`，不把观战更新称为新的游戏内核功能。
- 当前原生观战使用独立入口。规范构建的两份原生脚本与旧版相同；运行目录构建只改变源码目录标签，按实际目录另核对服务脚本哈希。本次没有为原生页面增加手持地图面板，也不宣称画面功能因此改变。贴图、模型、音频和原版/扩展边界保持。

验证：相关地图测试 8 项、自治回归 1022 项、隔离 wheel 消费 108 项通过；薄插件 357 项、页面数据测试 11 项、Ruff 和官方 release/Market 结构检查通过。安装包入口、依赖和源码指纹单独核验；结构检查不等于公开发布、完整离线资源包交付或长期生存验收。

发布只交付薄插件和独立运行资源，不修改或重启 Neko 主程序/SDK。导入和保存默认不自动进服，显式停止始终保留。

现场部署：自有执行器正常排空，无未知派发后切换依赖；配置只更新 `viewer.renderer_directory`，引擎包、账号、模型、人设及其它配置保留。实际 `/3dview/build.json` 返回新来源摘要，两份服务脚本逐一匹配按实际运行目录预构建的哈希，原资源与外观摘要不变，真实连接和已收到区块的观战状态通过。重新连接千灯纪后生命 20/20、饥饿 20/20，Neko 主程序/桌面及模型保持原进程；这不是新的长期生存验收。

已知限制：长期无人干预生存和规划效率仍在优化；Microsoft 正版账号完整流程、千灯纪全部特色资源与完整场景表现尚未全部验收。兼容观战的手持地图更新不代表当前原生界面新增同名面板。网页声音需浏览器允许播放；本完整包面向 Windows x64 / Neko CPython 3.11，其他宿主组合需另行验证。GitHub 发布不等于 Market 审核已通过。
