# 0.5.37 维护候选

0.5.36 的现场检查发现当前 Neko 角色采用结构化性格档案，没有 `system_prompt` 字段。适配器错误地把空正文当作可用人格，导致身份及相关记忆进入了规划请求，但人格正文没有进入。

此版在自定义提示词为空时读取公开档案的显式性格字段白名单，同时兼容默认和旧版字段、字符串与字符串列表；不复制 `_reserved`、语音 ID、模型设置或整个角色对象。没有有效正文则返回不可用，让主脑通过既有回合回传人格要点。`persona_needed` 和 `memory_needed` 分开，避免仅缺人格就重复检索已选记忆。

核心仍为固定 0.1.53 / 0.5.4，本次无需重启游戏执行器。适配层 75 项回归覆盖空/缺失档案、结构化性格及私有字段排除；官方结构检查与真实运行记录另行留存。长期自主生活仍待验收，不创建发布 tag 或 Market 提交。
