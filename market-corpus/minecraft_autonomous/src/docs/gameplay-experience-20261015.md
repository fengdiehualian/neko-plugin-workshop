# 角色游玩、死亡复盘与观战维护

Minecraft Java 1.21.1 为主力。完整人格共享、原生队列、规划及死亡复盘在独立框架 `agent-mc-autonomy`/`agent-mc-world`；插件只负责 Neko 公共接口适配和随包外观素材。人格是主脑提供的中立投影，固定前缀承载身份/人格，当前意图和少量相关记忆位于动态末尾；生存指南只是按需参考，角色可按兴趣安排生活，明确用户目标仍优先。

实际死亡保留同一身体事件的 run/cursor/时间、现场和回执；默认等待4秒后请求重生，停止、提前原生重生或换连接取消等待。现有规划回合承担死亡复盘，通过 `death_review` 查询/记录带适用条件与证据的教训。记忆按世界、账号和 Agent 隔离；模型总结是待验证推断，不能作为生存能力提升的证明。没有额外模型循环。

Neko 随包的 `skills/gameplay-speaking.md` 由公共 SDK 注册进 `minecraft_autonomy_review` 的稳定工具说明；心跳通知指向该工具，fresh inspect 只附一份有界重点证据，最终判断不再重复技能正文或证据。沿用角色人格，用自然中文分享经历、自然停顿；不朗读内部背包、工具或控制状态。`speech_contract` 按当前语音回执区分受理、未知、忙碌/拒绝及缺省，受理不代表听见或播完；已排入或结果未知时不重复同句。插件只清理自己收到的 `spoken_text`，无法截获宿主普通工具前文字或最终回复，提示接线不保证所有生成或听感问题消失。没有新重点的例行复盘使用公共 `ai_behavior=read` 静默进上下文，回执仅为 context_only/deferred，不冒充主脑判断。重要变化、死亡和需要新策略的情况继续唤起主脑，用户提问正常回答。

共享观战显示层对收到的生物位置/步态做有界插值，轨迹保留最近8秒/最多24点；背包预览面对镜头，短窗口和点击保留约3.2秒，已关闭窗口明确标为操作回放。死亡效果由本人实际生命和生命周期触发，倒计时结束不作为已经重生的证明。

地形仅剔除由原始静态完整不透明形状完全遮住的内部方块；压缩保留它们的真实状态ID供房间遮挡及粒子碰撞使用。透明、液体、动态、部分模型或未接收邻居保守保留。近处范围扩大但维持扫描、渲染和事件字节预算，地形未变时复用快照，身体事件仍连续更新。

源码测试、独立安装、部署和真实画面分别验收。不诱发线上死亡，不修改或重启 Neko 主程序/SDK、Java 测试服及模型。长期无人值守稳定生存与完整场景一致性仍需真实观察；此更新不创建发布标签、Release或提交Market。

本轮接线审计修正了高级视觉工具被隐藏、失败/身体受限未进入主脑简报、同一复盘缓存丢掉新事件及已解决失败抢占预览的问题。拍照/地图/空间查询继续按需调用，原始图像仍需实际提供器成功和支持图像的模型；没有额外截图或分析循环。观战合并兼容的原始静态面、异步读回小地图，并保留原始几何、UV、法线和材质，不靠删掉未支持内容冒充性能完成。

插件面板增加自定义公网服务器草稿、千灯纪1.21.1预设、随包YUI外观入口与显式本机账户控制台。正版登录沿用核心官方设备授权流程；代码/令牌只在人类本机控制台出现。预设不自动保存或连接，Web外观不更改服务器皮肤。

可选 `decision_policy` 在已有模型回合内按新意图、风险、失败和新死亡选择常规/复杂预算，默认关闭。预算不超过上下文已保留的总输出空间，不切换端点、模型或显卡。直连参数按协议校验；供应商拒绝可选档位时仅成功回退后记住拒绝。Neko SDK未开放的推理参数明确回退，只使用本次输出预算；主脑人格与模型绑定保持归宿主所有。
