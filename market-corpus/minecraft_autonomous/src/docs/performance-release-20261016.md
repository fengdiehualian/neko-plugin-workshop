# 0.5.44 性能与发布准备记录

主力版本为 Minecraft Java 1.21.1。核心固定 `5171af57`，框架固定 `621cda08 / 0.1.61`；共享查看器固定 `6265b4f3`。源码更新、安装包检查、现场表现与公开发布分别记录。本版为内部候选，长期自主生活和完整场景一致性尚未通过。

## 已修复与验证

- 核心同步上游的操作经验、选择及采纳记录；修复早期终结回执跨世界取样和物品多堆叠覆盖问题。实际 64+10→64 记录为 74→64，历史原文保持。核心 954 通过、2 项跳过；框架 546 通过。
- 观战本人显示使用 50 ms 位置缓冲，相机和角色采用同一显示姿态。远端无关更新不再令当前地形全部重建，未知边界保守处理。HUD/地图/相机减少重复写入，增加可见帧间隔统计；不以平均 FPS 代替卡顿分析。
- 实际移动暴露了液体和生物群系染色重建的主线程长停顿。按快照保留最多 65,536 项精确缓存，约 4 ms 主动让出调度，并处理换维度、重生和取消时的资源归属。旧完整地形在新地形准备好后整体替换。原始几何、UV、颜色、状态和缺失数据语义保留。
- 配置页已在实际 Neko 宿主验证整页保存、非法端口旁的中文提示、本地资源元数据与外部观战边界。新增上游 `memory.read_preference` 的草稿往返兼容。千灯纪预设保留账号与认证方式，Microsoft 授权指引可见；测试草稿已取消，没有发起账号授权或连接预设服务器。
- 修复官方打包规则误排除公开 CA 的问题，唯一允许的 PEM 为 Certifi 公开证书集合；私钥、运行配置、世界、日志和开发目录仍排除。源码、wheel 和候选包各 112 项插件测试通过，7 项 Node 测试通过，官方候选结构与载荷校验通过。

## 可重复的离线性能证据

使用本人连接收到的同一地形快照和原版资源复放；测试采用 Node 调度，不等于浏览器/GPU 帧率测量。

| 工作 | 原总耗时 | 新总耗时 | 原最长连续计算 | 新最长连续计算 |
| --- | ---: | ---: | ---: | ---: |
| 9,131 个水方块网格 | 2,380 ms | 317 ms | 2,380 ms | 4.51 ms |
| 19,937 个水/草/树叶染色结果 | 6,993 ms | 1,072 ms | 6,993 ms | 4.67 ms |

网格的有序位置、颜色、UV、法线及索引字节摘要相同；全部染色结果摘要也相同。共享查看器完整套件 953 通过、14 项既有可选夹具跳过。首次全套因测试进程未提供 `minecraft-data` 解析路径失败，使用已安装锁定依赖后，失败单例和完整套件通过；未修改依赖或宿主。

约 4 ms 是协作调度目标，不是 GC、单次分配或 GPU 上传的硬上限；原有同步签名、房间和射线缓存仍需现场观察。运行端从固定提交副本构建，已核对服务源码摘要 `5bb682f0db05254cf6ead85809b2183a795f420038cc1eb6fa6004edc7f6f334` 与匹配 1.21.1 注册表。

## 发布边界

默认不自动启动或连接；通用 Mineflayer 能力和服务器扩展依照实际数据与匹配资源启用。固定后端和视觉伴随资产的安装、SHA 与准备命令见 [候选安装说明](install-candidate-20261016.md)。源码已普通推送主干，本地生成候选资产；没有创建 tag、公开 Release 或 Market 提交。

本次测试仍观察到死亡、饥饿消耗与反复搜寻；重生满血不证明已经恢复自主生存能力。食物取得、持续补给、庇护和长期存活需要继续验收。本人 Microsoft 首次授权、所有模型图像/文字回退和自然语音播放也未因离线测试自动视为通过。Neko 主程序及 SDK 的受保护文件与主服务、测试服、模型进程保持原身份。
