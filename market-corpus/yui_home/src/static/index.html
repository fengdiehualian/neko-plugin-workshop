🐾 Yui的家

和真实的 Yui 一起建造，在我的世界里一起生活。

首次使用：先解压完整项目包，退出 N.E.K.O.，运行包中的“安装Yui的家.cmd”，再启动 N.E.K.O.。此插件是配套控制入口，不包含桌面运行环境。安装位置改变后请重新运行安装脚本。

在“插件入口”里打开家园、建造或保存。家园用猫爪菜单操作，真实聊天在角色旁边的气泡中输入，共同建造阶段会写入 YUI 长期记忆。

Minecraft Java 1.21.6 → 多人游戏 → 127.0.0.1:55919

这个独立测试世界支持双向实时同步。导出的单人世界是保存时的快照。关闭桌面家园会安全保存并停止它的测试服务器。
