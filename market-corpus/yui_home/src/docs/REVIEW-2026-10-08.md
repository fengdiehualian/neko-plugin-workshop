# Yui的家 2.13.1 发布前审查

复核日期：2026-10-08。审查对象为市场配套控制插件，以及完整项目中的安装、鉴权、聊天、记忆、Minecraft 同步和角色逻辑。

## 完整性

- 两个原始 ZIP 的 CRC 全部通过，无越界路径或重复条目。
- 市场源码包的 13 个源文件全部匹配原始公开清单。
- 完整项目的 8,145 个文件全部匹配 PACKAGE-MANIFEST.json；清单自身不列入哈希，符合预期。
- 两个包中的原始市场源码逐字节一致。完整包的原始 .neko-plugin CRC 通过。

## 已修复

1. 启动进程遭到操作系统拒绝时原实现抛出异常；现在返回有错误码的 SDK 回执。安装读取和进程启动移至工作线程。启动回执明确仅为 launch_requested，不声称窗口或游戏已连接。
2. 原实现只依赖 JSON schema 提示风格和农场操作的合法值；现在在入口执行时再次校验，不合法输入不会发送给桌面运行环境。现场事件增加对象、关联编号、JSON 数据和长度校验。
3. 连接失效和现场回执确认失败现在可解释，保持“已提交”与“已生成/播音/施工”分离。
4. 显式报告 Windows 平台要求，并登记插件内的安装指引；入口名称和说明提供中英文 SDK 国际化元数据。清单的名称/说明保持当前 SDK 要求的字符串格式。

## 本次测试

- 原始 9 项 Python 测试通过；修复后扩展至 33 项，全部通过。覆盖本机 HTTP、鉴权、代理绕过、重定向拒绝、全部控制入口、失败回执、输入边界及场景消息关联。
- 8 组 Node 核心逻辑测试通过：world、cobuild、farm-plan、avatar-physics、avatar-wander、native-speech、native-inline-chat、native-chat-window。
- Node 测试的聊天/语音/窗口部分使用协议或窗口替身，不生成真实 Yui 台词，不代表真实桌面实机验收。
- Python Ruff 检查通过；官方 SDK 严格检查通过。最终发布包另外执行官方 release 检查、解包和 payload 哈希验证。

## 运行边界

- 本次环境为 macOS，未运行 Windows 安装脚本、N.E.K.O.exe、Windows Java 或原生 Minecraft 客户端。完整项目内的旧 Windows 验证 JSON 只作为作者此前记录，不冒充本次测试。
- 控制插件不能独立提供家园。完整桌面运行环境由作者单独提供，其安装会修改 N.E.K.O. 的 Electron 启动归档，并通过精确哈希阻止不兼容版本安装；升级宿主后需要重新核对兼容性。
- 当前同步范围是本机独立测试世界的指定方块区域；不宣称同步所有实体、容器、其他玩家或任意远程服务器。
- 此次公开内容仅为配套控制源码、测试和说明。原始完整私人项目、房屋/记忆存档、运行时会话口令、模型资源和宿主备份不进入公开仓库。
