# Yui的家

与 N.E.K.O. 中真实的 Yui 一起建造三维家园，把共同经历写入她的记忆。

版本：2.13.1；插件 ID：`yui_home`；目标平台：Windows。

## 安装前提

这是 **Yui的家桌面运行环境的配套控制插件**。它调用已安装的桌面家园，不提供独立的聊天模型，也不捆绑 N.E.K.O.、Minecraft 游戏客户端、服务器、Java、Yui 模型或私人存档。

首次使用应先取得 Yui的家完整项目包，在固定可写目录解压，退出 N.E.K.O. 后运行包中的 `安装Yui的家.cmd`。安装程序检查与本机 N.E.K.O. 版本的兼容性，并登记安装路径到 `%LOCALAPPDATA%/YuiHome/installation.json`；它会备份并适配 N.E.K.O. 的 Electron 启动归档。版本不兼容时安装会停止。家园运行环境可通过完整包的恢复脚本撤回。

然后重新启动 N.E.K.O.，在插件中心安装本插件。尚未安装完整项目时，插件提示“需要设置”，不会下载软件或修改 N.E.K.O. 安装目录。更换完整项目目录后重新运行安装脚本。

此公开源码仓库仅提供配套插件；完整项目包当前由作者单独提供，请勿将本机私人项目备份上传到市场。

## 功能

- 打开家园、逐块建造、导出原版结构 NBT 与单人世界快照。
- 在角色旁的气泡中，通过 N.E.K.O. 原有对话连接与真实 Yui 聊天。
- 听取真实 Yui 的建议，邀请她自主共建；共同经历写入当前 YUI 的长期记忆。
- Minecraft Java 1.21.6 本机测试世界双向实时同步，支持养猪、种田和钓鱼。
- 三维旋转、Yui 第一视角、拖动角色、重力碰撞、空中变猫；小猫可以自然走动。
- 原生风格猫爪菜单，窗口顶部可拖动，支持滚轮调整视角和窗口尺寸。

Minecraft 客户端通过多人游戏连接 `127.0.0.1:55919`。只有运行环境管理的本机测试世界实时同步；导出的单人世界是保存时的快照。

## 数据与通信

配套插件只读取本机安装登记和当前家园的会话口令，使用固定环回地址 `127.0.0.1:48931`；请求不经过代理，不跟随 HTTP 重定向。口令不会写入源码或返回给模型。聊天和场景事件交给 N.E.K.O. 原有 YUI 连接处理。运行环境按用户启用的功能保存房屋、共建日记和当前角色记忆。

## 插件开发与市场发布

仓库名称必须为 `n.e.k.o_plugin_yui_home`。设置 VS Code 的 `nekoPlugin.repoRoot` 为本机 N.E.K.O. 源码路径。在 N.E.K.O. 源码环境中执行：

```text
neko-plugin check <本插件源码目录> --release
```

仓库提供官方生成的 Verify 和 Release 工作流，以及安装路径、缺失运行环境、环回鉴权、重定向拒绝和启动行为测试。首次投稿审核通过后，再运行官方 `neko-plugin publish <本插件源码目录>` 发布可安装版本。首次审核申请和版本发布是两个步骤。
