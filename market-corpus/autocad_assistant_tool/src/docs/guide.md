# CAD辅助绘图 使用指南

## 这是什么

本插件让你用**自然语言对话**驱动 AutoCAD（及中望CAD、浩辰CAD）绘图。
你只需对 AI 角色说"画一个长100宽50的矩形"，AI 会理解意图并调用插件
把图形逐笔落到 CAD 画布上。

## 前置条件

- 已安装 AutoCAD（2018~2026 完整版或LT）/ 中望CAD / 浩辰CAD
- **手动启动 CAD 一次**（确保 COM 组件已注册），加载完成后再连接
- 插件本身零系统依赖，无需 pip 安装任何库

## 工作流程

1. **连接 CAD** — 对 AI 说"连接CAD"，或调用 `connect` 入口
2. **描述图形** — 用自然语言描述要画的内容
   - 例："画一个圆心在原点、半径50的圆，红色图层"
   - 例："画一个长100宽50高30的长方体，中心在原点，然后切到等轴测视图"
3. AI 自动拆解为多条绘图命令，逐条执行
4. 必要时让 AI "查看画布状态"（`get_status`）了解当前实体

## 坐标与单位

- 单位：毫米
- 2D 原点 (0,0)
- 3D 坐标 [x,y,z]，z 向上为正
- 颜色编号：1红 2黄 3绿 4青 5蓝 6品红 7白

## 典型对话

**用户**：帮我画一个标准A4图框，外框297×210，内框287×200。
**AI**：依次执行 4 条 `line`/`polyline` 命令绘制内外框，最后 `zoom_extents`。

**用户**：画一个底面半径20、高60的圆柱，再在顶部加一个半径20的半球，合并成一个零件。
**AI**：`create_cylinder` + `create_sphere` + `boolean_union`，再 `change_view` 切等轴测。

## 入口清单

| 入口 | 作用 |
|------|------|
| `connect` | 连接CAD（未运行时自动启动） |
| `disconnect` | 断开连接 |
| `get_status` | 查询连接状态/实体数/图层/实体句柄 |
| `get_capabilities` | 列出全部绘图命令及参数 |
| `draw` | 执行一条绘图命令（AI 画图主入口） |

## 常见问题

- **连接失败**：先手动打开 AutoCAD，等待许可证弹窗关闭后再连接
- **看不到3D立体效果**：让 AI `change_view` 切到等轴测视图
- **画错想撤销**：对 AI 说"撤销上一步" → `undo`
