# 1.3.9 发行范围与决定

决定日期：2026-10-15。作者已确定将 1.3.8 之后的全部更新一次性正式发行为 1.3.9。
本文取代此前的版本划分建议；当前发行不拆分多个版本。

## 发行范围

- 日记：目录、标题、搜索、分页、归档与阅读导航；固定记录日期与大字标题；
  手动直接生成、独立后台写作、最多两次尝试与 90 秒总期限、失败原因提示；
  移除整本日记清空入口，兼容已有记录。
- 情绪：角色自主性提示、工具状态结束规则、当前选择与变化历史、连续心情估计，
  以及默认 20 秒、可调 10–3600 秒的语气分析间隔和响应优化。
- 统计：热力图留白、月份对齐、活跃日颜色分档、窄屏横向查看及日期边界修复。
- 新增文案同步八种语言；宿主与生产数据保持不变。
- 动态壁纸、Wallpaper Engine 导入和视频加载优化属于既有 1.3.8 功能。

完整用户发行说明见 `tools/RELEASE_NOTES_1.3.9.md`。
CHANGELOG 顶部增加正式汇总，下面的同版本开发记录保留，不改写历史过程。
CHANGELOG 中更早的 1.4.0 至 1.5.0 是历史本地测试编号，不是正式发行序列。
