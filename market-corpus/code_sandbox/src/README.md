# 代码沙箱（code_sandbox）

让 YUI 在受限安全沙箱中执行 Python 代码的 N.E.K.O 插件。适合数学计算、数据处理、算法验证、逻辑推理辅助；系统命令、网络访问、文件写操作等危险行为一律拦截。

## 功能

| 工具 | 说明 |
|---|---|
| `run_code` | 在安全沙箱中执行 Python 代码，返回 stdout 与执行结果 |

- 数学计算：`2**100`、矩阵运算、概率统计
- 数据处理：JSON/列表/字典操作、排序、去重、统计
- 算法验证：写一段函数看输出是否符合预期
- 逻辑推理辅助：把问题拆成可验证的小计算

## 安装

1. 打开 N.E.K.O 客户端 → 插件中心
2. 搜索「代码沙箱」，点击安装
3. 无需任何配置，直接可用

## 安全机制（四层防护）

1. **静态扫描**：AST 预检，拦截 `os`、`subprocess`、`socket`、`open`、`exec`、`eval`、`getattr` 等危险调用（含 `__builtins__` 绕过路径）
2. **进程隔离**：在独立的 `python -I` 子进程中执行，与宿主环境完全隔离
3. **环境净化**：剥离 API Key 等敏感环境变量，沙箱内不可见
4. **资源兜底**：超时强制终止（默认 30 秒），输出截断（上限 50KB），防止资源耗尽

## 使用示例

- 用户：帮我算 2 的 100 次方
- YUI：调用 `run_code(code="print(2**100)")` → 返回 `1267650600228229401496703205376`

- 用户：这段代码有什么问题：`x = [1,2,3]; print(x[3])`
- YUI：调用 `run_code(...)` → 返回 IndexError 信息与解释

## 安全说明

- 危险调用返回明确错误提示，不会执行
- 沙箱内无法访问宿主的文件、网络与环境变量
- 若需要执行系统命令或网络操作，请勿使用本插件（它刻意不支持）
