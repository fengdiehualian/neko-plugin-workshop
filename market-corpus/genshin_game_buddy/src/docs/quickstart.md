# 原神游戏搭子 · 快速开始

这个插件让猫娘知道你现在在玩哪款游戏，然后换用那款游戏的语境和术语陪你聊。它不会去检测你在玩什么，也不需要你装任何游戏模组——由你（或猫娘自己）告诉它就行。

## 这个插件做什么

- 登记你当前在玩的游戏（原神、鸣潮等）
- 加载那款游戏的术语库，让它出现在猫娘的对话语境里
- 猫娘拿不准某个词时，可以随时查术语库
- 你说换游戏，它就换语境

## 这个插件不做什么

- 不检测你在玩什么。它不会看窗口标题、不会扫进程、不会截图、不会读游戏内存
- 不操作游戏。不会替你出牌、点地图、按技能
- 不做任何联网请求。术语库是本地文件，它也不自己调用任何模型

换句话说：它是一个"本地术语本 + 两个对话工具"，不是一个游戏助手。

## 第一步：登记你在玩的游戏

有三种方式，任选一种。

**方式一：直接跟猫娘说（推荐）**

在对话里说一句就行，比如：

```
我在玩原神
```

猫娘会调用登记工具，把当前游戏记下来。

**方式二：在插件管理器里手动触发**

打开插件管理器的「入口点」页，找到「登记游戏」，把游戏名填进去触发。

**方式三：直接问**

不确定现在登记的是什么，可以触发「查看当前游戏」，或者直接问猫娘。

## 陪聊时会发生什么

登记成功后，这个插件会往猫娘的对话上下文里放一小段说明，大意是：

```
【当前陪聊游戏】原神
口吻：熟悉提瓦特大陆，会聊元素搭配、角色培养与抽卡……
常用术语：
- 元素反应：两种元素相互作用产生的额外效果……
- 深境螺旋：每月刷新的高层挑战副本……
- 抽卡：通过祈愿获得角色与武器，有保底机制……
需要更细的术语（角色/机制/黑话）时，调用 lookup_game_term 查询。
```

这段说明只有猫娘能"看到"，不会显示在聊天窗口里。它不打断你说话，而是在你下一次开口时自然生效。

如果想知道这段说明现在是什么样，可以触发「重新注入语境」让它刷新一次。

## 切换游戏

直接说就行：

```
我不玩原神了，换鸣潮
```

猫娘会重新登记，并推一段新的说明，标题会写成「鸣潮（已从原神切换）」。

需要注意的是：**已经在对话里聊过的旧游戏内容，是收不回来的。** 插件能做的是让旧游戏的术语查不到、并明确告诉猫娘现在换游戏了。如果你发现它还偶尔提起上一款游戏，那是对话历史里的残留，不是切换失败。

## 让猫娘查术语

术语库分成两类：

| 类型 | 何时用 |
| --- | --- |
| 常用术语 | 登记时会自动放进语境，猫娘一直知道 |
| 其他术语（角色、机制细节、黑话） | 需要时才查，不占用上下文 |

猫娘遇到不确定的词会自己查。你也可以直接问它，比如：

```
声骸这个词是什么意思
```

如果它查的是当前游戏里没有的东西，它会告诉你「当前游戏里没有查到相关术语」，而不会拿别的游戏的知识乱答。

## 自己补充或修正术语

术语库分两层：随插件分发的默认层，和你可以改的覆盖层。

**默认层**在插件目录里，升级插件时会被替换，不要改这里。

**覆盖层**在你的用户数据目录下：

```
<用户数据根目录>/plugins/genshin_game_buddy/data/terms/<游戏>/<维度>.toml
```

各系统的默认用户数据根目录：

| 系统 | 默认位置 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\N.E.K.O` |
| macOS | `~/Library/Application Support/N.E.K.O` |
| Linux | `~/.local/share/N.E.K.O` |

覆盖层只需要写你要改的那几条，其余字段会自动继承默认层。例如你想把「雷神劈了」这个说法去掉，就在 `terms/genshin/characters.toml` 里只写：

```toml
[terms."雷电将军"]
aliases = ["雷神", "影", "Raiden Shogun"]
brief = "雷元素单手剑角色，靠元素爆发提供雷附着与全队增伤。"
slang = ["开大"]
```

改完重启插件（或触发一次「重新注入语境」）即可生效。

**四个维度的含义：**

| 维度文件 | 装什么 | 会不会自动进语境 |
| --- | --- | --- |
| `core.toml` | 最通用的术语，外加这款游戏的口吻 | 会 |
| `slang.toml` | 玩家黑话 | 会（少量） |
| `characters.toml` | 角色、职业 | 不会，按需查 |
| `systems.toml` | 机制、系统、模式 | 不会，按需查 |

**一条术语这样写：**

```toml
[terms."术语名"]
kind = "机制"
brief = "一句话解释，建议不超过 80 字。"
aliases = ["别名1", "别名2"]
slang = ["玩家会怎么说"]
avoid = "容易被说错的地方"
source = "版本或出处（可选）"
```

只有 `kind` 和 `brief` 是必填的。

## 新增一款游戏

分两步。

**第一步：在运行配置里登记游戏。** 打开你的用户数据目录下的运行配置：

```
<用户数据根目录>/plugins/genshin_game_buddy/config/plugin.toml
```

加上一段：

```toml
[games.honkai_star_rail]
display_name = "崩坏：星穹铁道"
aliases = ["崩铁", "星铁", "Star Rail"]
terms_dir = "terms/honkai_star_rail"
enabled = true
```

**第二步：建术语目录。** 在插件的覆盖层里建对应的四个文件：

```
<用户数据根目录>/plugins/genshin_game_buddy/data/terms/honkai_star_rail/core.toml
                                                              /characters.toml
                                                              /systems.toml
                                                              /slang.toml
```

`core.toml` 里要有一张 `[game]` 表写明口吻，其余三个只写 `[terms.…]`：

```toml
[game]
tone = "熟悉星穹列车与命途体系，聊配队、光锥和模拟宇宙"

[terms."命途"]
kind = "机制"
brief = "角色所属的体系分类，决定能装备哪些光锥。"
```

`aliases` 里最好把玩家常用的简称都写上——你说「崩铁」和说「星穹铁道」都要能认出来。

## 常见问题

**我说了游戏名，但它没登记上。**

可能是名字对不上。触发「列出可用游戏」看看当前登记了哪几款，用列表里的名字再说一次。

**它登记了一个不对的游戏。**

直接说「不对，我在玩 XX」重新登记即可。

**它把两款游戏的术语混着说了。**

先确认当前登记的是哪一款（触发「查看当前游戏」）。术语查询是严格按当前游戏隔离的，如果出现混淆，通常是模型把旧对话里的内容带进来了——说一句「我现在只聊 XX」通常能纠正。

**术语写错了想改。**

改覆盖层，不要改插件目录里的默认层。参见上面「自己补充或修正术语」。

**它还在提上一款游戏。**

这是对话历史的残留，不是切换失败。插件无法从已经发生的对话里撤回内容。

## 数据放在哪里

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 当前登记的游戏的记录 | 插件的存储区 | 重启插件后会自动恢复 |
| 你写的术语覆盖 | `<用户数据根目录>/plugins/genshin_game_buddy/data/terms/` | 升级插件不会丢 |
| 随插件的默认术语 | 插件目录 `terms/` | 升级插件会被替换 |
| 日志 | 插件管理器的日志页 | 只记录游戏名与数量，不记录你的对话内容 |
