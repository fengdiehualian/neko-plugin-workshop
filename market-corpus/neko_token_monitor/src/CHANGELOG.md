# 更新日志

## 0.8.29-dev.5 · 2026-10-22 · Windows 接管与退出恢复修复

- Windows 接管排除猫粮及其 WebView2 子进程，只隐藏实际可见的 NEKO 窗口；不把不可见的辅助窗口当成接管成功。
- 窗口原位置、最小化／最大化状态和进程身份在隐藏前保存；正常退出恢复本插件实际隐藏的窗口。异常退出后，下次启动先核对并恢复旧窗口，不误操作复用的窗口句柄。
- 原生切换与网页统一携带会话编号，旧会话退出不影响新会话。退出写入持久结束标记，减少页面中断后记录误续。
- Windows 增加摄像头开关：灰色待机、红色已确认接管；退出后只保留摄像头，可再次进入；右键摄像头打开额度页。
- 互动记录显式使用 UTF-8，避免系统默认编码导致中文记录保存失败。Windows 仍是窗口隐藏／恢复，不代表卸载或暂停 Live2D。
- 测试以 Windows 构建机的真实 Win32 隔离窗口为准，未等同于用户电脑正式 NEKO 实机通过。macOS 近期的文件喂食功能不属于此 Windows 修复包。
