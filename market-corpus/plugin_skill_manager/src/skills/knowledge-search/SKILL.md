# 知识库语义搜索

## 何时使用

- 用户询问的内容可能来自**已导入的文档**（手册、笔记、小说设定、技术文档等）
- 用户明确说"查一下知识库 / 我导入的文档里有没有提到……"
- 回答前需要引用文档原文或标注来源文件

## 如何使用

调用知识库插件的 `kb_search` 入口：

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `query` | string | 必填 | 自然语言查询，支持中英文 |
| `top_k` | int | 5 | 返回条数（1-20） |
| `track_hot` | bool | true | 是否计入热度（高频问题会自动沉淀到热知识表） |

返回 `hits` 数组，每条含 `content`（原文块）、`source`（来源文件名）、
`similarity`（相关度 0-1）、`promoted`（本次是否触发热知识提升）。

## 注意

- 回答时引用 `content` 原文并注明 `source`
- `similarity` 低于 0.3 的结果可能不相关，谨慎采用
- 每次搜索都会计入滑动窗口热度；同一问题在 7 天内被问 5 次，该知识块会自动
  提升到 `hot_knowledge` 表供快速查询
