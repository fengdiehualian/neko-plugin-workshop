# v1.2.79 更新说明

这一版修复应用内更新的两个问题：**下载进度全程 0%** 和 **下载完成后安装不执行**。覆盖安装即可；`runtime/` 与 `workspace/` 照例不参与覆盖。

## 一、下载进度 0% 修复

- 病因：码云通道的版本接口不返回附件字节数，进度分母恒为 0，百分比、进度条、明细全程不动
- 修复：分母优先取**已验签清单声明的字节数**（它同时是完整性硬校验字段，最可信），接口资产声明次之，下载响应头兜底；下载中实时显示 已收/总量/速度

## 二、安装链卡死修复

- 病因：安装等待循环里的 `tasklist | findstr` 活管道在无控制台环境偶发收不到 EOF，findstr 永久挂起，整个安装流程冻死（下载白下）
- 修复：检查改为落临时文件再检索（无活管道），活进程等待/已退出放行/文件缺失安全放行三个分支均实测验证
- 新增**断点续装**：已验证的更新包若安装没跑成，下次启动工坊自动重核 SHA 后续装，不用重新下载

## 三、继承口径

- 用量统计、弹层折叠、会话搜索、绿→青→蓝滑杆等继续生效

## 四、数量口径

- 单测 **304 pass / 0 fail**；static 全部通过；syntax 仓库自有 0 错
- 包体：payload **132 条**；`BUILD_INFO.json` 出处 `6e22c12 @ v1.2.79`

## 你需要做什么

不需要操作，覆盖安装即可（从旧版本更新上来同样会走修复后的链路）。
