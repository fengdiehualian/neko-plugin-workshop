# v1.2.78 更新说明

这一版在左下角新增**用量统计**。覆盖安装即可；`runtime/` 与 `workspace/` 照例不参与覆盖。

## 一、用量统计

- 侧栏底部新增「📊 用量统计」（与「查看已归档」「压缩上下文」同款入口风格），点开弹层：
  - **总览**：总用量 / 计费消息数 / 输入 / 输出 / 含思考，一排胶囊
  - **按对话**：各会话 token 用量（含已归档，带标记，降序）
  - **按日期**：每天用量（本地时区）
  - **按模型**：各模型用量；历史消息没记录模型的归入「未记录」，从这版起每个任务自动记录所用模型
  - **趋势柱状图**：近 7 / 30 天可切换，缺的天补零，悬停看当日数值
