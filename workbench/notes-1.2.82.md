### 侦察确认、本轮已修（主文件：wb-studio.mjs / wb-agent-lib.mjs）

- **引导页「探测可用模型」按钮复活**：首次配置页 HTML 补上 `probeTip` 等缺失 id（此前点击报 TypeError、卡在「探测中」）；`static_check` 同步识别页面 JS 的 `$('x')` 简写，这类「JS 引用了 HTML 没有的 id」今后过门禁就能抓到
- **保存警告不再被吞**：保存成功但连接测试有提示（如模型名 404）时，不再 1.2 秒后自动刷新把警告冲掉，改为按钮变「仍要进入工坊 →」由你决定

- **busy 三处补闸**：`/api/health` 返回 `busy` 字段，任务进行中刷新页面会恢复停止键（不再「停止键消失、再发消息 429」）；任务进行中切模型返回 429 拒绝（不再连累正在跑的引擎）；任务进行中启动更新同样 429 拒绝（更新会退出进程、杀掉在跑任务）
- **更新链 5 项**：① 下载中弹窗与页签都给出「取消下载」键，中止后状态复位可重试；② 下载 30 秒无新数据自动放弃该通道换源（不再永远卡半路）；③ zip 分支解压失败不删包不重启，下次启动凭 pending.json 续装（不会循环弹提示）；④ 更新弹窗正文显示更新说明（换行渲染、HTML 转义防注入）；⑤ 更新启动失败给出人话原因（如「任务进行中,完成后再更新」）
- **📊 图标观感**：用量统计按钮换成灰阶几何字符 ▦，与「查看已归档 / 压缩上下文」两个按钮观感一致（文案与功能不变）
- **外发写补拦（issue #26）**：命令替换体（`$(git push)`、反引号包裹）与「括号/编号包裹」形态（如 `#26 (git push)`）的 git push 一律命中外发写确认——此前这些形态会被当成普通文本自动放行
