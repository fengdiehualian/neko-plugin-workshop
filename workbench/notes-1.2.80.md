# v1.2.80 更新说明

热修：v1.2.79 存在**启动即崩溃**的问题，装上后工坊 2.5 秒左右自动退出。覆盖安装即可；`runtime/` 与 `workspace/` 照例不参与覆盖。

## 一、修复内容

- 病因：v1.2.79 新增的断点续装定时器引用了请求回调作用域里的函数，启动后触发未定义引用直接崩溃
- 修复：续装检查改为在页面/健康检查第一次被访问时执行（此时窗口已真正打开），实例前台 20 秒存活实测通过
- v1.2.79 的两处更新修复（进度 0% 与安装链卡死）保持有效

## 二、继承口径

- 用量统计、弹层折叠、会话搜索、绿→青→蓝滑杆等继续生效

## 三、数量口径

- 单测 **304 pass / 0 fail**；static 全部通过；syntax 仓库自有 0 错
- 包体：payload **132 条**；`BUILD_INFO.json` 出处 `61c0e3c @ v1.2.80`

## 你需要做什么

**如果你的工坊还在 v1.2.76~1.2.79 之间：直接用更新功能升到 v1.2.80**（更新链路的修复从这一版起完整生效；若卡住请重启工坊再试一次，已下载的包会自动续装）。
