# v1.2.81 更新说明

这一版统一了用量统计的观感并增强了柱状图。覆盖安装即可；`runtime/` 与 `workspace/` 照例不参与覆盖。

## 一、用量统计整改

- **体感统一**：入口按钮与「查看已归档 / 压缩上下文」同款；弹层卡片对齐工坊弹窗的既有设计语言（宽度体系、圆角、边框、内边距、阴影、遮罩、关闭钮），页签药丸对齐设置面板风格
- **柱状图悬停详情**：悬停任意柱子弹出详情卡片——完整日期、当日 token 数、当日消息数、相对窗口占比、峰值标记；卡片位置跟随柱子且不溢出
- **用量刻度轴**：柱状图左侧新增 4~5 档 token 刻度（自适应两档退避防撞档）与对齐的浅色网格线

## 二、继承口径

- 更新链路三修复（进度/安装/续装）、折叠弹层、会话搜索、绿→青→蓝滑杆等继续生效

## 三、数量口径

- 单测 **304 pass / 0 fail**（byDate 断言补 messages 字段）；static 全部通过；syntax 仓库自有 0 错
- 包体：payload **132 条**；`BUILD_INFO.json` 出处 <提交> @ v1.2.81
