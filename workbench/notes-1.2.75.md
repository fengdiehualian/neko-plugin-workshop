# v1.2.75 更新说明

这一版加了**会话搜索框**并按参考图优化了思考强度效果。覆盖安装即可；runtime/ 与 workspace/ 照例不参与覆盖。

## 一、会话搜索

- 「新对话」上方新增搜索框，输入即过滤，范围覆盖全部会话（含已归档，带「已归档」标记），点击直达，清空恢复
- 匹配按行文本（标题+消息条数+累计 token），无命中显示「无匹配」；Esc 即清空并恢复原列表
- 过滤复用既有 GET /api/sessions 全量缓存，无新后端路由；搜索中点「查看已归档」会先清空搜索再切视图

## 二、思考强度

- 填充条换成参考图同款**绿→青→蓝方向渐变**（左绿=低档、右蓝=高档），渐变锚定 128px 轨道定宽，拖到哪一档就露出渐变的哪一段
- 新增**全圆角胶囊轨道凹槽**：「自动」「关」等未填满状态也能看清整条轨道在哪
- thumb 换成**白色圆点+蓝 #2f7bf6 细环+柔光晕**（浅色主题上靠蓝环立得住）
- 双层动效保留、配色全部换到同一色板：底流为绿→青→蓝→亮青循环渐变；流星白头的光晕由粉改蓝
- 档位越高越快不变（1.3/0.9/0.6/0.4s），「自动」「关」保持全静止，系统开「减少动态效果」时全停
- 浅色主题（粉/蓝/白）的绿端/青端自动换深变体 #15803d/#0d9488（对轨道底 3.28-4.55:1，达到非文本 UI 3:1）；黑主题保留参考图原色（5.84-6.38:1）
- 128px 定宽、滑杆交互不被流星层遮挡等骨架约束原样保留
