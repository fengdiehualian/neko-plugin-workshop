# N.E.K.O. 插件工坊

让零基础的你,用一句话做出 N.E.K.O.(猫娘计划)插件。

## 快速开始(只需两步!)

1. **双击 start.cmd(或桌面快捷方式)** —— 工坊在自己的应用窗口中打开。
2. **第一次会先弹出「首次配置」**:填写你模型服务商提供的接口地址(Base URL)、
   API 密钥和模型名称(需要 OpenAI 兼容格式,页面内有说明),
   点「保存并进入工坊」,以后就不用再填了。

然后直接说需求,比如:「做一个每天提醒我喝水的插件」,等猫咪做完活,
点下载按钮拿到 .neko-plugin 文件,在 N.E.K.O 的插件管理器里导入即可。

## 工坊窗口

- 工坊运行在自己的窗口里(独立于你平时的浏览器),可以多开窗口指向同一工坊。
- **关闭窗口 = 安全退出**:引擎随窗口关闭自动停止,对话已实时保存,放心关。
- 再次双击 start.cmd 不会重复启动,只会重新打开窗口。
- 多个对话相互独立、互不干扰;左侧列表可新建/删除/切换对话。

## 放置位置

把本文件夹整个放到 N.E.K.O 安装目录旁边(同一个文件夹里),例如:

    某个文件夹\
    ├── N.E.K.O\          <- 猫娘计划(安装版或源码版都可以)
    └── N.E.K.O.插件工坊\ <- 本文件夹

> 工坊需要用 N.E.K.O 自带的插件检查工具把关质量;放别处也可以打开
> wb-studio.config.json 手动填 nekoRepo 路径。

## 目录说明

| 目录/文件 | 用途 |
|---|---|
| start.cmd | 双击启动 |
| workspace\ | 你的插件项目都在这里生成 |
| workspace\*.neko-plugin | 做好的插件安装包 |
| _engine\ _bin\ _py\ _site\ | 工具运行时(不用管) |
| runtime\ | 引擎数据/对话记录/窗口配置(密钥也在这里,勿外传;可整体删除重置) |
| wb-studio.config.json | 高级设置(端口/模型/窗口尺寸;openMode 改 browser 可用系统浏览器) |

## 常见问题

- **双击后窗口一闪而过** -> 关掉后重新双击;仍不行就把窗口里的红字截图反馈。
- **提示「模型服务限流/额度不足」** -> 等几分钟再点开工;或检查账户额度。
- **提示「模型服务拒绝访问」** -> 关掉工坊,删除 runtime\config\opencode\opencode.json,
  重新双击 start.cmd 即会再次弹出配置页,重新填密钥。
- **提示找不到 N.E.K.O** -> 把本文件夹放到 N.E.K.O 旁边,或手动填配置里的 nekoRepo。
- **生成的插件装到 N.E.K.O 后报错** -> 在对话里说「帮我修复 xx 插件,问题是……」。
- **想换模型/换服务商** -> 关掉工坊,删除 runtime\config\opencode\opencode.json,
  重开工坊会再次进入配置页。

## 隐私与安全

- 全部处理都在本机完成;对话与生成的代码保存在 workspace\ 里。
- 模型服务只在生成时联网调用你的模型服务商 API。
- 密钥保存在本文件夹 runtime\ 里,不会上传;请勿把整个文件夹发给别人。
- 工坊只读写本文件夹与 N.E.K.O 的插件目录,不碰系统其他位置。
